# EIC0002_Carta de crédito

# Carta de crédito

| Produto: | Easy Import Control - SIGAEIC |
| --- | --- |
| Versões: | P11 |
| Ocorrência: | Carta de crédito |
| Passo a passo: | Esta rotina permite cadastrar as Cartas de Créditos emitidas para o Fornecedor em garantia do pagamento do Importador.Esta transação armazena os dados da Carta de Crédito que deve ser vinculada ao processo de embarque. Este tratamento permite o controle de saldos à medida que estas cartas de crédito são associadas aos pedidos de importação.  Pré-Requisitos:Possuir um Purchase Order cadastrado.
#### Exemplo - Como cadastrar uma Carta de Crédito
No Easy Import Control (SIGAEIC), acesse  Atualizações\ Financeiro\ Carta de Credito.Clique na opção Incluir e informe os seguintes dados:3. Em Açoes Relacionadas clique em Incluir.4. Selecione o PO desejado e clique em Confirmar.5. Clique em Confirmar para salvar a Carta de Crédito. |
| Observações: | Importante: Os saldos disponíveis podem ser consultados através do campo Saldo Carta, disponíveis na carta de crédito. O Saldo Carta é abatido toda vez que um Purchase Order é vinculado a L/C. |
