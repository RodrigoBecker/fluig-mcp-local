# Criação de processos workflow

# Índice

Em processos workflow é possível definir o responsável por uma atividade através de mecanismos de atribuição. Para resolver os responsáveis por uma tarefa do processo workflow e/ou gestor de processo é possível criar um mecanismo de atribuição personalizado, diferente dos mecanismos oferecidos por padrão pela plataforma.
