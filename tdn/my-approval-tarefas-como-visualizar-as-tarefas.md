# My Approval ❙ Tarefas ❙ Como visualizar as tarefas?

Para visualizar todas as tarefas disponíveis no aplicativo My Approval siga os passos abaixo:

---

**01.** Acionar a aba **Tarefas**;

**02.** Todas as tarefas serão exibidas;

É possível acessar as tarefas acionando o ícone **>** .

### Detalhes da tarefa

Para ver quais detalhes a tarefa possui siga os passos abaixo:

**01.** Com a tarefa aberta é possível ver:

- Título: título que foi atribuído à tarefa aberta conforme definido nas configurações do processo.
- Destaque: Informação definida conforme configuração feita no processo.
- Descrição: descrição que foi atribuída à tarefa aberta conforme definido nas configurações do processo.

**02.** É possível também ver o formulário, caso a tarefa possua, para isso, acionar **Visualizar formulário**;

- O formulário será aberto para visualização: verificar se há mais alguma ação aqui

### Opções da tarefa

Para ver quais opções de decisão a tarefa possui siga os passos abaixo:

**01.** Acionar o botão Ver opções de decisão;

**02.** Selecionar a ação que deseja tomar na tarefa;

Enquanto a decisão da tarefa é enviada é possível cancelar a ação por meio do botão **Cancelar**.

**03.** A decisão será encaminhada e neste passo também é possível escolher um usuário para prosseguir com a tarefa. Acionar o botão Selecione um usuário para enviar;

**04.** Escolha o usuário para que a tarefa seja enviada acionando o nome dele. O usuário escolhido será identificado por um ícone verde;

**05.** Acionar o botão ![](/download/attachments/565739974/oie_transparent.png?version=1&modificationDate=1620999346610&api=v2) para que a tarefa seja enviada para o usuário selecionado;

Enquanto a tarefa é enviada para o usuário é possível cancelar a ação por meio do botão **Cancelar**.

**06.** Após isso, o usuário autenticado é levado novamente para a tela geral de todas as tarefas. A tarefa aberta será apresentada com o indicativo Concluído.
