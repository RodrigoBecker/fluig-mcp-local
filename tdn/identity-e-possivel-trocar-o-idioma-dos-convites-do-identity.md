# Identity | É possível trocar o idioma dos convites do Identity?

**Dúvida**

É possível trocar o idioma dos convites do Identity?

**Solução**

O idioma dos convites do Identity será o mesmo definido no navegador do usuário que está realizando o envio desses convites. Se o idioma padrão do navegador for português, esse será o idioma dos convites.

A alteração do idioma padrão deve ser realizada nas configurações do navegador pelo próprio usuário. Saiba mais em [Notificações via E-mail](/pages/viewpage.action?pageId=273980172).
