# BPM 068 - Posso importar processos criados no Microsoft Visio no fluig?

# Índice

# Plataforma

**Produto:  **fluig

**Versão:** 1.5.11

# Ocorrência

Posso importar processos criados no Microsoft Visio no fluig?

# Solução

Infelizmente este recurso não está disponível no fluig. 

Caso deseje que esta funcionalidade seja avaliada pela Equipe de Produto do fluig basta abrir uma chamado como Sugestão de Melhoria para o Suporte fluig através do [Portal do Cliente](https://suporte.totvs.com/).
