# Plataforma ❙ Mais ações de datasets

# Falando de mais ações de datasets...

---

Dependendo do tipo de *dataset,* a plataforma disponibiliza diversas ações que podem ser efetuadas: consultar dados do *dataset,* editar em modo simples ou avançado, exibir o código-fonte, consultar o histórico de versões, remover, ativar ou desativar *dataset.*

Na tela de [Datasets](/pages/viewpage.action?pageId=235598394), ao localizar o *dataset* para o qual será necessário efetuar alguma dessas ações, é possível acessar o menu de ações por meio do botão ![](/download/attachments/400655388/Barras%20horizontais2.png?version=1&modificationDate=1536079675000&api=v2) na coluna **Mais ações**. 

![](/download/attachments/400655388/Mais%20a%C3%A7%C3%B5es%20de%20dataset.png?version=4&modificationDate=1750786265837&api=v2)

## Consultar dataset

---

**01.** No menu **Mais ações**, clique em **Consultar**.

**02.** Veja os dados do *dataset*.

**03.** Clique em **Fechar**.

## Editar dataset

---

**01.** No menu **Mais ações**, clique em **Editar dataset**.

Essa opção está disponível para os *datasets* simples ou avançados:

- **Dataset simples**: a plataforma apresenta os campos para configuração, conforme apresentado na documentação de usuário [Novo Dataset simples](/pages/viewpage.action?pageId=235598394#Plataforma❙Datasets-novo);

- **Dataset avançado**: a plataforma abre uma nova aba com a interface para edição do código-fonte do *dataset,* conforme apresentado na documentação de usuário [Novo Dataset avançado](/pages/viewpage.action?pageId=235598394#Plataforma❙Datasets-avançado). Pode-se editar o código-fonte do rascunho ou da versão publicada do dataset escolhido.

## Editar em modo avançado

---

**01. **No menu **Mais ações** ![](/download/attachments/400655388/Barras%20horizontais2.png?version=1&modificationDate=1536079675000&api=v2), clique em **Editar em modo avançado**.

Essa opção só está disponível para os *datasets* simples, possibilitando a escolha da forma de edição:

- **Edição simples**: apresenta os campos para configuração, conforme apresentado na documentação de usuário [Novo Dataset simples](/pages/viewpage.action?pageId=235598394#Plataforma❙Datasets-novo);

- **Edição avançada**: a plataforma abreuma nova aba com a interface para edição do código-fonte do *dataset,* conforme apresentado na documentação de usuário [Novo Dataset avançado](/pages/viewpage.action?pageId=235598394#Plataforma❙Datasets-avançado). Pode-se editar o código-fonte do rascunho (se houver) ou da versão publicada do dataset escolhido.

Importante!

A partir do momento em que um *dataset* simples for editado em modo avançado, ele passa a ser um *dataset* avançado, e com isso, não poderá ser novamente editado em modo simples.

**02.** Na janela de confirmação, clique em **Editar em modo avançado**.

**03.** Edite o código do *dataset*, conforme necessidade.

**04.** Clique em **Publicar** para concluir as alterações.

## Exibir código fonte do dataset

---

Compatibilidade no modo escuro

Este recurso ainda não é compatível com o modo escuro lançado na atualização [Voyager 2.0](https://tdn.totvs.com/x/6HxjN). 

**01.** No menu **Mais ações**, clique em **Exibir código**.

Essa opção está disponível para os *datasets* simples ou avançados.

**02**. Veja o código fonte em *javascript* do *dataset *desenvolvido.

**03**. Clique em **Fechar**.

## Exibir histórico de versões

---

**01.** No menu **Mais ações**, clique em **Histórico de versões**.

**02**. Veja o histórico de versões publicadas do *dataset *consultado.

Cada alteração gravada na configuração do dataset simples, ou alteração em código-fonte publicada no dataset avançado gera uma nova versão no histórico.

Caso seja necessário visualizar o código fonte da versão, é possível acessar o código, clicando na linha referente à versão desejada.

**03**. Clique em **Voltar**.

## Restaurar versão anterior de um dataset

---

**01.** No menu **Mais ações** ![](/download/attachments/400655388/Barras%20horizontais2.png?version=1&modificationDate=1536079675000&api=v2), clique em **Histórico de versões**.

**02**. Localize no histórico de versões, a versão que deve ser restaurada.

**03**. Clique em **Restaurar**.

Com isso, será criada uma nova versão do *dataset,* com o código fonte que foi restaurado.

## Desativar / Ativar dataset

---

**01. **No menu **Mais ações** ![](/download/attachments/400655388/Barras%20horizontais2.png?version=1&modificationDate=1536079675000&api=v2), clique em **Desativar**ou**Ativar**.

Essa opção está disponível para os *datasets* simples ou avançados. Ao desativar um *dataset*, se houver configuração de sincronização para ele, essa configuração será perdida.

**02.** Clique em **Desativar **ou** Ativar **para confirmar a ação.

Fique atento!

Esta documentação é válida a partir da atualização **Voyager (2.0)**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
