# Requisitos mínimos para executar os bancos de dados homologados

# Índice

# Objetivo

O objetivo deste guia é mostrar qual o hardware mínimo para executar os bancos de dados homologados, conforme demonstrado na [Matriz de Portabilidade](/display/fluig/Matriz+de+Portabilidade) do TOTVS Fluig Plataforma.

## Recomendação mínima

| Memória RAM | Quantidade de memória em GB | 8 GB ¹ |
| --- | --- | --- |
| Processador | Bits | 64 |
| Core (vCPU) | 2 |  |
| Disco | Quantidade de disco | 60 GB ¹ |

¹ Quantidade de disco médio para o sistema operacional e o banco de dados. Este valor poderá ser modificado conforme necessidade do cliente.
