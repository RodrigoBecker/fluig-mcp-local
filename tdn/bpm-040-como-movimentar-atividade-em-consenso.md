# BPM 040 - Como movimentar atividade em consenso?

# Índice

# Plataforma

**Produto:  **fluig

**Versão: **Todas as versões

# Ocorrência

Percentual de consenso não se altera quando o primeiro usuário executa a atividade, a atividade foi configurada para 2 usuários com consenso de 1%.

# Solução

Uma pessoa decidindo não é um consenso. Se colocar 3 usuários no consenso e dois decidirem, a atividade será movimentada automaticamente quando o consenso mínimo for atingido. 
No caso de existir somente dois usuários os dois são obrigados a movimentar.

Sobre o percentual de consenso, se um usuário decide que o fluxo vai pra atividade A e o outro usuário decide que vai para a atividade B, o consenso não é de 50%, mas sim de 0%, visto que não houve consenso algum. Uma decisão não é um consenso. Consenso só pode existir entre mais pessoas. Entre duas pessoas ou existe consenso (100%) ou não existe (0%).
