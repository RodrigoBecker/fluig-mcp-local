# Plataforma ❙ Slots

# Falando de slots...

---

O *layout* de uma página é composto por diversos *slots*, onde é possível adicionar *widgets*. *Slots* são espaços pré-definidos dentro de um *layout*, que indicam o local da página onde é possível adicionar *widgets*.

![](/download/attachments/234455982/slots%20contrutor.png?version=1&modificationDate=1749664537510&api=v2)

Fique atento!

Esta documentação é válida a partir da atualização **Voyager (2.0)**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
