# Diferença entre Nuvem Pública e Nuvem Privada

# Definição

### Nuvem Pública (Cloud)

---

Infraestrutura e controle de ambiente da plataforma TOTVS Fluig administrados pela equipe TOTVS Fluig e/ou parceiros autorizados sobre contrato conforme proposta comercial;

### Nuvem Privada (On-premise)

---

Infraestrutura e controle de ambiente da plataforma TOTVS Fluig administrados pelo CLIENTE, sendo de responsabilidade do mesmo atualizar para nova release;

# Matriz de Diferenças

|  | Nuvem Pública* | Nuvem Privada |
| --- | --- | --- |
|  | Nuvem Pública* | Nuvem Privada |
| Provisionamento com TOTVS Identity | Sim | Sim(Plataforma em nuvem privada +Identity em nuvem pública) |
| Espaço em Disco | Conforme proposta | Ilimitado no Software |
| Cópia Controlada | Conforme proposta | Necessita de Servidor Windows+ Microsoft Office instalado no Servidor |
| Usuários convidados | Conforme proposta | Ilimitado no Software |
| Acesso a TOTVS Store | Sim | Sim |
| Desenvolvimento no Fluig Studio | Sim(instalado na máquina cliente)  | Sim |
| Criação de Tenants | Ilimitado | Ilimitado no Software |
| Fluig Viewer | Disponível | Disponível |
| Ambiente de Homologação | Conforme proposta | Instalado na mesma máquina de produção |

* Verifique opções com fornecedor de Data Center autorizado.
