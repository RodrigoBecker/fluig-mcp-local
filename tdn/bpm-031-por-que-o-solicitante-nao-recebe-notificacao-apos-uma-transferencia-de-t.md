# BPM 031 - Por que o solicitante não recebe notificação após uma transferência de tarefa?

# Índice

# Plataforma

**Produto:  **fluig

**Versão: **Todas as versões

# Ocorrência

Solicitante não recebe notificação após uma transferência de tarefa. 

# Causa

O fluig envia a notificação apenas quando trata-se de uma movimentação do processo.

# Solução

Transferências são ações internas dos processos e o fluig entende que o solicitante não precisa ser notificado sobre esse tipo de procedimento.

Caso este usuário queria obter estas informações, ele pode consultar a solicitação e verificar os detalhes.
