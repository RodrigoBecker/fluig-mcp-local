# Platform ❙ Store

# Speaking of Store items...

---

This feature allows easily and almost instantaneously installing [TOTVS Store](http://www.fluigstore.com/) solutions directly in the platform.

This type of offering is implemented by TOTVS Fluig developers or partners, based on standard platform components such as widgets, layouts and pages. All of the solutions available in this feature underwent rigorous quality control before being made available for installation.

Note:

This screen shows free and paid solutions; free solutions can be installed at any time. Installation of paid solutions is not immediately available. The user must contact the TOTVS Fluig sales representative or partner to request a demo before the solution can be installed.

Important!

Refer to [this FAQ](/pages/viewpage.action?pageId=437257928) if you cannot see the solutions in your environment.

## Search solutions

---

**01**. In the main menu, click ![](/download/attachments/388236671/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1764855605477&api=v2) **Control Panel**.

**02.** Locate the **Applications** group.

**03.** Click ![](/download/attachments/388236671/%C3%ADcone-store.png?version=1&modificationDate=1764854705077&api=v2) **Store items**.

**04**. Search the desired solutions.

Search options available:

- **All solutions (tab)**: show all solutions available.

- **Installed solutions (tab)**: show solutions installed on the platform.

- **Search (field)**: search a solution name.

- **Use license (combobox)**: view only free solutions, only paid solutions, or all solutions.

**05.** It is also possible to use the filter located to the right of the search field, identified by the icon ![](/download/attachments/388236671/flaticon-filter%20%281%29.png?version=1&modificationDate=1764855784970&api=v2).

The available options in this filter are:

- **All developers**: displays solutions from all partner developers;

- **Digte**: displays all solutions from the partner Digte;

- **TOTVS**: displays all solutions from TOTVS.

Additionally, it is possible to check the **Applications** and **Flows** fields.

**06.** View solutions displayed in blocks.

Users may check additional solution information. Click any part of the respective block to open a window with more details about the solution.

For solutions developed by partners under the [ISV Program](https://isvprogram.fluig.com/), a partner support program, the identification seal ![](/download/attachments/388236671/2018-11-09.jpg?version=1&modificationDate=1544623393257&api=v2) is shown on the upper right corner of the block.

## Install solution

---

**01**. In the main menu, click ![](/download/attachments/388236671/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1764855605477&api=v2) **Control Panel**.

**02.** Locate the **Applications** group.

**03.** Click ![](/download/attachments/388236671/%C3%ADcone-store.png?version=1&modificationDate=1764854705077&api=v2) **Store items**.

**04.** Follow the steps in the item Search solutions. 

**05.** Click **Install** on the solution’s information window.

The “Install” option only appears if the solution is free or if the solution license has been acquired. Compatibility between the application version and the TOTVS Fluig Platform update is also checked. After all validations are completed, the installation process will begin automatically.

If the solution was developed for an update newer than the one available on the environment, the platform must be updated to install the solution.

**06.** Wait until the installation is completed.

The installed solution is shown in the *Installed solutions* tab and can also be accessed on **Control Panel → Applications**group**→****Component Center****.**

## Update solution

---

**01**. In the main menu, click ![](/download/attachments/388236671/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1764855605477&api=v2) **Control Panel**.

**02.** Locate the **Applications** group.

**03.** Click ![](/download/attachments/388236671/%C3%ADcone-store.png?version=1&modificationDate=1764854705077&api=v2) **Store items**.

**04.**  Click the **Installed solutions** tab.

**05**. Find the solution to be updated.

**06.** Click **Update**.

This option is only shown if there is a newer solution version available for the current TOTVS Fluig Platform update.

**07**. Wait until the update is completed.

Attention!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
