# Atualização Silver Mist (1.8.1)

![](/download/attachments/745742724/silver_mist_1660_490.png?version=1&modificationDate=1678739461237&api=v2)

Mantenha seu License Server atualizado!

A partir da release **Silver Mist 1.8.1**, para garantir o correto controle de licenças, é necessário que o License Server esteja utilizando a versão **3.2.0**ou superior. Caso o License Server esteja utilizando uma versão inferior, o Fluig entrará no modo demonstração, **não permitindo o acesso dos usuários**.

Desativação do Universal Analytics

Conforme comunicado divulgado no portal do cliente dia (04/04/2023), o Google desativará o Universal Analytics em **01** **de Julho de 2023** e será substituído pelo **Google Analytics 4**. Essa desativação fará com que os dados e métricas da sua empresa no TOTVS Fluig Plataforma deixem de ser coletados.

Para continuar utilizando o Google Analytics no Fluig, é necessário que a tag de configuração do Google Analytics 4 seja criada e configurada no TOTVS Fluig Plataforma. 

Fique ligado: recomendamos que a nova tag seja configurada antes do prazo de desativação. **Clique aqui** e confira como efetuar a configuração. 

- Confira a notícia que disponibilizamos no **portal de clientes**.

Release mínima para atualização da plataforma

O processo de atualização para a release 1.8.1 do Fluig, exige que a plataforma esteja na release **1.7.1 ou superior**. Caso seu ambiente esteja em uma release inferior, é necessário realizar o processo de atualização para a 1.7.1, e então atualizar o Fluig para a 1.8.1.

## WCM

---

**Deseja criar páginas com mais praticidade?**

Com o novo construtor de páginas ficou muito mais fácil criar páginas no TOTVS Fluig, para que seus portais fiquem prontos para serem visualizados em qualquer dispositivo, seja ele computador, celulares e tablets.

Desenvolvemos um layout totalmente modernizado e mais clean, para que a criação e o gerenciamento de páginas seja cada vez mais prático e intuitivo. Confira abaixo as novidades! ![(big grin)](/s/5bn9pn/8804/xgjkrn/_/images/icons/emoticons/biggrin.svg)

**Clique, arraste e solte**

As *widgets* agora estão disponíveis no menu lateral do construtor, organizadas por categorias. Para selecionar uma *widget*, basta clicar e arrastá-la até os slots do layout na área do construtor. 

Ao arrastar uma *widget* para um *slot* é possível notar uma marcação azul indicando a posição que a *widget* irá ocupar, dessa forma a movimentação de *widgets* entre *slots* está muito mais simplificada.

Além disso, o menu pode ser recolhido para aproveitar toda a área do construtor. Para adicionar novas *widgets*, basta clicar em um *slot* vazio para abrir o menu novamente.

![](/download/attachments/745742724/construtor%20de%20p%C3%A1ginas%20drag%20and%20drop.gif?version=1&modificationDate=1678897016430&api=v2)

**Layouts Responsivos**

Alguns *layouts* foram reestruturados para atender a critérios de responsividade. Ao criar uma página, você identificará a tag **Layout responsivo** e quando utilizados na página, significa que o conteúdo irá se adaptar a diferentes tamanhos de telas e dispositivos móveis.

Mas lembre-se, para que a experiência responsiva seja satisfatória todas as *widgets* adicionadas na página também precisam ser responsivas.

Para clientes que possuem desenvolvimento de layouts, recomendamos validar algumas propriedades novas para garantir que o layout está escrito de forma responsiva ou que o novo construtor de páginas seja carregado corretamente. Entenda melhor **aqui**.

Nas versões anteriores usávamos o Yui Compressor Maven Plugin porém ele não tem compatibilidade com ES6+. No desenvolvimento de formulários, nada foi afetado. Formulários não passam pelo mesmo processo de compilação de widgets.

Saiba mais detalhes acessando a documentação **Closure Compiler Maven Plugin**.

## Arquitetura

---

**Mais segurança e desempenho no Fluig**

Nesta release homologamos a versão do MySQL 8.0. Essa ação vem com o intuito de trazer maior segurança, estabilidade e desempenho ao TOTVS Fluig Plataforma. Lembrando que a atual versão homologada pela plataforma (MySQL 5.7) deixará de receber suporte pela própria fornecedora do sistema em **Outubro de 2023**. Atualize sua plataforma para garantir todos os benefícios dessa nova versão.

Para mais detalhes acesse a documentação oficial do MySQL **aqui**.

**ATENÇÃO:** A versão MySQL 8.0 exige algumas configurações iniciais que só podem ser realizadas na instalação. Portanto é muito importante que a atualização seja feita por um especialista em banco de dados.

Ao atualizar o banco de dados para a versão MySQL 8.0 também deve ser atualizado o driver de conexão JDBC "MySQL Connector/J". Por questões legais não é permitido que o driver seja disponibilizado na instalação do TOTVS Fluig, portando o processo deve ser feito manualmente.

Verifique as recomendações e instruções de como realizar a **Configuração de banco de dados MySQL**.

Além disso, homologamos os sistemas operacionais **Oracle Linux** e **Red Hat Enterprise Linux** na versão **8.7**.

## Correções

---

- Correção realizada para que ao finalizar uma avaliação vinculada a um treinamento todas as informações sejam apresentadas corretamente.
- Correção realizada para que mostre apenas uma opção ou permita a criação de sub-processos mesmo tendo fluxo automático configurado.
- Realizada correção para que usuários com estado bloqueado, não consigam iniciar solicitações em um processo.
- Ajuste realizado para que a mensagem ao excluir um anexo que foi adicionado por outro usuário seja apresentada corretamente.
- Correção realizada para que seja possível desabilitar o bloqueio de Clickjacking corretamente nos parâmetros da plataforma.
- Correção realizada para que um documento compartilhado externamente não fique mais disponível para acesso após sua exclusão.
- Correção realizada para que somente os processos ativos sejam apresentados na central de diagnóstico.
- Ajuste realizado para que seja possível excluir um processo que não tenha vinculo ao processo pai e que não possua solicitações iniciadas. Ajuste realizado também nas mensagens apresentadas.
- Correção realizada para que ao realizar uma publicação a plataforma busque outras comunidades corretamente para replicar a publicação.
- Ajustes realizados na exibição do select, ao enviar os dados para movimentação de uma atividade para que não ocorra duplicidade nos valores no formdata.
- Correção realizada para que seja possível criar um artigo corretamente em uma comunidade, em que a geração de thumbnail esteja habilitada no cadastro da empresa.
- Correção realizada para que seja possível publicar corretamente um documento como anexo em solicitações.
- Correção realizada para que o usuário que movimentar a solicitação não possua permissão no papel configurado na atividade, uma mensagem será apresentada, evitando a movimentação e a perda de relacionamento.
- Correção realizada para que ao alterar o fuso horário a data dos documentos mantenha-se da forma correta.
- Correção realizada para que seja possível acessar o arquivo anexado ao processo quando o processo está utilizando eventos de processos e datasets.
- Correção realizada para que ao executar o fluxo automático relacionado à tarefas em atraso, o e-mail de notificação seja enviado corretamente.
- Correção realizada para que a barra de rolagem do documento seja apresentada corretamente na tela de anexos da solicitação.
- Implementada validação para identificar o usuário autenticado na plataforma ou o usuário administrador, fazendo com que o envio da URL do documento via API ocorra corretamente ao utilizar o fluxo automático.
- Correção realizada para que seja possível transferir uma solicitação ao gestor do processo quando a mesma está atribuída por campos de formulário.
- Corrigida inconsistência na transferência de pendencias onde continha documentos com dois ou mais níveis de aprovação.
- Correção realizada para ajustar o comportamento das regras de formulário abaixo:Ao excluir uma atividade que possua regras de formulário, que as regras sejam excluídas também. 
- Ao filtrar as regras de formulário por atividade para que seja possível visualizar todas as regras corretamente.
- Correção realizada para que ao habilitar a opção "Utilizar logo da empresa no formulário" na configuração do formulário do processo, a logo seja apresentada corretamente no formulário.
- Correção realizada para que seja possível adicionar widgets no layout Comunicativo com usuário comum que possua permissão para editar a página.
- Correção realizada para que o conteúdo da aba da comunidade seja apresentado corretamente ao selecionar um arquivo para a publicação.
- Correção realizada para que seja possível exportar listas corretamente.
