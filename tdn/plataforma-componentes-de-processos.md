# Plataforma ❙ Componentes de processos

Consulte a documentação correta:

Esta documentação refere-se ao novo editor de processos da plataforma. Caso esteja utilizando o editor de processos atual, acesse [Configurar atividades e fluxos](/pages/viewpage.action?pageId=233763197). 

IDIOMA

![](/download/attachments/860252098/diagrama.png?version=2&modificationDate=1742307589447&api=v2)

---

Os componentes são as representações gráficas das etapas de um processo e são utilizados para montar o seu diagrama, no qual é possível ver o que acontece com a solicitação quando ela está em cada etapa, bem como as direções que ela pode seguir conforme as etapas vão sendo concluídas.

Cada componente possui características e configurações próprias, que podem ser definidas de acordo com o que é esperado para cada etapa, em cada processo, para cada negócio.

Clique em cada componente para obter informações mais detalhadas sobre eles.

![](/download/attachments/860252098/in%C3%ADcio-mini.png?version=1&modificationDate=1724770157570&api=v2)  

**Início**Representa a etapa inicial do processo, onde o fluxo começa e a solicitação é iniciada.

![](/download/attachments/860252098/atividade-mini.png?version=1&modificationDate=1724770157000&api=v2)   

[**Atividade**](/pages/viewpage.action?pageId=862123505)
Representa cada etapa do processo pelas quais a solicitação vai passar.

![](/download/attachments/860252098/atividade-servi%C3%A7o-mini.png?version=1&modificationDate=1741020732123&api=v2)   

[**Atividade de serviço**](/pages/viewpage.action?pageId=919050491)
Representa a consulta de dados de um serviço externo.

![](/download/attachments/860252098/subprocesso-mini.png?version=1&modificationDate=1742317086460&api=v2)   

[**Subprocesso**](/pages/viewpage.action?pageId=923182939)
Representa outro processo dentro do processo principal.

![](/download/attachments/860252098/bloco-de-atividades-mini.png?version=1&modificationDate=1760365255197&api=v2)   

[**Bloco de atividades**](/pages/viewpage.action?pageId=993699681)
Representa a organização e as subdivisões participantes do processo.

![](/download/attachments/860252098/paralelo-mini.png?version=1&modificationDate=1724770157910&api=v2)   

**Paralelo**
Representa o início de etapas paralelas, onde o fluxo principal se divide em duas ou mais etapas.

![](/download/attachments/860252098/join-mini.png?version=1&modificationDate=1724770157747&api=v2)   

**Join**
Representa o fim de etapas paralelas, sendo retomado o fluxo principal.

![](/download/attachments/860252098/exclusivo-mini.png?version=1&modificationDate=1739284743413&api=v2)   

**Exclusivo**Representa o mecanismo que direciona para qual fluxo a solicitação deve seguir, dependendo do resultado obtido.

![](/download/attachments/860252098/cancelamento-mini.png?version=1&modificationDate=1724770157243&api=v2)   

**Cancelamento**
Representa o cancelamento da solicitação.

![](/download/attachments/860252098/fim-mini.png?version=1&modificationDate=1724770157420&api=v2)   

**Fim**
Representa o fim do processo, onde o fluxo termina e a solicitação é finalizada.

![](/download/attachments/860252098/anota%C3%A7%C3%A3o-mini.png?version=1&modificationDate=1758887299487&api=v2)   

**Anotação**
Permite adicionar comentários e explicações no diagrama do processo.

![](/download/attachments/860252098/fluxos-mini.png?version=1&modificationDate=1724770355850&api=v2)   

**Fluxos**
Representam as direções para onde a solicitação deve seguir conforme as etapas vão sendo concluídas.

Fique atento!

Esta documentação é válida a partir da atualização **Voyager (2.0)**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
