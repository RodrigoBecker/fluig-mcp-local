# MOB - Como visualizar widgets em comunidades no Fluig Mobile?

# Índice

# Plataforma

**Produto:** Fluig Mobile

# Ocorrência

Na página da comunidade tenho um widget configurado para ser exibido no Fluig Mobile. Quando eu acesso a comunidade no aplicativo mobile o widget não aparece. Tenho que fazer mais alguma configuração?

# Solução

No Android, quando você acessa uma comunidade que possui widgets, é exibida na tela da comunidade um link para o conteúdo adicional, ou seja, as widgets.

Já no iOS você precisa tocar em **Conteúdo Adicional** para visualizar as widgets. Essa opção fica no menu da lateral direita da tela quando você desliza para a esquerda.
