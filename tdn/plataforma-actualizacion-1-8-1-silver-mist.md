¡Mantenga actualizado su License Server!

A partir de la versión **Silver Mist 1.8.1**, para garantizar un correcto control de las licencias, es necesario que License Server esté utilizando la versión **3.2.0** o superior. Si License Server está utilizando una versión inferior, Fluig entrará en modo demo, **no permitiendo el acceso a los usuarios**.

Desactivación de Universal Analytics

Como se comunicó en el portal del cliente el día (04/04/2023), Google deshabilitará  Universal Analytics el **01** **de julio de 2023** y será reemplazado por **Google Analytics 4**. Esta desactivación provocará que los datos de acceso a la Plataforma TOTVS Fluig dejarán de ser recabados por Google Analytics.

Para seguir utilizando Google Analytics en Fluig, se debe crear y configurar la etiqueta de configuración de Google Analytics 4 en la Plataforma TOTVS Fluig  

Estén atentos: recomendamos configurar la nueva etiqueta antes de la fecha límite de desactivación. [**Haga clic aquí**](https://tdn.totvs.com/x/2GMNLw) y vea cómo realizar la configuración. 

- Consulte las novedades que ponemos a su disposición en el [**portal de clientes**](https://tdn.totvs.com/x/3BPyMw#NOT%C3%8DCIAS-analytics).

Versión mínima para la actualización de la plataforma

El proceso de actualización para la versión 1.8.1 de Fluig, requiere que la plataforma tenga la versión **1.7.1 o superior**. Si su entorno tiene una versión anterior, es necesario realizar el proceso de actualización a la versión 1.7.1 y luego actualizar Fluig a la versión 1.8.1.

## WCM

---

**¿Desea crear páginas de una manera más práctica?**

Con el nuevo creador de páginas es mucho más fácil crear páginas en TOTVS Fluig, para que sus portales estén listos para poder visualizarlos en cualquier dispositivo, ya sea computadoras, celulares y tabletas.

Desarrollamos un diseño completamente modernizado y más limpio, para que la creación y gestión de páginas sea cada vez más práctica e intuitiva. ¡Consulte las novedades a continuación! 

**Haga clic, arrastre y suelte**

Los *widgets* ahora están disponibles en el menú lateral del creador, organizados por categorías. Para seleccionar un *widget*, solo debe hacer clic y arrastrarlo a los slots de diseño en el área del creador. 

Cuando arrastra un *widget* a un *slot* es posible notar una marca azul que indica la posición que ocupará el *widget*, de esta manera el movimiento de *widgets* entre *slots* está mucho más simplificado.

Además, el menú se puede retirar para aprovechar al máximo el área del creador. Para agregar nuevos *widgets*, solo debe hacer clic en un *slot* vacío para abrir el menú nuevamente.

![](/download/attachments/750388765/Construtor%20de%20p%C3%A1ginas%20ES.gif?version=1&modificationDate=1683305616587&api=v2)

**Layouts****responsivos**

Algunos *layouts*se han reestructurado para cumplir con los criterios de capacidad de respuesta. Al crear una página, se podrá identificar la etiqueta **Layout responsivo** y cuando se utiliza en la página, significa que el contenido se adaptará a diferentes tamaños de pantalla y dispositivos móviles.

Pero recuerde que para que la experiencia de respuesta sea satisfactoria todos los *widgets* agregados a la página también deben ser responsivos.

Para los clientes que tienen desarrollo de layouts, les recomendamos validar algunas propiedades nuevas para asegurarse de que el layout esté escrito de manera responsiva o que el nuevo creador de páginas se cargue correctamente. Comprenda mejor [**aquí**](https://academy.fluig.com/theme/totvs_fluig_academy/landpage.php?course=72).

**ES6 en TOTVS Fluig Plataforma**

A partir de esta versión es posible desarrollar widgets usando [ES6](https://www.w3schools.com/js/js_es6.asp) que es una nueva versión de JavaScript con el fin de modernizar la plataforma.

En las versiones anteriores usábamos Yui Compressor Maven Plugin pero no es compatible con ES6+. En el desarrollo de formularios, nada se vio afectado. Los formularios no pasan por el mismo proceso de compilación que los widgets.

## Arquitectura

---

**Más seguridad y rendimiento en Fluig**

En esta versión aprobamos la versión de MySQL 8. Con esta acción se busca brindar mayor seguridad, estabilidad y desempeño a la Plataforma TOTVS Fluig. Teniendo en cuenta que la versión actual aprobada por la plataforma (MySQL 5.7) ya no será compatible con el propio proveedor del sistema el **octubre de 2023**. Actualice su plataforma para asegurarse todos los beneficios de esta nueva versión.

Para conocer más detalles, acceda a la documentación oficial de MySQL [**aquí**](https://endoflife.date/mysql).

**ATENCIÓN:** La versión MySQL 8 requiere algunas configuraciones iniciales que solo se pueden realizar durante la instalación. Por eso es muy importante que la actualización la haga un especialista en bases de datos.

Al actualizar la base de datos a MySQL 8 también se debe actualizar el driver de conexión JDBC "MySQL Connector/J". Por razones legales, no se permite que el driver esté disponible en la instalación de TOTVS Fluig, por lo tanto el proceso se debe realizar manualmente.

Verifique las recomendaciones e instrucciones sobre cómo realizar la [**Configuración de la base de datos MySQL**](https://tdn.totvs.com/x/_ofYCg).

Además, certificamos los sistemas operativos **Oracle Linux** y **Red Hat Enterprise Linux** en la versión **8.7**.

## Correcciones

- Corrección realizada para que al finalizar una evaluación vinculada a una capacitación toda la información se presente correctamente.
- Corrección realizada para que solo muestre una opción o se permita la creación de subprocesos incluso con un flujo automático configurado.
- Corrección realizada para que los usuarios que posean estado bloqueado no puedan iniciar solicitudes en un proceso.
- Ajuste realizado para que se muestre correctamente el mensaje al eliminar un anexo que fue agregado por otro usuario.
- Corrección realizada para que sea posible desactivar correctamente el bloque de Clickjacking en los parámetros de la plataforma.
- Validación implementada que evita SQLinjections de tipo based time en las consultas de API de dataset.
- Corrección realizada para que un documento compartido externamente ya no esté disponible para acceder después de su eliminación.
- Corrección realizada para que en el centro de diagnóstico solo se muestren los procesos activos.
- Ajuste realizado para que sea posible eliminar un proceso que no tenga vínculo con el proceso padre y que no tenga solicitudes iniciadas. Ajuste realizado también en los mensajes presentados.
- Corrección realizada para que cuando se realice una publicación la plataforma busque correctamente otras comunidades para replicar la publicación.
- Ajustes realizados en la visualización del select, al enviar los datos a mover una actividad para que no se produzca duplicidad en los valores en el formdata.
- Corrección realizada para que sea posible crear correctamente un artículo en una comunidad, en la que se habilita la generación de thumbnail en el registro de la empresa.
- Corrección realizada para que sea posible publicar correctamente un documento como adjunto en las solicitudes.
- Corrección realizada para que el usuario que mueve la solicitud no tenga permiso en el papel configurado en la actividad, se mostrará un mensaje evitando el movimiento y la pérdida de la relación.
- Corrección realizada para que al cambiar el huso horario se mantenga correctamente la fecha de los documentos.
- Corrección realizada para que sea posible acceder al archivo adjunto al proceso cuando el proceso está utilizando eventos de proceso y datasets.
- Corrección realizada para que al ejecutar el flujo automático relacionado con las tareas atrasadas, el correo electrónico de notificación se envíe correctamente.
- Corrección realizada para que la barra de desplazamiento del documento se muestre correctamente en la pantalla de adjuntos de la solicitud.
- Validación implementada para identificar al usuario autenticado en la plataforma o al usuario administrador, haciendo que el envío de la URL del documento a través de API se realice correctamente al utilizar el flujo automático.
- Corrección realizada para que sea posible trasladar una solicitud al administrador de procesos cuando esta se asigna por campos de formulario.
- Inconsistencia corregida en la transferencia de pendientes donde había documentos con dos o más niveles de aprobación.
- Corrección realizada para ajustar el comportamiento de las reglas de formulario a continuación:

- Al eliminar una actividad que tiene reglas de formulario, las reglas también se eliminan. 
- Al filtrar las reglas de formulario por actividad para que se puedan ver todas las reglas correctamente.

- Corrección realizada para que al habilitar la opción "Utilizar logotipo de la empresa en el formulario" en la configuración del formulario del proceso, se muestre correctamente el logotipo en el formulario.
- Corrección realizada para que sea posible agregar widgets en el layout Comunicativo con un usuario común que tenga permiso para editar la página.
- Corrección realizada para que el contenido de la pestaña de la comunidad se muestre correctamente al seleccionar un archivo para su publicación.
