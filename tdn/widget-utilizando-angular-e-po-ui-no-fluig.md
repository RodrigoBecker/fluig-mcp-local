# Widget utilizando Angular e PO UI no Fluig

# Índice

Nesta documentação contém um exemplo de construção de widget utilizando o framework Angular, que também pode ser usada com frameworks modernos. Essa é uma **versão beta** liberada apenas para parceiros de desenvolvimento Fluig. Caso encontre algum problema, orientamos reportar para a equipe de Parceiros do Fluig.

Este exemplo foi testado com o framework Angular, porém pode ser seguida a mesma estratégia com o React e Vue.js

# Widget utilizando Angular e PO UI no Fluig

---

O objetivo desse documento é apresentar uma **técnica** de como adicionar uma aplicação com Angular + PO UI no Fluig.

Essa técnica consiste em criar uma *widget* e adicionar uma aplicação Angular dentro dela. Posteriormente podemos incluir essa *widget* na edição ou criação de uma página na plataforma ajustando as necessidades do seu negócio e para o seu dia a dia.  Também é possível criar qualquer tipo de *widget* utilizando essa técnica para fins específicos da empresa, existem duas maneiras de se criar uma *widget*, através da [documentação oficial](https://tdn.totvs.com/x/jSiDC) (recomendamos essa opção) ou através do plugin de desenvolvimento Eclipse no [Fluig Studio](https://tdn.totvs.com/x/oxVbB).

# Pré-requisitos

---

- Node 10.15.x
- NPM 6.4.x
- Angular CLI: 7.1.3
- Java 7 ou superior
- Maven 3.6.0
