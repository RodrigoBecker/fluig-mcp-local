# Platform ❙ Control panel

![](/download/attachments/236429905/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1765287734307&api=v2)

---

The Control Panel allows only company administrators to access the platform’s configuration features. ![](/plugins/servlet/confluence/placeholder/unknown-macro?name=tooltip&locale=en_US&version=2)

Control Panel groups:

- [People](https://tdn.totvs.com/x/ijKAGg): it has features to manage the platform, such as registration of users, groups, roles, permissions and communities;

- [Technical parameters](https://tdn.totvs.com/x/kjKAGg): administrative features to manage platform operation, such as icon registration, parameters, indexation and process image generator;

- [Customization](https://tdn.totvs.com/x/mTKAGg): administrative features to manage platform customization, such as theme, document types and customized fields.

- [Development](https://tdn.totvs.com/x/jDKAGg): administrative features responsible for platform communication, such as adapters, datasets, services and servers;

- [Security and access](https://tdn.totvs.com/x/lTKAGg): administrative features to ensure superior platform security, such as log control, usage statistics, and controlled copy log.

- [Applications](https://tdn.totvs.com/x/jjKAGg): administrative features enabled by default. You may enable these and use them as needed. This group has features such as digital signature, collaborative editing, and component center.

The company’s admin users (admin role) have access to all features. Other users can only access those to which they were granted access based on their [permission](/pages/viewpage.action?pageId=236429985) settings.

Need help?

Access the help center by clicking the icon ![](/download/attachments/236429905/ajuda-tdn.png?version=1&modificationDate=1765287914317&api=v2), located in the upper right corner of the Control panel menu pages, for specific information on this feature and links to related documentation. [Learn more.](/pages/viewpage.action?pageId=244422903)

### My last accesses

---

The control panel has a last access feature that shows the last features accessed in the Control Panel, and displays up to eight (8) items accessed recently by the user. Resources are sorted by access order (i.e. the last accessed resource is always the first shown in the list).
Latest items are stored in the control panel through browser cookies. Last access data is not shown if the user logs into TOTVS Fluig Platform on another desktop or browser.

### My links

---

The My Links group is shown in the Control Panel only when the user has custom pages in the platform. All pages created by the user are centralized in a single group with the remaining features.

Attention!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
