# Plataforma ❙ WebDAV

# Conceito WebDAV

---

O WebDAV (*Web-based distributed authoring and versioning*) é uma extensão do protocolo HTTP (*Hypertext Transfer Protocol*), que permite que os usuários editem e gerenciem conjuntamente arquivos em servidores da Web remotos.

A plataforma utiliza o WebDAV para efetuar a edição de conteúdo dos arquivos através dos softwares que são compatíveis com esse protocolo, como o Microsoft Word.

Fique atento!

Esta documentação é válida a partir da atualização **Voyager (2.0)**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
