# Identity | Como preencher o campo ADSync Service Server no SmartSync?

**Dúvida**

Como preencher o campo ADSync Service Server no SmartSync?

**Solução**

O endereço correto para utilizar na configuração do SmartSync é [https://app.fluigidentity.com/adsync.](https://app.fluigidentity.com/adsync.) Este endereço vem preenchido por padrão na aplicação.

Porém, caso o ambiente utilizado no Identity seja de homologação (customerfi.com) o campo ADSync Service Server deve ser preenchido com [https://app.customerfi.com/adsync](https://app.customerfi.com/adsync).
