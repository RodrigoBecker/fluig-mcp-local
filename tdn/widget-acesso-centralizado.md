# Widget Acesso centralizado

O *widget* de Acesso centralizado permite que sistemas externos ao TOTVS Fluig Plataforma, cadastrados no Fluig Identity, possam ser executados a partir de um acesso rápido. Ou seja, ao clicar em um item do *widget* de acesso centralizado, o sistema externo configurado será executado.

Esta execução não ocorre dentro da plataforma Fluig. A plataforma apenas fará a chamada para execução do sistema externo, abrindo uma nova aba no navegador (caso seja um sistema *web*) ou abrindo o executável do ERP (caso o sistema seja *desktop*).

A autenticação no sistema é feita automaticamente, utilizando o usuário e empresa selecionados no Fluig.

Ainda no *widget* de acesso centralizado é possível favoritar os itens mais utilizados e buscar o cadastro desejado informando o título do mesmo no campo de busca.
