# ESB - É possível instalar o TOTVS ESB no linux em modo caractere?

# Índice

# Plataforma

**Produto:** TOTVS ESB

# Ocorrência

É possível instalar o TOTVS ESB no linux em modo caractere?

# Solução

O TOTVS ESB não possui instalador em modo caractere. É possível fazer uma instalação em algum ambiente linux em modo gráfico, zipar essa instalação e copiar para o seu ambiente em modo caractere que funcionará normalmente.
