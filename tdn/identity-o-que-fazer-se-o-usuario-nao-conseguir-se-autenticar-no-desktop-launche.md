# Identity | O que fazer se o usuário não conseguir se autenticar no Desktop Launcher?

**Dúvida**

O que fazer se o usuário não conseguir se autenticar no Desktop Launcher?

**Solução**

Uma possível solução para esse problema é alterar o endereço de conexão com o Identity. No Desktop Launcher, acesse a opção Advanced Settings e altere os valores dos campos abaixo:

- **SSOProfileStoreRestUrl:** de "https://meufluig.fluigidentity.com" para "http://meufluig.fluigidentity.com";

- **UserStoreRestUrl:** de "https://meufluig.fluigidentity.com" para "http://meufluig.fluigidentity.com".
