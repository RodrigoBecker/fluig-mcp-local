# BPM 025 - Como criar tarefas para grupos no processo Listar Tarefas?

# Índice

# Plataforma

**Produto:  **fluig

**Versão: **Todas as versões

# Ocorrência

Estou tentando criar uma tarefa para um grupo de usuários, porém no campo 'Responsável' do processo Listar Tarefas, é possível inserir apenas um responsável. Ao tentar incluir o segundo o sistema não salva o usuário escolhido:

![](/download/attachments/235320768/image2016-4-5%2015%3A41%3A7.png?version=1&modificationDate=1459878626000&api=v2)

# Solução

O processo Listar Tarefas não permite selecionar um grupo de usuários para ser responsável por cada tarefa. É possível escolher apenas um responsável.

 Apenas para complemento, o Listar Tarefas é um processo padrão do fluig utilizado para organizar atividades a serem desempenhadas rotineiramente, permitindo informar qual tarefa será desempenhada, por quem e qual o prazo para conclusão.

Para atender esta necessidade, é possível modificar o Listar Tarefas ou até mesmo criar um novo processo, de modo que atenda as particularidades de cada cliente. Por exemplo, o fluig permite definir um mecanismo de atribuição da atividade por Grupo, para um Grupo, por Usuário, etc ou poderá utilizar o recurso de Atividade Conjunta. 

Para criar, alterar fluxos ou efetuar desenvolvimentos sobre a plataforma fluig, disponibilizamos o plugin fluig Designer do Studio. Segue alguns recursos disponíveis no mesmo: cadastro de servidor fluig, a criação de projeto fluig, importação e exportação de artefatos, criação de processos workflow, formulários, eventos globais, datasets e serviços

Para obter mais detalhes sobre como efetuar estes desenvolvimentos, recomendo que verifique os treinamentos Studio I, II, III, IV e V disponíveis junto aos treinamentos do fluig. Caso não tenha acesso, será necessário entrar em contato com seu ESN (Executivo de Soluções de Negócio).
