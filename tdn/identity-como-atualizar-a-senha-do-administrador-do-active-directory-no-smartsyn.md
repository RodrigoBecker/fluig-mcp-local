# Identity | Como atualizar a senha do administrador do Active Directory no SmartSync?

**Dúvida**

Como atualizar a senha do administrador do Active Directory no SmartSync?

**Solução**

Para atualizar a senha do administrador do Active Directory no SmartSync, siga os procedimentos abaixo:

**01.** Abrir o SmartSync e acionar **Configure**.

**02.** Selecionar a aba **Domain LDAP**.

**03.** Clicar duas vezes sobre o nome do Active Directory para abrir a janela de edição.

**04.** No campo **Password**, informar a nova senha do administrador do AD.

**05.** Acionar **Save**.

**06.** Acionar **Save** novamente.

**07.** Parar o serviço do SmartSync em **Stop Service**.

**08.** Iniciar novamente o serviço do SmartSync em **Start Service**.
