# Atualização 1.1.3

Confira abaixo as novidades na atualização 1.1.3 do Fluig:

# Administração

**Praticidade no cadastro de usuários**

Agora é possível já no momento da inclusão de um novo usuário relacioná-lo diretamente no seu respectivo papel.

**Cadastro de Feriados Recorrentes**

Ao cadastrar um feriado recorrente, informe somente o dia e o mês. Não é mais necessário informar o ano.

# API

**Web service ECMDocumentService**

Nesta atualização do Fluig, foi corrigido o método "createDocumentWithApprovementLevels" para que seja possível utilizar a *tag* "*levels*". Para mais informações sobre este método, [clique aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=73084007#UtilizaçãodeWebservices-ECMDocumentService).

# BPM

**Uso de campos desabilitados em formulários**

Com esta atualização do Fluig, formulários que possuem campos do tipo *radio** button* desabilitados são salvos corretamente.

**Visualize a descrição principal dos formulários na Central de Tarefas**

Agora os agrupadores "Tarefas a concluir" e "Minhas Solicitações" da Central de Tarefas passam a exibir uma coluna chamada "Identificador", com o valor do campo que foi selecionado como descrição principal dos formulários.
 Ao filtrar um processo, a coluna "Identificador" é automaticamente renomeada para o nome do campo que foi selecionado como descrição principal dos formulários, como por exemplo: "Nome da Empresa".
![](/download/attachments/107940580/central.png?version=1&modificationDate=1388084287000&api=v2)

# ECM

**Busca avançada**

A busca avançada foi aprimorada, para que os resultados de busca considerem todos os filtros informados.

# Social

**Melhor desempenho na exibição de publicações na timeline**

Visando deixar o carregamento da timeline mais rápido, quando as imagens publicadas forem maior que 5MB as mesmas não são renderizadas e será gerado um link para sua visualização.
