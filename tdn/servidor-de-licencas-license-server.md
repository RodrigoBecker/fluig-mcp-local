# Servidor de Licenças (License Server)

# Índice

# Visão geral

---

License Server é um recurso computacional que tem como objetivo realizar o controle das licenças de uso dos softwares e aplicações. Através deste recurso é possível prover de forma eficiente e segura as licenças e liberações de utilização de módulos e/ou funcionalidades das aplicações, em conformidade com o contrato firmado entre o cliente e o TOTVS Fluig.

## Teste de conexão

---

Para verificar se o servidor de licenças está ativo, existem duas formas: pelo serviço do License Server ou através do teste de conexão na plataforma.

Para fazer o teste de conexão, acesse a plataforma com o usuário wcmadmin e acione **Configurações do sistema**, na aba **Parâmetros da plataforma**. No trecho de configuração **Servidor de licenças**** **há um botão que possibilita a realização do teste de conexão.
