# IDE - Os grupos do Identity podem ser importados para a plataforma ou vice-versa?

# Índice

# Plataforma

**Produto:** TOTVS Fluig Plataforma integrado ao TOTVS Identity

# Ocorrência

Os grupos do Identity podem ser importados para a plataforma ou vice-versa?

# Solução

**Não.** Os grupos criados na plataforma e no Identity são independentes e não existe integração entre eles nas duas ferramentas. Os únicos grupos que podem ser importados para o Identity são aqueles criados no Active Directory.
