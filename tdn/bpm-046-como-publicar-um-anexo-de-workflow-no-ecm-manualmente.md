# BPM 046 - Como publicar um anexo de workflow no ECM manualmente?

# Índice

# Plataforma

**Produto:  **fluig

**Versão:** todas

# Ocorrência

Como publicar um anexo de workflow no ECM manualmente?

# Solução

Quando um documento é anexado a uma solicitação com a opção **Carregar arquivos** ele não é automaticamente publicado no ECM. 

Siga os passo abaixo para realizar a publicação manualmente.

- [Passo 1](#)
- [Passo 2](#)
- [Passo 3](#)

 - O usuário responsável pela atividade deve acessar a solicitação na **Central de Tarefas** e acessar a aba **Anexos**;

 - Ao lado dos arquivos anexados existe um menu definido pelo ícone ![](/download/attachments/243008103/image2016-7-4%2014%3A55%3A56.png?version=1&modificationDate=1467718643000&api=v2)

 - Para publicar o documento no ECM, acione a opção **Publicar**.

![](/download/attachments/243008103/imagem1.png?version=4&modificationDate=1553532435083&api=v2)

**Figura 1 - Publicar arquivo anexado ao workflow**

 - Na tela seguinte selecione o diretório onde o arquivo será salvo;

![](/download/attachments/243008103/imagem2.png?version=1&modificationDate=1467719101000&api=v2)

**Figura 2 - Selecionar diretório**

 - Defina as propriedades do novo documento como **Descrição**, **Informações Gerais** e **Segurança**;

 - Acione Confirmar para finalizar.

![](/download/attachments/243008103/imagem3.png?version=1&modificationDate=1467719890000&api=v2)

**Figura 3 - Definir as propriedades do novo documento**
