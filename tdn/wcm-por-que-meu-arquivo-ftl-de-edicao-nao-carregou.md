# WCM - Por que meu arquivo FTL de edição não carregou?

# Índice

# Plataforma

**Produto:**TOTVS Fluig Plataforma

# Ocorrência

Por que meu arquivo FTL de edição não carregou?

# Solução

Verifique no [arquivo application.info](https://tdn.totvs.com/display/fluig/Arquivo+application.info) se existe a propriedade **edit.file={arquivo-edit.ftl}**. Na atual estrutura do Studio é esperado que propriedade seja algo como o exemplo abaixo:

- **edit.file=minhawidgetedit.ftl**
