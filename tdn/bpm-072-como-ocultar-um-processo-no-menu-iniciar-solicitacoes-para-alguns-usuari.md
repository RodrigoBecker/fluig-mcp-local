# BPM 072 - Como ocultar um processo no menu "Iniciar Solicitações" para alguns usuários?

# Índice

# Plataforma

**Produto:  **fluig

**Versão:** 1.5

# Ocorrência

Como faço para que outros usuários não vejam a solicitação no Iniciar Solicitações?

![](/download/attachments/266967409/1.png?version=1&modificationDate=1553533214370&api=v2)

# Solução

Deve selecionar o mecanismo de atribuição da atividade inicial de acordo com os usuários que poderão visualizar a solicitação.

Veja o passo a passo de como fazer:

- [Passo 1](#)
- [Passo 2](#)
- [Passo 3](#)
- [Passo 4](#)

 - Acesse como administrador e em **Configurar processos** selecione o processo que deseja. Clique em **Editar**.

![](/download/attachments/266967409/2.png?version=1&modificationDate=1553533249790&api=v2)

  - Na atividade inicial, clique na engrenagem para editar. No campo mecanismo de atribuição selecione a atribuição que lhe for mais adequada.

![](/download/attachments/266967409/3.png?version=1&modificationDate=1475519391000&api=v2)

![](/download/attachments/266967409/4.png?version=1&modificationDate=1475519391000&api=v2)

A seleção será de acordo com o mecanismo que escolher. Se for por grupo, serão listados os grupos para selecionar. O mesmo vale para papel e usuário.

 - Selecione o usuário que poderá inicializar a solicitação. Então é só confirmar e liberar a versão.

![](/download/attachments/266967409/5.png?version=1&modificationDate=1475519391000&api=v2)

****

 - Assim o usuário que não foi atribuído no mecanismo não irá ver o processo na tela de iniciar solicitações.

![](/download/attachments/266967409/6.png?version=1&modificationDate=1553533290773&api=v2)
