# Identity | Política de senha do Active Directory

# Falando de política de senha...

---

A política de senha consiste em um conjunto de regras e configurações definidas pelo administrador da empresa conforme as necessidades e prioridades de segurança da companhia.

É possível permitir que o usuário altere a senha do Active Directory diretamente pelo TOTVS Identity e exibir os requisitos de segurança da senha do AD (por exemplo, quantidade de caracteres, exigência de letras maiúsculas e minúsculas).

![](/download/attachments/273992622/Pol%C3%ADtica%20de%20senha.png?version=1&modificationDate=1584465876277&api=v2)

## Permitir alteração da senha do Active Directory pelo Identity

---

**01. **Acionar o ícone **Configurações **no canto superior direito.

**02.** Selecionar a opção **Active Directory**.

**03.** Na seção **Política de senha,**assinalar **Permitir aos usuários trocarem sua senha do Active Directory pelo Identity**.

Caso habilitada, a alteração da senha do Active Directory poderá ser realizada na página [Meu Perfil](/pages/viewpage.action?pageId=280746624) do usuário.

## Exibir requisitos de senha do Active Directory para o usuário

---

**01. **Acionar o ícone **Configurações **no canto superior direito.

**02.** Selecionar a opção **Active Directory**.

**03.** Na seção **Política de senha**, definir se os requisitos de senha do Active Directory configurados pelo administrador devem ser apresentados para os usuários durante a definição/alteração da senha.

O Identity é responsável apenas por mostrar os requisitos de senha. A configuração dos requisitos mínimos deverá ser realizada no Active Directory, que também é responsável por validar a conformidade da senha.

**04.** Informar os requisitos mínimos de senha.****

**05.** Acionar **Salvar**.
