# My Fluig ❙ Como funciona o idioma dentro do aplicativo?

---

No aplicativo My Fluig damos suporte a três idiomas distintos que são o Português, o Espanhol e o Inglês.

Nos casos onde o aplicativo for baixado para um dispositivo que utiliza o sistema operacional Android, a seleção de idioma segue a seguinte regra:

Se você utiliza seu dispositivo em um dos três idiomas suportados, o aplicativo respeitará esse idioma e será apresentado utilizando o idioma configurado. 

**Exemplo**: O dispositivo que utiliza o idioma Espanhol terá esse mesmo idioma apresentado no aplicativo, pois é um idioma suportado. 

Já nos casos onde o dispositivo utiliza um idioma diferente dos suportados, como por exemplo o Mandarim, o aplicativo será apresentado no seu idioma definido como padrão, que é o Inglês.
