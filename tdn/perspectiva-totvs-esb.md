# Perspectiva TOTVS ESB

A perspectiva TOTVS ESB pode ser utilizada através do Fluig Studio ou Eclipse para configurar os parâmetros do servidor Fluig ESB e para a criação de diagramas definindo fluxo das informações trafegadas.

A perspectiva TOTVS ESB pode ser acessada através do menu principal **Window >****Open Perspective** **> TOTVS ESB**.

Para a devida utilização da perspectiva TOTVS ESB, é necessário que o processador de mensagens Fluig ESB esteja em execução. Vide o item [Execução do Fluig ESB](/pages/viewpage.action?pageId=6066527) para inicar o serviço.

# TOTVS ESB

---

A perspectiva TOTVS ESB tem como finalidade realizar configurações específicas para cada servidor Fluig ESB, além da montagem e configurações dos diagramas.

Detalhes como portas, configurações do monitor, logs e memória do servidor ESB são realizadas através dessa perspectiva. Ainda permite o gerenciamento de vários servidores ESB localizados remotamente.

Através de componentes especializados pode-se configurar o fluxo de mensagens dentro do Fluig ESB e realizar enviar essas instruções para o servidor Fluig ESB.
