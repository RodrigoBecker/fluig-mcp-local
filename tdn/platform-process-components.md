# Platform ❙ Process components

Consult the correct documentation:

This documentation refers to the new process editor of the platform. If you are using the current process editor, access [Configure activities and flows](/pages/viewpage.action?pageId=236429448). 

LANGUAGE

![](/download/attachments/979502312/diagrama.png?version=1&modificationDate=1755888259597&api=v2)

---

The components are the graphical representations of the stages of a process that you can use to build your diagram, where you can see what happens to the request at each stage, as well as the directions it can take as the stages are completed.

Each component has its own characteristics and configurations, which you can define in accordance with what you expect for each stage, in each process, for each business.

Click each component for more details.

![](/download/attachments/979502312/in%C3%ADcio-mini.png?version=1&modificationDate=1755888256660&api=v2)  

**Start**Represents the initial stage of the process, where the flow begins and the request is initiated.

![](/download/attachments/979502312/atividade-mini.png?version=1&modificationDate=1755888254657&api=v2)   

[**Activity**](/pages/viewpage.action?pageId=979031748)
Represents each stage of the process that the request will go through.

![](/download/attachments/979502312/subprocesso-mini.png?version=1&modificationDate=1755888260377&api=v2)   

[**Subprocess**](/pages/viewpage.action?pageId=979019129)
Represents another process within the main process.

![](/download/attachments/979502312/paralelo-mini.png?version=1&modificationDate=1755888257223&api=v2)   

**Parallel**
Represents the start of parallel stages, where the main flow splits into two or more stages.

![](/download/attachments/979502312/join-mini.png?version=1&modificationDate=1755888256837&api=v2)   

**Join**
Represents the end of parallel stages, resuming the main flow.

![](/download/attachments/979502312/exclusivo-mini.png?version=1&modificationDate=1755888257727&api=v2)   

**Exclusive**Represents the mechanism that directs the request to the flow it should follow, depending on the result obtained.

![](/download/attachments/979502312/cancelamento-mini.png?version=1&modificationDate=1755888254860&api=v2)   

**Cancellation**
Represents the cancellation of the request.

![](/download/attachments/979502312/fim-mini.png?version=1&modificationDate=1755888255407&api=v2)   

**End**
Represents the end of the process, where the flow terminates and the request is finalized.

![](/download/attachments/979502312/fluxos-mini.png?version=1&modificationDate=1755888257000&api=v2)   

**Flows**
Represent the directions that the request should follow as the stages are completed.

Attention!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
