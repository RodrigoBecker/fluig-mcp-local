# BPM 095 - Como configurar corretamente o widget de Gráfico de processos e tarefas?

# Plataforma

**Produto**:  Fluig

**Versão:** 1.6.2

A seguir, serão mostrados os templates existentes no gráfico de processos e tarefas e por fim, uma breve descrição dos campos do gráfico que são configurados de acordo com a necessidade de cada cliente ou usuário.

# Estado das atividades

O template  de “Estados das atividades” permite uma análise mais aprofundada das atividades de um ou mais processos. Com ela é possível verificar quais são as tarefas que mais atrasam e quem é o responsável sobre elas.

![](/download/attachments/307840470/doc2.PNG?version=1&modificationDate=1508502867000&api=v2)

# Carga de solicitações

Com o template "Carga de Solicitações" é possível verificar como está o andamento das solicitções agrupadas por processo, agilizando e simplificando o modo de visualizar as solicitações no prazo, em alerta e as atrasadas.

![](/download/attachments/307840470/doc3.PNG?version=1&modificationDate=1508502867000&api=v2)

# Tarefas próximas do vencimento

O template "Tarefas próximas do vencimento” monta um calendário com as datas de finalização e as solicitações cujas tarefas estão próximas do vencimento, tornando fácil o controle das tarefas que irão atrasar.

![](/download/attachments/307840470/doc4.PNG?version=1&modificationDate=1508502867000&api=v2)

# Solicitações próximas do vencimento

O template "Solicitações próximas do vencimento” trabalha de forma semelhante ao template de "Tarefas próximas do vencimento" , também gerando um calendário com as datas de finalização, porém, está não exibe datas próximas do vencimento das tarefas e sim, prazo das solicitações que estão para vencer.

![](/download/attachments/307840470/doc5.PNG?version=1&modificationDate=1508502864000&api=v2)

# Estado das solicitações

Utilizando o template “Estados das solicitações” permite que seja feita uma análise mais aprofundada das solicitações de um ou mais processos. Com ela é possível é verificar quais são as solicitações que mais atrasam, permitindo também, verificar quem é o responsável sobre elas.

![](/download/attachments/307840470/doc6.PNG?version=1&modificationDate=1508502863000&api=v2)

# Dados a serem preenchidos

| Nome | Descrição |
| --- | --- |
| Nome | Descrição |
| Título do gráfico | Permite inserir um nome para o gráfico. |
| Template | Permite selecionar um dos cinco templates disponíveis para visualização. |
| Fonte | Na sessão Fonte, se tem a possibilidade de informar qual o tipo de dado que será buscado na plataforma, sendo as Solicitações ou Tarefas, também permite escolher se quer listar solicitações/atividades sob gerência, requisitante ou que é responsável, possibilitando agrupar por status, processo ou data de vencimento. |
| Filtros | Diversos filtros para deixar o gráfico mais flexivel, nessa sessão, é possível filtrar por localização do usuário requisitando e/ou responsável, qual o processo, status e até mesmo por campo de formulário do processo quando disponível. |
| Gráfico | Permite configurar o tamanho(Pequeno, médio ou grande) e o tipo do gráfico(Pizza, Rosca, Radar, Barras horizontais ou Barras verticais), conforme sua necessidade. Além da possibilidade de informar uma mensagem de recebimento e adicionar um filtro global para filtrar mais de um gráfico na página. |
