# Dimensionamento

# Objetivo

O processo de dimensionamento de infraestrutura, também conhecido como *sizing*, tem o objetivo de propor a melhor infraestrutura para o cliente a partir de suas necessidades atuais e futuras.

Uma infraestrutura inadequada pode causar considerável perda de performance quando houver grande número de acesso simultâneo na aplicação, pois o ambiente não irá oferecer escalabilidade limitando o uso da aplicação. Portanto, é de extrema importância escolher adequadamente a infraestrutura e dimensionamento para que se possa usufruir todos os recursos do TOTVS Fluig Plataforma de forma eficiente.
