# EIC0005_Parâmetros_de_Integração_SIGAEICxSIGAFIN

# Assunto

| Produto: | Easy Import Control - SIGAEIC |
| --- | --- |
| Versões: | P11 e 12 |
| Ocorrência: | Parâmetros de Integração SIGAEIC x SIGAFIN |
| Ambiente: | CodeBase - DbAccess |
| Passo a passo: | Os parâmetros definem como o sistema irá tratar as movimentações dos processos de Importação.Serão apresentados os parâmetros necessários para gerar títulos no Financeiro dos processos do Easy Import Control.MV_EASY - Define se haverá ou não integração do módulo de Importação.MV_EASYFIN - Define se haverá integração do módulo de Importação com o Financeiro.MV_EASYFCA - Define se será gerado título provisório (PR) do câmbio quando há pagamento antecipado.MV_EASYFPO - Define se serão gerados títulos provisórios (PR) do valor do processo, das despesas e impostos na fase do PO.MV_EASYFDI - Define se serão gerados títulos provisórios (PRE) de Despesas e impostos na fase do Embarque.MV_PG_ANT - Define se o sistema gerará câmbio antecipados e títulos “PA” no Financeiro.MV_EIC0003 - Define se o título provisório do valor antecipado do processo será ou não excluído em casos de liquidação de pagamento antecipado.MV_COMPAUT - Define se será realizada a compensação automática no Financeiro do título INV contra o PALBL |
| Observações: |   |
