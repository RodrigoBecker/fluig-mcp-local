# MOB - Por que lista de tarefas aparece vazia no mobile?

# Índice

# Plataforma

**Produto: **Fluig Mobile

# Ocorrência

Ao acessar a lista de tarefas pendentes pelo mobile, nada aparece. No gráfico da Central de tarefas consta que existem tarefas pendentes e na web também.

# Causa

Essa inconsistência pode ser causada pelo cache do aplicativo mobile.

# Solução

Limpe os dados do aplicativo:

1. No Fluig Mobile, clique no menu (lado esquerdo superior)
2. No menu, clique no botão em formato de engrenagem ao lado do seu nome
3. Nesta tela (Configurações do Aplicativo), clique na última opção: "Limpar dados"
4. Após limpar os dados, volte à lista de Tarefas a concluir e deslize o dedo para baixo para recarregar a lista.
