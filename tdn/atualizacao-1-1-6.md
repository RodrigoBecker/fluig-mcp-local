# Atualização 1.1.6

Confira abaixo as novidades na atualização 1.1.6 do Fluig:

# Administração

**Usuários inativos não são considerados no consumo de licenças**
Nesta atualização, a validação de licenças irá contar apenas usuários ativos no sistema. Caso existam usuários desabilitados, estes não serão contabilizados no licenciamento do produto.

 **Regras ilimitadas para na definição de segurança de páginas**
Agora é é possível incluir quantas regras forem necessárias para definição de acesso a uma determinada página, de acordo com o perfil de usuário desejado.

# Analytics

**Aprimorado envio de dados para o Fluig Analytics**
Para o envio de dados para o Analytics nesta atualização do Fluig, é necessário a informar os parâmetros nos dados adicionais abaixo, no gerenciamento de empresas:

- E-mail: endereço de e-mail do Administrador do Fluig Analytics
- Senha: senha do endereço de e-mail informado.

![](/download/attachments/123602408/analytics.png?version=1&modificationDate=1392412005000&api=v2)

Para mais detalhes sobre o Fluig Analytics, [clique aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=107381593).

# API

Webservice **ECMDocumentService**Ao atualizar um documento via webservice era obrigatório informar o código do ícone do documento. Nesta atualização este parâmetro não é mais obrigatório. Quando não informado, o documento continuará com o ícone informado anteriormente. 

Para mais informações sobre Web services disponíveis no Fluig, [clique aqui](/pages/viewpage.action?pageId=73084007).

# Fluig Studio

**Armazenamento de informações do formulário em dataset – Tabelas do banco de dados**
Agora ao cadastrar um formulário e optar por salvar os dados em tabelas do banco de dados, informando um dataset é possível consultar os valores dos registros de formulários. 

# ECM

**Links de acesso à um documento externo**
O recurso de cópia de link estava disponível para os documentos externos, porém não era possível acessar o documento utilizando o link gerado. Com o Fluig 1.1.6. é possível acessar um documento externo através do link direto para o documento publicado.

****

**Central da tarefas otimizada para muitos responsáveis**
Nesta nova atualização do Fluig, a lista de atividades da Central de Tarefas foi otimizada para exibir todos os seus respectivos responsáveis. Além da opção de expandir a lista de responsáveis, é possível visualizar o nome completo dos responsáveis através de uma dica de contexto (*tooltip*).

![](/download/attachments/123602408/imagem1.png?version=1&modificationDate=1392402463000&api=v2) 

**Agilidade ao atribuir papéis à um usuário**
Ao editar um usuário e atribuir novos papéis, é possível utilizar o campo de busca e navegar por todos os papéis listados, para localizar o papel desejado.

 ![](/download/attachments/123602408/imagem2.png?version=1&modificationDate=1392402479000&api=v2) 

**Otimize os resultados de busca filtrando por campos customizados**
Agora é possível utilizar a busca avançada informando filtros para campos customizados, para obter melhores resultados de busca.

 ![](/download/attachments/123602408/imagem6.png?version=1&modificationDate=1392402557000&api=v2)

# BPM

**Deixe o desenho de seus processos mais bonitos!**Algumas atividades de processos workflows eram exibidas desalinhadas, onde os fluxos ligados a determinada atividade não eram posicionados corretamente. Nesta atualização do Fluig, as atividades são exibidas em seu tamanho correto e os fluxos de origem e destino são posicionados corretamente, deixando o desenho do processo ainda mais bonito.

**Transferir atividade para qualquer usuário**Em uma atividade sem mecanismo de atribuição configurado, é permitido transferi-la para qualquer usuário ativo no sistema, independentemente do mecanismo utilizado na atividade anterior.

![](/download/attachments/123602408/imagem3.png?version=1&modificationDate=1392402503000&api=v2) 

# Social

**Imagens de perfil de comunidades distintas por empresa**
A imagem de perfil das comunidades e de usuários agora podem ser utilizadas em ambiente multiempresa sem restrições. Onde comunidades com mesma descrição podem existir em empresas diferente e manter suas características individuais, como por exemplo, cada uma possuir sua própria foto de perfil.

**Visualização de posts, conteúdos com quebra de linha**
 Nesta atualização é possível criar publicações com quebras de linhas, sem perder a formatação ao efetuar a publicação.

![](/download/attachments/123602408/imagem4.png?version=1&modificationDate=1392402521000&api=v2)   

**Visualize mais de um link em uma publicação**Agora as publicações que contenham mais de um link serão exibidas corretamente, permitindo o acesso através de um clique.   ![](/download/attachments/123602408/imagem5.png?version=1&modificationDate=1392402542000&api=v2)
