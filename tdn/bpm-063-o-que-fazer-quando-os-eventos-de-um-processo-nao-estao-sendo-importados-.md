# BPM 063 - O que fazer quando os eventos de um processo não estão sendo importados do servidor fluig?

# Índice

# Plataforma

**Produto:**fluig Studio

**Versão:** 1.5.10

# Ocorrência

A importação de processos do fluig não está importando os *scripts* do processo

# Solução

Verificamos que o problema ocorreu devido ao tipo do projeto que foi criado no TDS/Eclipse.

Para o correto funcionamento do plugin fluig, recomendamos que todos os projetos sejam do tipo **Projeto fluig**. Na página [Criando um projeto fluig no Studio](https://tdn.totvs.com/x/UhgSCw) disponibilizamos o passo a passo.

Após realizarmos este procedimento, os scripts de processos foram importados corretamente.
