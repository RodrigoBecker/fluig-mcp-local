# SOC - Como extrair dados dos formulários publicados em comunidades?

# Índice

# Plataforma

**Produto:** TOTVS Fluig Plataforma

# Ocorrência

Qual é o procedimento para extrair os dados dos formulários publicados em uma comunidade?

# Solução

Acesse a comunidade e clique na aba **Formulários**, localize o formulário que deseja extrair os dados e clique na seta do lado superior direito, escolha a opção **Extrair relatório**, dessa forma o sistema fará o *download* do arquivo com os dados do formulário, e lançará uma notificação quando o arquivo estiver disponível.
