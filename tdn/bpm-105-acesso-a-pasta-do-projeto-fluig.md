# BPM 105 - Acesso à pasta do projeto fluig

# Índice

# Plataforma

**Produto:  **fluig

# Ocorrência

Reportei um problema em um workflow e a equipe de atendimento solicitou a pasta completa do projeto que contém os eventos, formulários e diagrama. 

Onde encontro essa pasta?

# Solução

Nos chamados abertos sobre desenvolvimento a equipe de atendimento fluig pode solicitar que a pasta do projeto seja enviada para análise.

Em primeiro lugar você precisa instalar e configurar o fluig Studio. Para saber mais acesse o [Guia de instalação fluig Studio](/pages/viewpage.action?pageId=73078179).

Em seguida siga a documentação sobre [Importação de Projetos fluig do TDS](https://tdn.totvs.com/pages/viewpage.action?pageId=128681226#ImportaçãoeexportaçãodeprojetonoFluigStudio-ImportaçãodeProjetosFluigdoTDS) para que o projeto fique disponível no volume do TDS ou Eclipse.

Agora acesse a estação de trabalho do TDS ou Eclipse. Se não lembrar qual é o caminho, você pode consultar acessando o menu **Arquivo > Trocar Espaço de Trabalho > Outras...** O campo **Espaço de Trabalho** exibe o caminho.

Acesse o diretório e compacte o projeto no formato .zip ou .rar para conseguir encaminhar em anexo no chamado.
