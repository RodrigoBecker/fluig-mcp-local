# DES - Como editar eventos dos formulários?

# Índice

# Plataforma

**Produto:** TOTVS Fluig Plataforma

# Ocorrência

Como editar eventos dos formulários?

# Solução

A edição de eventos de formulário deve ser feita no Fluig Studio:

- Em primeiro lugar você precisa instalar e configurar o Fluig Studio, para isso siga atentamente os passos descritos em: [Configuração para uso inicial do Fluig Studio](/pages/viewpage.action?pageId=172297237)

- Em seguida, cadastre o servidor fluig seguindo os passos descritos em: [Cadastrando servidor fluig no Studio](https://tdn.totvs.com/display/fluig/Criando+um+projeto+fluig+no+Studio#CriandoumprojetofluignoStudio-Cadastrandooservidorfluig)

- E por final, importe o formulário utilizando a opção [Importar Formulário do Servidor Fluig](https://tdn.totvs.com/pages/viewpage.action?pageId=128681226#ImportaçãoeexportaçãodeprojetonoFluigStudio-ImportaçãodeartefatosFluigdoservidorFluig.).

Assim, você terá acesso aos arquivos e poderá editá-los.
