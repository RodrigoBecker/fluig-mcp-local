# Plataforma ❙ Multiplicadores

# Índice

## Falando de Multiplicadores...

Nessa aba é possível cadastrar os multiplicadores da pontuação de um evento para cada time de usuários existente. Ou seja, quando o usuário executar um evento, sua pontuação será calculada considerando a pontuação do evento e o multiplicador do time ao qual ele pertence.

Por padrão, os multiplicadores são:

**•** 1 = 100% dos pontos são atribuídos ao usuário quando ele executar o evento;

**•** 0 = anula os pontos do evento, ou seja, nenhuma pontuação é atribuída ao usuário quando ele executar o evento.
