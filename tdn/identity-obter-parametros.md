# Obter companyId

---

Os passos da documentação [Identity | Token REST API](/display/fluig/Identity+%7C+Token+REST+API) descrevem o procedimento para obtenção do **companyId**.

# Obter userId

---

Os passos abaixo descrevem o procedimento para obtenção do **userId:**

**01.** Acionar o menu **Usuários**.

**02.** Localizar o usuário desejado na lista.

**03.** Clicar sobre o nome do usuário para abrir a respectiva página de gerenciamento.

**04**. O userId será exibido na barra de endereços do navegador, no final da URL, após .../user/#/users/.

![](/download/attachments/344457998/userId_3.png?version=3&modificationDate=1520516637000&api=v2)

# Obter applicationId

---

Os passos abaixo descrevem o procedimento para obtenção do applicationId:

**01.** Acionar o menu **Aplicativos**.

**02.** Localizar o aplicativo desejado na lista.

**03**. Acionar o nome do aplicativo para visualizar as configurações.

**04**. O applicationId será exibido na barra de endereços do navegador, após .../application/#/apps/.

![](/download/attachments/344457998/applicationId_3.png?version=1&modificationDate=1520517346000&api=v2)

# Obter groupId

---

Os passos abaixo descrevem o procedimento para obtenção do groupId.

**01.** Acionar o menu **Grupos**.

**02.** Localizar o grupo desejado na lista.

**03.** Clicar sobre o nome do grupo para abrir a respectiva página de gerenciamento.

**04**. O groupId será exibido na barra de endereços do navegador, após .../group/#/groups/.
