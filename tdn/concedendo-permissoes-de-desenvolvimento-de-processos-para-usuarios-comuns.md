# Concedendo permissões de desenvolvimento de processos para usuários comuns

# Objetivo

---

Para permitir que **usuários comuns** possam **desenvolver**e configurar **processos**, é necessário atribuir as permissões de desenvolvimento adequadas.

Nesta documentação, mostraremos como **conceder**essas permissões, possibilitando que usuários comuns tenham **acesso**às ferramentas necessárias para criar, editar e gerenciar **processos, formulários, serviços e datasets** dentro do sistema.
