# Identity | Como obter a URL de acesso a um aplicativo do Identity?

**Dúvida**

Como obter a URL de acesso a um aplicativo do Identity?

**Solução**

É possível obter o código do aplicativo através da URL de configuração desse aplicativo no Identity.

**01.** Acessar  o menu **Aplicativos**.

**02.** Clicar sobre o aplicativo desejado.

**03.** Copiar o código exibido na URL após .../apps/. No exemplo abaixo, o código do aplicativo Skype-DTL é "de09gzd6xv1oyb2x".
