# Platform ❙ Notification center

![](/download/attachments/236430069/%C3%ADcone-notifica%C3%A7%C3%B5es.png?version=1&modificationDate=1763754965293&api=v2)

---

The Notification Center consolidates all ongoing event and activity notifications sent to users in a single area of the system and allows the receipt of notifications of a given event to be parameterized.

- [Notification settings](/pages/viewpage.action?pageId=236430100): the user can define which notifications - among the ones the administrator has enabled for the company - they want to receive and how to receive them. Some notifications cannot be disabled, because they are default settings. In this case, the option None is not displayed. E-mail and Push notifications are only displayed for configuration if the administrator has enabled them to be used in the company.

- [Desktop notifications](/pages/viewpage.action?pageId=236430101): this feature informs users of all platform activities without having to keep it constantly open on the browser. All notifications sent to the platform’s Notification Center are also issued in the desktop’s Notification Center via Connect.
