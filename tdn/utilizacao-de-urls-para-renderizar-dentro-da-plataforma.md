# Utilização de URLs para renderizar dentro da plataforma

# Índice

# Objetivo

Esse guia visa apresentar os passos necessários de configuração para que os *dashboards*e os relatórios do Analytics possam ser apresentados em outros ambientes.

# Pré-requisitos

- Conhecimento prévio em determinados pontos, principalmente uma visão geral sobre o TOTVS Fluig Plataforma e o card [Recurso de Analytics](/display/fluig/Recurso+de+Analytics)

# Utilização de URLs para renderizar

Os *dashboards* e relatórios do Analytics disponibilizam URLs para que as informações disponíveis nestas páginas também possam ser exibidos, de forma fácil e segura, em outros ambientes.

Para obter essas URLs, acesse o Analytics – [analytics.fluig.com](https://analytics.fluig.com/) – escolha o relatório ou *dashboard* desejado e acione a opção “*Embed*”. Basta copiar a URL gerada e utilizar, por exemplo, em um documento externo da plataforma TOTVS Fluig.

Observação

Independente do painel selecionado para acesso inicial, todos os demais painéis também estarão disponíveis para acesso, pois fazem parte do *dashboard* o qual foi gerado o Embed. Caso deseje restringir permissões de acesso é recomendado criar um *dashboard* específico para apresentação das informações.
