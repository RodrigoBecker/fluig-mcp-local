# Plataforma ❙ Perspectiva

# Falando de perspectiva...

---

As perspectivas são utilizadas para mostrar o conteúdo de uma lista na página Home de cada usuário. Esta é uma forma dinâmica de mostrar uma tabela e seu conteúdo para seus usuários. Podem-se selecionar somente os campos necessários para a exibição e também é possível adicionar filtros aos resultados, desta maneira somente os dados que realmente precisão ser exibidos serão apresentados.

EXEMPLO
A lista Colaboradores têm os seguintes campos: Nome, E-mail, Ramal, RG, CPF e Endereço Residencial. O administrador recebeu um chamado para adicionar esta lista à home do TOTVS Fluig Plataforma, porém alguns campos não podem ser exibidos devido ao nível de exposição dos usuários cadastrados, pois os dados dos campos RG, CPF e Endereço Residencial são pessoais. O administrador, então, cria uma nova perspectiva para a lista Colaboradores, mas somente serão exibidos os dados dos campos Nome, Ramal e E-mail os dados pessoais do usuários não serão exibidos, desta forma os usuários da plataforma sempre terão uma lista de contatos com ramal e e-mail atualizadas.

## Criar perspectiva

---

**01.** No menu principal, clique em ![](/download/attachments/234455530/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1749491371013&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Personalização**.

**03**. Clique em ![](/download/attachments/234455530/%C3%ADcone-listas.png?version=1&modificationDate=1749491233853&api=v2) **Listas**.

**04.** Assinale a lista com a qual deseja criar a perspectiva.

**05.** Clique em **Mais**.

**06.** Clique em **Criar perspectiva**, localizada abaixo do menu **Mais**.

Para exibir o conteúdo do menu **Mais** é preciso clicar sobre ele, assim será apresentado a opção **Criar perspectiva** e demais opções.

**07.** Em **Criar perspectiva**, insira o nome da nova perspectiva.

**08.** Insira a descrição.

**09.** Assinale a ordem desejada para exibição das colunas.

**10.** Escolha um campo pelo qual os valores devem ser agrupados.

Ao escolher o campo que identifica os departamentos dentro da empresa, os dados serão agrupados por seus departamentos.

**11.** Clique em **Adicionar um filtro**.

Uma perspectiva permite filtrar a exibição dos dados que serão apresentados.

EXEMPLO
Exibir somente os valores iguais a José do campo Nome:

- selecione o campo Nome;
- selecione o tipo de filtro **é igual a**.
- insira o valor José.

**12.** Em **Criação de filtro**, selecione o campo desejado.

**13.** Selecione o tipo de filtro desejado.

**14.** Insira o valor para o filtro.

**15.** Clique em **Salvar**.

**16.** Para editar um filtro, assinale o filtro desejado.

Alterar as configurações que forem necessárias para um filtro já existente.

**17.** Clique em **Editar filtro**.

**18.** Em **Edição de filtro**, altere o campo, caso necessário.

**19.** Altere o tipo de filtro, caso necessário.

**20.** Altere o valor, caso necessário.

**21.** Clique em **Salvar**.

**22.** Para remover um filtro, assinale o filtro desejado.

Para determinadas perspectivas, alguns filtro passam a ser desnecessários após um período. Filtros que não são mais aplicados podem ser removidos da perspectiva.

**23.** Clique em **Remover filtro**.

**24.** Se necessário, clique em **Visualizar** para conferir como ficou sua perspectiva.

**25.** Clique em **Salvar**.

## Editar perspectiva

---

**01.** No menu principal, clique em ![](/download/attachments/234455530/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1749491371013&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Personalização**.

**03**. Clique em ![](/download/attachments/234455530/%C3%ADcone-listas.png?version=1&modificationDate=1749491233853&api=v2) **Listas**.

**04.** Assinale a lista que contém a perspectiva que deseja editar.

**05.** Clique em **Mais**.

**06.** Clique em **Editar perspectiva**, localizada abaixo do menu **Mais**.

Para exibir o conteúdo do menu **Mais**, é preciso clicar sobre ele, assim será apresentado a opção **Editar perspectiva** e demais opções.

**07.** Em **Editar perspectiva**, selecione a perspectiva desejada.

**08.** Clique em **Editar**.

**09.** Insira um novo nome para a perspectiva.

**10.** Insira a descrição, caso necessário.

**11.** Assinale a ordem desejada para exibição das colunas, caso necessário.

**12.** Escolha um campo pelo qual os valores devem ser agrupados.

Ao escolher o campo que identifica os departamentos dentro da empresa, os dados serão agrupados por seus departamentos.

**13.** Clique em **Adicionar um filtro**, caso necessário.

Uma perspectiva permite filtrar a exibição dos dados que serão apresentados.

EXEMPLO
Exibir somente os valores iguais a José do campo Nome:

- selecione o campo Nome;
- selecione o tipo de filtro **é igual a**.
- insira o valor José.

**14.** Em **Criação de filtro**, selecione o campo desejado.

**15.** Selecione o tipo de filtro desejado.

**16.** Insira o valor para o filtro.

**17.** Assinale o campo desejado.

Só é permitida a alteração de um campo por vez.

**18.** Clique em **Salvar**.

**19.** Para editar um filtro, assinale o filtro desejado.

Alterar as configurações que forem necessárias para um filtro já existente.

**20.** Clique em **Editar filtro**.

**21.** Em **Edição de filtro**, altere o campo, caso necessário.

**22.** Altere o tipo de filtro, caso necessário.

**23.** Altere o valor, caso necessário.

**24.** Clique em **Salvar**.

**25.** Para remover um filtro, assinale o filtro desejado.

Para determinadas perspectiva alguns filtro passam ser desnecessários após um período. Filtros que não são mais aplicados podem ser removidos da perspectiva.

**26.** Clique em **Remover filtro.**

**27.** Se necessário, clique em **Visualizar** para conferir como ficou a edição da sua perspectiva.

**28.** Clique em **Salvar**.

## Remover perspectiva

---

**01.** No menu principal, clique em ![](/download/attachments/234455530/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1749491371013&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Personalização**.

**03**. Clique em ![](/download/attachments/234455530/%C3%ADcone-listas.png?version=1&modificationDate=1749491233853&api=v2) **Listas**.

**04.** Assinale a lista que contém a perspectiva que deseja remover.

**05.** Clique em **Mais**.

**06.** Clique em **Remover perspectiva**, localizada abaixo do menu **Mais**.

Para exibir o conteúdo do menu Mais é preciso acioná-lo, assim será apresentado a opção Remover perspectiva e demais opções.

**07.** Em **Remover perspectiva**, selecione a perspectiva desejada.

**08.** Clique em **Remover**.
