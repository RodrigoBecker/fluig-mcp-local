# Platform ❙ Platform login

# Speaking of login...

---

The login page is the portal through which users access the company on TOTVS Fluig Platform. To access the login page, users must enter the company domain in the browser address bar.

EXAMPLE
[https://yourcompany.fluig.com](https://yourcompany.fluig.com.)

Users can only be authenticated through the login page of the company to which they belong, otherwise access will be denied.

![](/download/attachments/441813465/Fluig%20login.png?version=3&modificationDate=1764941183127&api=v2)

## Login

---

**01.** Enter the access address to TOTVS Fluig in the browser's address bar.

**02.** Enter the account login.

It is possible to authenticate yourself in the platform using the login or the email informed by the administrator in the user registration.

Except if there is another active user with the same email in a different company, this user and others with the same email will not be able to access the system using their email address. In this case, login must be made by entering only the login, and not the email address.

**03.** Enter the user password.

**04.** Click **Access**.

After clicking **Access**, if the information is correct, the platform will perform the authentication. If a[consent form](/pages/viewpage.action?pageId=550328756) is set up for the platform, the user must accept the form in order to access the [Home page](/pages/viewpage.action?pageId=236429027).

## Retrieve password

---

**01.** Click **Forgot your password?****.**

**02.** Enter the account login to retrieve the password.

**03.** Click **Send**.

You will receive an e-mail containing a link to reset your password. This link is valid for 24 hours.

Important!

- This procedure applies to any platform user with a valid e-mail address.

- This procedure cannot be used to reset Identity passwords.

**04.** Open the link received via e-mail.

**05.** Enter the new password and confirm.

**06.** Click **Send**.

This will reset your password and allow you to access the platform.

## Change login page language

---

**01**. On the login page, click on the option that represents the desired language to access the platform.

The available options are:

- **Portuguese (Brazil)**;

- **English (United States)**;

- **Spanish (Default)**.

This procedure is only valid for changing the language on the login page. If you want to change the language on the platform, go to the [Language](/pages/viewpage.action?pageId=244422874) documentation.

Important!

The options may be different if the platform has some [customization on the login page](https://tdn.totvs.com/pages/viewpage.action?pageId=428928481).

Attention!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
