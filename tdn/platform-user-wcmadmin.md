# Platform ❙ User WCMADMIN

![](/download/attachments/236429908/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1765288507127&api=v2)

---

The wcmadmin user is used for initial settings, such as creating new companies and setting respective administrators, for example. In addition, it includes settings related to the environment and infrastructure such as the e-mail server, license server, data volume, access and authentication URL. ![](/plugins/servlet/confluence/placeholder/unknown-macro?name=tooltip&locale=en_US&version=2)

The following tabs make up the wcmadmin user’s Control Panel:

- [General](/pages/viewpage.action?pageId=236429910): it is where they can manage the company’s data volume and control Digital Subscription licenses, if enabled;

- [ECM](/pages/viewpage.action?pageId=236429914): in this tab, ECM 3 databases are converted and Connect is enabled;

- [WCM](/pages/viewpage.action?pageId=236429918): it contains the options to manage companies and systems, such as access URL, integrated authentication, integration with TOTVS Identity and Fluig Analytics, customization, and platform parameters.

Please note!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
