# BPM 067 - Como atualizar a lista de formulários no TDS?

# Índice

# Plataforma

**Produto:  fluig**

# Ocorrência

Mesmo depois de remover todos os processos do banco de dados do fluig os formulários ainda aparecem na lista de formulários para desenvolvimento no TDS. Como faço para atualizar esta listagem?

![](/download/attachments/256316432/Processos.png?version=1&modificationDate=1474379928000&api=v2)

**Figura 1 - Exemplo de tela das propriedades do processo no TDS - Aba Formulário.**

# Solução

Quando são excluídos os processos da plataforma fluig, os formulário vinculados a ele permanecem salvos na pasta 'Formulário fluig' no GED.

Para que a lista de formulários não apareça na listagem de opções do TDS, será necessário excluir os formulários da pasta do GED e atualizar o servidor do fluig nas propriedades do processo no TDS conforme imagem abaixo:

![](/download/attachments/256316432/Image%201.jpg?version=1&modificationDate=1474379928000&api=v2)

**Figura 2 - Exemplo de tela das propriedades do processo no TDS.**
