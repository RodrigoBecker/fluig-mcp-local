# Actualización de seguridad

El equipo de la plataforma TOTVS Fluig, a partir de las actualizaciones **1.6.5-210521 Liquid, 1.7.0-210518 Lake y 1.7.1-210518 Crystal Lake**, realizó una actualización de seguridad con el objetivo de mejorar la seguridad de su plataforma, para que pueda realizar todas sus operaciones sin tener que preocuparse por ataques maliciosos.
 Por eso, le sugerimos leer la documentación [Datasets en el acceso a una base de datos externa](https://tdn.totvs.com/x/OgFlDw) para que pueda estar al tanto de la forma correcta de utilizar este procedimiento.
 Trabajamos siempre para que su experiencia con nosotros sea cada vez más fluida y agradable.
