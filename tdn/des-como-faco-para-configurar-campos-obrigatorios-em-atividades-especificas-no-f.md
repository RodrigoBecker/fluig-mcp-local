# DES - Como faço para configurar campos obrigatórios em atividades específicas no formulário?

# Índice

# Plataforma

**Produto:**TOTVS Fluig Plataforma

# Ocorrência

Como faço para configurar campos obrigatórios em atividades específicas no formulário (não sendo necessariamente na atividade de início do processo)?

# Solução

Você encontra esta informação na documentação de [Desenvolvimento de Formulários](https://tdn.totvs.com/x/U4l8B). É possível desenvolver utilizando a função [validateForm](https://tdn.totvs.com/pages/viewpage.action?pageId=270924158#EventosdeFormulário-validateForm).
