# Plataforma ❙ Estruturas de páginas

# Falando de estruturas de páginas...

---

As páginas do TOTVS Fluig possuem *layouts*específicos para cada tipo de página, sendo páginas colaborativas, páginas públicas ou básicos. Cada *layout*de página possui uma estrutura específica de *slots*para a inclusão de *widgets*, onde os conteúdos serão inseridos.
