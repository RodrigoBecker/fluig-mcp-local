# BPM 032 - Por que não aparece o botão "Enviar" ao acessar uma solicitação na Central de Tarefas?

# Índice

# Plataforma

**Produto:  **fluig

**Versão: **Todas as versões

# Ocorrência

Ao acessar uma solicitação na Central de tarefas, não é exibido o botão "Enviar" para movimentar a solicitação, é exibido apenas o botão "Cancelar Solicitação".

# Solução

Quando acessada a aba Minhas Solicitações, na Central de tarefas do usuário, serão exibidas todas as solicitações abertas pelo usuário logado, mesmo as que estão pendentes com outro usuário. O objetivo deste menu é que o usuário possa verificar o status ou cancelar as solicitações que abriu.

Sendo o usuário responsável por movimentar a solicitação, o correto é acessar a aba Tarefas a concluir. Apenas acessando a solicitação através desta aba será possível movimentar uma solicitação como responsável pela atividade.
