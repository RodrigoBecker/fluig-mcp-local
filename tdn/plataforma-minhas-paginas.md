# Plataforma ❙ Minhas páginas

# Falando de minhas páginas...

---

As páginas são compostas por layouts que possuem diversos slots, e para cada slot de layout é possível adicionar uma widget. Assim é possível criar páginas personalizadas com as widgets que melhor atendem aos usuários. As páginas estarão disponíveis para visualização acionando-as no menu principal da plataforma e através de uma URL direta para a página respeitando as permissões de autenticação definidas na criação da página.

Fique atento!

Esta documentação é válida a partir da atualização **Voyager (2.0)**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
