# SOC - Por que usuários que não são moderadores conseguem administrar a comunidade?

# Índice

# Plataforma

**Produto:**TOTVS Fluig Plataforma

# Ocorrência

Usuários que não participam ou não são moderadores da comunidade podem editar as comunidades da plataforma.

# Causa

Este comportamento é normal para todos os usuários que possuírem o papel **admin** na empresa.

# Solução

Acessar **Painel de controle** > agrupador **Pessoas** > **Usuários** e remover o papel **admin** dos usuários que não devem conter este perfil na empresa. 

# Observações

É bom lembrar que usuários com o papel **admin** possuem permissão para editar e administrar qualquer comunidade, inclusive as comunidades ocultas.
