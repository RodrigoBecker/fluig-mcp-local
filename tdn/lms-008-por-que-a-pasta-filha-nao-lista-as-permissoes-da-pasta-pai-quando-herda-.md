# LMS 008 - Por que a pasta filha não lista as permissões da pasta pai quando "Herda permissões" está selecionada?

# Índice

# Plataforma

**Produto: **TOTVS Fluig Plataforma

**Card:** LMS

# Ocorrência

A pasta filha não lista as permissões configuradas para a pasta pai a opção "Herda permissões" está selecionada.

# Solução

Esse é o comportamento padrão do LMS.

A opção "Herda permissões" realmente faz com que a pasta filha herde a segurança configurada na pasta pai, mas a listagem de permissões não exibe esses valores. A listagem serve apenas para as permissões específicas aplicadas na pasta filha.
