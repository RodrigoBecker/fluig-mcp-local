# Platform ❙ User menu

![](/download/attachments/244422861/menu-usu%C3%A1rio.png?version=1&modificationDate=1764600421003&api=v2)

---

This menu allows the user to define the settings of the platform based on their preferences, such as language and profile information, as well as allows them to access the full user manual and log out the platform.

The location of the User menu depends on the Theme selected by the administrator:

- in the **Classic** theme, the menu is located in the upper right corner of the page and identified by a **Gear-shaped**![](/download/attachments/244422861/fluigicon-cog.png?version=1&modificationDate=1764600421247&api=v2) icon;

- in the **Snowflake** theme, it is positioned in the upper left corner next to the user's profile picture and is accessed by the **More options** ![](/download/attachments/244422861/flaticon-more-vert.png?version=1&modificationDate=1764600546487&api=v2) icon.

It consists of the following options:

- [Edit profile](/pages/viewpage.action?pageId=236429037): on this page, the user can change data such as subjects of interest, name and image to be displayed, add a substitute, and enable account log.

- [Edit image](/pages/viewpage.action?pageId=239038839): the image editing window allows the user to change and adjust their profile photo.

- [Language](/pages/viewpage.action?pageId=244422874): it allows the user to change the language for use on the platform. Currently available languages are Portuguese, English and Spanish.

- [Help](/pages/viewpage.action?pageId=244422903): it provides access to the full user manual, which contains relevant information on how to use the features available on the platform.

- [Exit](/pages/viewpage.action?pageId=244422919): it allows the user to end the current session on the platform.

Please note!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
