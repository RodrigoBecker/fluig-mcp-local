# Identity | É possível usar a mesma instalação do SmartSync para ambos ambientes de teste e de produção?

**Dúvida**

É possível usar a mesma instalação do SmartSync para ambos ambientes de teste e de produção?

**Solução**

**Não.** No caso de ambientes diferentes, é necessário instalar um SmartSync específico para cada um. Contudo, é possível cadastrar mais de um Active Directory em um SmartSync, desde que sejam vinculados a contextos que pertençam a um mesmo ambiente (homologação ou produção).
