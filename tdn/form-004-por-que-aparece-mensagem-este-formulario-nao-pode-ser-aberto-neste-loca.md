# FORM 004 - Por que aparece mensagem "este formulário não pode ser aberto neste local, pois não foi criado por essa ferramenta".

# Índice

# Plataforma

**Produto: fluig**

**Versão: todas**

# Ocorrência

Ao clicar no formulário do editor web é apresentada a mensagem: “Este formulário não pode ser aberto neste local, pois não foi criado por essa ferramenta”

# Solução

Utilizando o gerador de formulários do fluig é possível criar formulários sem possuir conhecimento técnico. Para isso, o fluig cria uma estrutura de dados para garantir a integridade das informações que serão publicadas nestes formulários. Por isso que, caso o formulário seja alterado/republicado externamente (com o fluig Studio ou publicação manual na Navegação de Documentos), não é mais possível realizar a edição deste formulário através do gerador.

Fique ligado em [fluig.com/blog](https://fluig.com/blog), pois em breve teremos novidades sobre a experiência de formulários na plataforma. Caso você tenha algum formulário que foi editado erroneamente pelo fluig Studio e você precisa editá-lo pelo Gerador, entre em contato conosco para avaliarmos: [https://suporte.fluig.com](https://suporte.fluig.com)
