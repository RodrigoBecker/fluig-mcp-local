# Guia de atualização Fluig Studio

# Índice

# Objetivo

---

Este guia tem como objetivo auxiliar os usuários na instalação do Fluig Studio e apresentar as ações possíveis na instalação ou atualização do mesmo. A atualização do plug-in Fluig Studio é feita ao sobrescrever a instalação atual na IDE com a versão mais recente.

# Pré requisitos

---

- Ter a mesma versão de plugin e servidor para melhor experiência. **Exemplo:** se o Fluig utilizado estiver na atualização 1.5.9, o plugin também deve estar nesta mesma versão.

# Identificando a versão do Fluig Studio instalada

---

Para identificar qual a versão do plugin Fluig Studio que está instalada em seu Eclipse© ou TOTVS Developer Studio siga os passos abaixo: 

- [Passo 1](#)
- [Passo 2](#)

 - Selecione no menu **Help** a opção **Installation Details** (ou **Ajuda** **→ Detalhes da Instalação**, se sua IDE estiver traduzida).

![](/download/attachments/240298991/Screenshot%2028_06%20001.png?version=1&modificationDate=1467113713000&api=v2)

 - Verifique na coluna **Version** a versão correspondente ao item "Fluig Workflow and WCM Designer":

![](/download/attachments/240298991/Installation%20Details.png?version=2&modificationDate=1466790917000&api=v2)

# Atualizando a versão do Fluig Studio

---

Para atualizar o plugin Fluig Studio para a última versão ou para uma versão específica basta seguir os passos e as dicas em [Guia de instalação Fluig Studio - Instalação/Atualização funções Fluig Studio.](https://tdn.totvs.com/pages/viewpage.action?pageId=73078179#GuiadeinstalaçãofluigStudio-InstalaçãodasfunçõesdofluigStudio)

Para instalar uma versão do Fluig Studio anterior à versão atualmente instalada em sua IDE, primeiramente será necessário remover essa versão para prosseguir com a instalação.
