# BPM 077 - Como receber notificações de uma atividade da solicitação que iniciei?

# Índice

# Plataforma

**Produto:  fluig**

# Ocorrência

Iniciei uma solicitação contudo, em uma das atividades o gestor aprova ou reprova um cadastro. Quando o gestor reprova eu não recebo notificações.

# Causa

A opção de 'Notifica Requisitante' da aba Acompanhamento das configurações da atividade não está selecionada.

# Solução

Para receber notificações referentes a esta atividade ou as demais do processo é necessário selecionar a opção 'Notifica requisitante'.

Realizando este procedimento o requisitante irá receber uma notificação referente ao andamento de cada atividade do processo que estiver selecionado.
