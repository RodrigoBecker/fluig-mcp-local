# Indexação de Documentos

# Índice

# Objetivo

---

Este guia tem como objetivo apresentar a tarefa de indexação de documentos.

# Introdução

---

A plataforma permite o agendamento de uma tarefa para indexação de documentos e a configuração da periodicidade dela.

# Agendando a Tarefa de Indexação

---

- [Passo 1](#)
- [Passo 2](#)
- [Passo 3](#)

 - Para agendar uma tarefa, deve-se acessar o menu **Painel de Controle** → agrupador **Parâmetros técnicos** → **Agendador de Tarefas**, conforme imagem abaixo:

![](/download/attachments/244726875/agendador.png?version=3&modificationDate=1597956916513&api=v2)

 - Em seguida, clique no botão **Adicionar** e escolha o tipo **Indexação de Documentos**. Nessa tela é necessário definir uma descrição para a tarefa, optar por iniciar pelos documentos mais antigos ou mais recentes, pré definir um horário para a execução e a frequência com que essa tarefa é executada.

![](/download/attachments/244726875/agendar_tarefa.png?version=1&modificationDate=1470860626000&api=v2)

 - Após estes passos, basta clicar em **Confirmar** e aguardar a tarefa ser executada conforme as configurações.

Dica

Consulte nossas documentações para conhecer mais sobre o [Agendador de Tarefas](https://tdn.totvs.com/display/HF/Agendador+de+tarefas) e a [Indexação](https://tdn.totvs.com/pages/viewpage.action?pageId=234455757) de documentos.

Importante!

O processo de indexação de documentos é custoso e poderá resultar em perda de performance no servidor fluig enquanto é executado. A frequência com que a indexação deve ser executada depende da necessidade de cada cliente, mas é interessante que seja realizada uma vez ao dia.
