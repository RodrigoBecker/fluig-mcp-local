# Plataforma ❙ Agrupador ECM

![](/download/attachments/233766781/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1750860237513&api=v2)

---

Neste agrupador é realizada a conversão de bases do ECM 3.

Ele é composto pelo seguinte recurso:

- [Conversor de base](/pages/viewpage.action?pageId=267801151): esse recurso permite converter uma base do antigo ECM 3 para o TOTVS Fluig.Importante! Esse recurso existe apenas **até** a **atualização** **1.5.13** do TOTVS Fluig, visto que a conversão de bases do ECM precisa ser feita nessa atualização e, só depois, aplicar as próximas atualizações da plataforma. Obtenha mais detalhes em [Conversão TOTVS ECM para plataforma TOTVS Fluig](/pages/viewpage.action?pageId=257622952).

Fique atento!

Esta documentação é válida **até** a **atualização 1.5.13**. Se você utiliza uma atualização anterior ou posterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
