# Plataforma ❙ Pontuar

Importante!

A partir de **Abril de 2025**, o [suporte](https://totvscst.zendesk.com/hc/pt-br/#home) ofertado ao LMS será descontinuado. Não havendo mais evoluções após este período. O LMS não estará mais disponível para acesso nos ambientes a partir da **próxima release** do TOTVS Fluig Plataforma, prevista para o primeiro semestre de 2025.

Nesse local é possível ajustar a pontuação dos alunos em itens de tópico e atribuir pontuação manual a itens definidos com esse tipo de pontuação. É composto por:

- [Pontuação manual](/pages/viewpage.action?pageId=233765938): permite inserir ou ajustar a pontuação de cada aluno em cada item de tópico que possui esse tipo de pontuação da turma acessada;

- [Ajustar pontuação](/pages/viewpage.action?pageId=233765941): permite alterar as notas de itens de tópico dos alunos.
