# Platform ❙ Favorites

# Index 

## Speaking of Favorites...

The Favorites item allows users to access and view documents, folders, processes, and communities marked as favorites. These items can also be removed from the favorites list in this area. This feature helps users by centralizing, for example, the most used documents, processes, or communities in a single area.

The Favorites area includes the following tabs:

- [Favorite documents](/pages/viewpage.action?pageId=236429047): it consists of documents and folders marked by the user as favorites

- [Favorite processes](/pages/viewpage.action?pageId=236429050): this space lists the processes set by the user as favorites for quick opening of requests

- [Social favorites](/pages/viewpage.action?pageId=236429057): it groups users and favorite communities

- [History](/pages/viewpage.action?pageId=236429053): it displays the items viewed by the user, such as documents, images and videos, grouped by time period
