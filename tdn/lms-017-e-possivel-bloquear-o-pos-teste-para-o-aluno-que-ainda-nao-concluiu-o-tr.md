# LMS 017 - É possível bloquear o pós-teste para o aluno que ainda não concluiu o treinamento?

# Índice

# Plataforma

**Produto:**TOTVS Fluig Plataforma

**Card:** LMS

# Ocorrência

Necessidade de bloquear a exibição/realização do pós-teste para o aluno que ainda não concluiu o treinamento.

# Solução

Sim, é possível. Para isso, é preciso definir os conteúdos como obrigatórios, assim o usuário terá que concluir os conteúdos para que o pós-teste seja liberado.

Para definir os conteúdos como obrigatórios, edite o treinamento e, no quadro **Conteúdos**, clique em **Configurações do conteúdo**. Na janela exibida, assinale a opção **Conteúdo obrigatório**.

Repita esse procedimento para todos os conteúdos do treinamento.
