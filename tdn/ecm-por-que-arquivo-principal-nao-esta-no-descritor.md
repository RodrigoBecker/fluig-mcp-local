# ECM - Por que arquivo principal não está no descritor?

# Índice

# Plataforma

**Produto**: TOTVS Fluig Plataforma

# Ocorrência

Ao utilizar o arquivo descritor para publicação múltipla de documentos, a plataforma exibe a mensagem de erro "O seguinte arquivo foi marcado como principal, porém, não está no descrito".

![](/download/attachments/240310332/Screenshot%2024_06%20001.png?version=1&modificationDate=1466788993000&api=v2)

# Causa

O conteúdo do arquivo descritor possui acentuação ou caracteres especiais.

# Solução

Remover caracteres especiais e acentuação dos campos no arquivo descritor.
