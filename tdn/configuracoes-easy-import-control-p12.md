# Configurações - Easy Import Control - P12

Antes de iniciar o processo de implantação preenchendo cadastros e realizando as movimentações, alguns dados que configuram o módulo Controle de Importações devem ser verificados no módulo Configurador e, caso necessário, o Advanced Protheus permite que o usuário altere-os, de acordo com as necessidades de cada empresa.

São parâmetros que devem estar devidamente preenchidos para que o sistema opere corretamente.
