# Platform ❙ Language

# Speaking of language...

---

This feature allows users to choose the language they want to use on the platform. Each user can define which language best meets their preferences.

![](/download/attachments/244422874/Language.png?version=2&modificationDate=1764788618953&api=v2)

## Change language

---

**01.** Click on **User Menu** ![](/download/attachments/244422874/menu-usu%C3%A1rio.png?version=1&modificationDate=1764788287113&api=v2) – located at the top right of the header.

If you have already changed your profile picture, it will be displayed in the **User Menu**, as follows: ![](/download/attachments/244422874/menu-usu%C3%A1rio-foto.png?version=1&modificationDate=1764788287190&api=v2).

The location of the **User Menu** varies according to the [Theme](/pages/viewpage.action?pageId=236430025) selected by the administrator:

- In the **Classic** theme, the menu is located at the top right of the page next to the user's profile name and is identified by the **Settings** icon ![](/download/attachments/244422874/fluigicon-cog.png?version=1&modificationDate=1764788287257&api=v2);

- In the **Snowflake** theme, it is positioned at the top left next to the user's profile picture and is accessed by the **More options** icon![](/download/attachments/244422874/flaticon-more-vert.png?version=1&modificationDate=1764788287340&api=v2).

**02.** Click on the arrow located next to the current language ![](/download/attachments/244422874/troca-idioma.png?version=1&modificationDate=1764788428287&api=v2).

**03.** Select the desired language for using the platform.

The available options are:

- **Portuguese (Brazil)**;

- **English (United States)**;

- **Spanish (Default)**.

Please note!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
