# Plataforma ❙ Componentes de procesos

Consulte la documentación correcta:

Esta documentación se refiere al nuevo editor de procesos de la plataforma. Si está utilizando el editor de procesos actual, acceda a [Configurar actividades y flujos](/pages/viewpage.action?pageId=292372874).

IDIOMA

![](/download/attachments/976155650/diagrama.png?version=1&modificationDate=1755089810187&api=v2)

---

Los componentes son las representaciones gráficas de las etapas de un proceso y se utilizan para montar su diagrama, en el cual es posible ver lo que sucede con la solicitud cuando está en cada etapa, así como las direcciones que puede seguir a medida que se van completando las etapas.

Cada componente tiene características y configuraciones propias, que pueden definirse de acuerdo con lo que se espera para cada etapa, en cada proceso, para cada negocio.

Haga clic en cada componente para obtener información más detallada sobre ellos.

![](/download/attachments/976155650/in%C3%ADcio-mini.png?version=1&modificationDate=1755089809653&api=v2)  

**Inicio**Representa la etapa inicial del proceso, donde comienza el flujo y se inicia la solicitud.

![](/download/attachments/976155650/atividade-mini.png?version=1&modificationDate=1755089809453&api=v2)   

[**Actividad**](/pages/viewpage.action?pageId=976136505)
Representa cada etapa del proceso por la que pasará la solicitud.

![](/download/attachments/976155650/subprocesso-mini.png?version=1&modificationDate=1755089810253&api=v2)   

[**Subproceso**](/pages/viewpage.action?pageId=976148180)
Representa otro proceso dentro del proceso principal.

![](/download/attachments/976155650/paralelo-mini.png?version=1&modificationDate=1755089809780&api=v2)   

**Paralelo**
Representa el inicio de etapas paralelas, donde el flujo principal se divide en dos o más etapas.

![](/download/attachments/976155650/join-mini.png?version=1&modificationDate=1755089809717&api=v2)   

**Join**
Representa el fin de etapas paralelas, reanudándose el flujo principal.

![](/download/attachments/976155650/exclusivo-mini.png?version=1&modificationDate=1755089810040&api=v2)   

**Exclusivo**Representa el mecanismo que dirige a qué flujo debe seguir la solicitud, dependiendo del resultado obtenido.

![](/download/attachments/976155650/cancelamento-mini.png?version=1&modificationDate=1755089809520&api=v2)   

**Anulación**
Representa la anulación de la solicitud.

![](/download/attachments/976155650/fim-mini.png?version=1&modificationDate=1755089809590&api=v2)   

**Final**
Representa el fin del proceso, donde el flujo termina y la solicitud se finaliza.

![](/download/attachments/976155650/fluxos-mini.png?version=1&modificationDate=1755089809840&api=v2)   

**Flujos**
Representan las direcciones hacia donde debe seguir la solicitud a medida que se van completando las etapas.

¡Manténgase atento!

Esta documentación es válida a partir de la actualización **Voyager (2.0)**. Si utiliza una actualización anterior, puede tener información diferente de la que ve en su plataforma.
