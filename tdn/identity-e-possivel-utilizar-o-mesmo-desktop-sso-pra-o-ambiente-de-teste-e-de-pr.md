# Identity | É possível utilizar o mesmo Desktop SSO pra o ambiente de teste e de produção?

**Dúvida**

É possível utilizar o mesmo Desktop SSO pra o ambiente de teste e de produção?

**Solução**

**Não.** É necessário configurar um Desktop SSO específico para cada ambiente.
