# My Approval ❙ Senha ❙ Como recuperar ou trocar minha senha?

Para recuperar ou trocar a senha para acessar o aplicativo My Approval siga os passos abaixo:

---

A senha que o usuário utiliza para se autenticar no aplicativo My Approval é a mesma senha utilizada para se autenticar no TOTVS Fluig Plataforma, dessa forma o processo de recuperação ou troca de senha é a mesma do Fluig Plataforma. 

**01.** Para realizar o procedimento, siga os passos descritos na documentação: [Login na plataforma](https://tdn.totvs.com/pages/viewpage.action?pageId=389547065#Plataforma%E2%9D%99Loginnaplataforma-Recupera%C3%A7%C3%A3odesenhapessoal).
