# ARQ - Como exportar base de dados SQL Server?

# Índice

# Plataforma

**Versão:** A partir da 1.6

**Ambiente:** Linux/Windows

**Banco de Dados:** SQL Server

# Ocorrência

Como exportar (dump) uma base de dados SQL Server?

# Solução

Para exportar uma base de dados SQL Server, utilize o seguinte comando:

[?](#)

| `BACKUP DATABASE fluig``TO DISK =``'C:\fluig.BAK'``WITH STATS = 1``GO` |
| --- |

Substitua **fluig** pelo seu database configurado.
