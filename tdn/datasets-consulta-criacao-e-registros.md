# Datasets - Consulta, criação e registros

# Índice

O TOTVS Fluig Plataforma permite disponibilizar informações provindas de várias fontes de dados através de formas variadas de apresentação. A plataforma possui o componente Dataset que permite padronizar o acesso às informações, independente da origem dos dados, ou seja, é possível acessar informações provenientes de vários locais, como aplicativos externos, banco de dados ou mesmo dos próprios recursos da plataforma.

A partir da **atualização 1.6.5 - Liquid**, o dataset pode ser configurado, codificado e consultado diretamente pela plataforma, em uma interface de desenvolvimento disponibilizada no Painel de Controle.
