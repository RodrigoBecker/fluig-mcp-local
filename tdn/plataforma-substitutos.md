# Plataforma ❙ Substitutos

# Falando de substitutos...

---

A funcionalidade de usuário substituto possibilita que, por determinado período, um usuário (substituto) possa realizar as tarefas de outro usuário (substituído).

É permitido o cadastro de vários substitutos para um mesmo usuário origem, inclusive no mesmo período. Mas um usuário somente pode ser substituto do mesmo usuário origem apenas uma vez. As atividades são registradas em nome do usuário que está sendo substituído, mas é o substituto quem faz a ação, portanto se você remover o registro de substituto não perderá nenhuma informação ou atividade que foi feita.

É possível definir em quais processos o usuário será responsável por executar as tarefas do substituído. E, também, é possível [consultar solicitações](/pages/viewpage.action?pageId=233763161) de processo em que o usuário participou como Gestor ou Substituto.

## Ver usuários substitutos

---

**01.** No menu principal, clique em ![](/download/attachments/234455459/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1748459808457&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Pessoas**.

**03**. Clique em ![](/download/attachments/234455459/%C3%ADcone-substitutos.png?version=1&modificationDate=1748459655750&api=v2) **Substitutos**.

**04**. Veja os usuários substitutos existentes.

## Adicionar usuário substituto

---

**01.** No menu principal, clique em ![](/download/attachments/234455459/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1748459808457&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Pessoas**.

**03**. Clique em ![](/download/attachments/234455459/%C3%ADcone-substitutos.png?version=1&modificationDate=1748459655750&api=v2) **Substitutos**.

**04.** Clique em **Adicionar**.

**05.** Insira as informações solicitadas.

**Usuário que será substituído**Usuário do qual as tarefas serão transferidas para outro durante um período definido. A matrícula é preenchida automaticamente após selecioná-lo.

Nota:

Somente será permitido alterar este campo quando o usuário logado possuir o papel **Admin**.

**Usuário que irá substituir**Usuário que ficará responsável pelas tarefas do substituído durante um período definido. A matrícula é preenchida automaticamente após selecioná-lo.

**Período da substituição**Data de início e data de fim do período durante o qual a substituição ocorrerá.

**Substituir todos os processos**Quando ativada, determina que a substituição será válida para todos os processos e documentos. Se não for ativada, é necessário selecionar os processos para os quais a substituição será válida no campo **Selecione os processos**.

**Selecione os processos**Selecione os processos para os quais a substituição será válida. Isso significa que apenas nesses processos o substituto pode fazer alguma ação em nome do substituído. Esse campo somente é habilitado quando a opção **Substituir todos os processos** não está ativada.

**Justificativa**Motivo pelo qual a substituição ocorrerá. Permite incluir uma justificativa com até 500 caracteres.

**06.** Clique em **Salvar**.

Durante o período definido, as atividades serão registradas em nome do usuário que está sendo substituído, mas será o substituto quem fará as ações.

## Editar usuário substituto

---

**01.** No menu principal, clique em ![](/download/attachments/234455459/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1748459808457&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Pessoas**.

**03**. Clique em ![](/download/attachments/234455459/%C3%ADcone-substitutos.png?version=1&modificationDate=1748459655750&api=v2) **Substitutos**.

**04.** Selecione o usuário substituto a ser editado.

**05.** Clique em **Editar**.

**06.** Altere as informações desejadas.

É possível alterar as datas que compreendem o período da substituição e os processos a serem considerados. Não é permitido alterar o usuário substituído e o usuário substituto. Se for necessário realizar este tipo de alteração, é necessário criar um novo registro de usuário substituto.

**07.** Clique em **Salvar**.

## Excluir usuário substituto

---

**01.** No menu principal, clique em ![](/download/attachments/234455459/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1748459808457&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Pessoas**.

**03**. Clique em ![](/download/attachments/234455459/%C3%ADcone-substitutos.png?version=1&modificationDate=1748459655750&api=v2) **Substitutos**.

**04.** Selecione o usuário substituto a ser excluído.

**05.** Clique em **Remover**.

**06.** Na mensagem de confirmação, clique em **Sim**.

Fique atento!
