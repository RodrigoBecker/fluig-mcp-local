# Plataforma ❙ Permissões do widget

# Falando de permissões do widget...

---

Esse recurso permite gerenciar as permissões de acesso dos usuários, grupos ou papéis aos widgets. Ao definir permissão para o widget em uma página, as permissões são aplicadas somente para o widget que está na página, ou seja, ainda é necessário conceder permissão na página para o usuário. 

Caso seja necessário conceder permissão em todas as páginas nas quais o widget está presente, é necessário acessar o Painel de Controle > agrupador Pessoas > Permissões e definir as permissões desejadas para o widget. É importante salientar que, para conseguir editar um widget de uma página, é necessário ter primeiro a permissão para editar a página. Caso o usuário, grupo ou papel tenha permissão somente no widget, não será possível editar a página na qual o widget está presente.

Para que o usuário consiga editar as permissões do widget é necessário que ele já tenha permissão para editar a página, pois o recurso presente nesta documentação permite gerenciar as permissões de acesso somente para o widget. 

Por padrão, o widget recebe as mesmas permissões da página onde estiver alocado. Essas permissões podem ser personalizadas para cada widget individualmente, ou seja, cada widget presente em uma página pode ter suas permissões individualizadas, pois um ícone de cadeado é apresentado em cada um dos widgets contidos na página. 

É importante lembrar que: as permissões alteradas de um widget que esteja alocado em uma página afetam somente o widget em si. Em casos de páginas públicas, todos os widgets ficam visíveis, independente do grau de permissão que esteja configurada para cada um. 

No entanto, recomendamos atenção em quais widgets são utilizados em páginas públicas, pois seu comportamento pode variar ou mesmo apresentar inconsistências, já que alguns widgets utilizam informações de usuários conectados, por exemplo.

## Alterar permissão de widget

---

**01.** Com a página em modo de edição, clique no ícone ![](/download/attachments/244910403/flaticon-unlock%20%281%29.png?version=1&modificationDate=1714683430147&api=v2).

**02.** Após clicar no ícone do *widget*, clique em **Adicionar** na aba **Por grupo** para relacionar um grupo de usuários ao *widget* e definir as permissões.

**03.** Localize e selecione o grupo de usuários para o qual serão liberadas as permissões.

**04.** Assinale as permissões desejadas.

As opções de permissão disponíveis são:

**Visualizar widget**Quando assinalado, permite que os usuários do grupo consigam visualizar essa *widget* na plataforma.

**Atribuir permissão**Quando assinalado, permite que os usuários do grupo consigam visualizar a opção Permissões do *widget* e atribuir permissão para demais usuários.

**Alterar widget**Quando assinalado, permite que os usuários do grupo consigam alterar o *widget* na plataforma.

Para remover o relacionamento do grupo de usuários com o *widget*, caso necessário, basta selecioná-lo e clicar em **Remover**.

**05.** Clique na aba **Por papel**.

**06.** Clique em **Adicionar** para relacionar um papel e definir as permissões que ele terá no *widget.*

**07.** Assinale as permissões desejadas.

As opções de permissão disponíveis são:

**Visualizar widget**Quando assinalado, permite que o papel consiga visualizar essa *widget* na plataforma.

**Atribuir permissão**
Quando assinalado, permite que o papel consiga visualizar a opção Permissões do *widget* e atribuir permissão para demais usuários.

**Alterar widget**
Quando assinalado, permite que o papel consiga alterar o *widget* na plataforma.

Para remover o relacionamento do papel com o *widget*, caso necessário, basta selecioná-lo e clicar em **Remover**.

**08.** Clique na aba**Por usuário.**

**09.** Clique em **Adicionar** para relacionar um usuário e definir as permissões que ele terá no *widget*.

**10.** Assinale as permissões desejadas.

As opções de permissão disponíveis são:

**Visualizar widget**Quando assinalado, permite que o usuário consiga visualizar essa *widget* na plataforma.

**Atribuir permissão**Quando assinalado, permite que o usuário consiga visualizar a opção Permissões do *widget* e atribuir permissão para demais usuários.

**Alterar widget**Quando assinalado, permite que o usuário consiga alterar o *widget* na plataforma.  

Para remover o relacionamento do usuário com o *widget*, caso necessário, basta selecioná-lo e clicar em **Remover**.

**11.** Depois de definir as permissões para grupos, papéis e usuários para o *widget*, clique em **Aplicar alterações**.

**12.** Na mensagem apresentada, clique em **Confirmar** para efetivar as permissões atribuídas ao *widget*.
