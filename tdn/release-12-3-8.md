# Release 12.3.8

Este documento contém breves descritivos acerca das implementações e correções efetuadas no pacote **12.3.8**.

## Implementações

#### TOTVS | ESB Plugin e TOTVS | ESB Server

**Função: Lançamento de exceção**

**Situação**: Não era possível criar um diagrama para lançamento de exceção planejada.

**Solução**: Foi adicionado o recurso *Throw Exception* (Lançar Exceção).

**Função: Atualização das bibliotecas**

**Situação**: O motor Camel do ESB e diversas outras bibliotecas estavam desatualizadas, impedindo algumas inovações.

**Solução**: Foram atualizados o motor Camel do ESB e todas as bibliotecas para as versões mais recentes.
