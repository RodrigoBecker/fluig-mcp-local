# Aplicativos Móveis - Protheus 12

- BackOffice ProtheusMeus Contratos

Agroindústria
- Beneficiamento de Algodão
- Minha Coleta de Fardões

Para utilizar os aplicativos móveis Protheus listados acima, é necessário: 

- Possuir licenças disponíveis, de acordo com cada aplicativo (para mais informações sobre o licenciamento, **consulte seu Executivo de Soluções de Negócios).**
- Protheus em versão não expirada (cada versão do Protheus liberará funcionalidades mais recentes dos aplicativos), para os apps que não o Analytics.
- Acesso ao Smart Analytics ou ao Fast Analytics, para o app Analytics.
- Ter o módulo correspondente implantado e funcional via SmartClient.
- Possuir o REST configurado no ambiente Protheus (instruções para configuração em: [Configuração do REST Protheus para uso com os aplicativos Mobile](/pages/viewpage.action?pageId=519719292)).
- Utilizar as integrações (REST) entre Protheus e aplicativos móveis **com a autenticação habilitada**.

Após ter seu ambiente configurado corretamente, para alguns aplicativos, é necessário solicitar à TOTVS um **ALIAS de acesso**. Este ALIAS é gerado sem custo e pode ser obtido através [deste link (como obter um ALIAS no TOTVS Mingle).](/pages/viewpage.action?pageId=286515823)

Os aplicativos móveis podem ser instalados em versão de sistema operacional Android e alguns possuem liberação para dispositivos iOS.

As versões mínimas de sistemas operacionais necessárias são:

Android 4.4.1 ou superior

iOS 7 ou superior

Entretanto, as funcionalidades são homologadas sempre, e somente, nas versões mais recentes dos sistemas operacionais, sendo esta necessária para uso de todos os recursos.

IMPORTANTE

A TOTVS **não homologa nem indica aparelhos para uso com os aplicativos móveis**, nem se responsabiliza caso o aparelho adotado pelo usuário não possua os recursos mínimos para utilização de todos os recursos disponíveis nos aplicativos.
