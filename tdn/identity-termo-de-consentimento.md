# Identity | Termo de consentimento

# Falando de termo de consentimento...

---

O termo de consentimento é um documento escrito com o objetivo de apresentar as cláusulas para garantir que o usuário esteja ciente de suas responsabilidades e das responsabilidades da empresa, das regras de uso do sistema, da privacidade dos seus dados pessoais, entre outras informações.

Quando o termo de consentimento está configurado para a empresa, cada usuário só conseguirá acessar os recursos do Identity se o termo for aceito. Caso o termo seja recusado, o usuário é redirecionado para a tela de login, e o termo continuará sendo apresentado nas próximas autenticações, até que seja aceito.

Além disso, cada vez que o documento vinculado como termo de consentimento for alterado, ele será novamente repassado para aceite dos usuários.

## Aceitar termo de consentimento

---

**01.** Após autenticar-se no sistema, baixar o termo de consentimento para a leitura.

**02.** Acionar **Aceitar**.

Após esse aceite, o usuário será direcionado para o [Launchpad](https://tdn.totvs.com/x/8ppUE). 

## Recusar termo de consentimento

---

**01.** Após autenticar-se na plataforma, realizar a leitura do termo de consentimento.

**02.** Acionar **Recusar**.

Enquanto o usuário não der seu aceite, o usuário será direcionado para a tela de login e não conseguirá acessar o sistema.

## Configurar termo de consentimento

---

O termo de consentimento é um documento configurado pela administração da empresa. As instruções para configurar o termo estão na documentação de [Dados e privacidade](https://tdn.totvs.com/x/C5JvI).

**Atenção!**
Após realizar o upload do **termo de consentimento**, não será possível removê-lo, somente alterá-lo.
