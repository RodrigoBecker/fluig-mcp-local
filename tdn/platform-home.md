# Platform ❙ Home

# Speaking of Home...

---

Home (Homepage) is intended for gathering the users' most used features. The user can define specific widgets (for example: widgets for pending items, popular documents, wall) to be displayed when they access Home, that is, after logging in or pressing the Home button in the main menu. 

As the company administrator edits the Homepage, they can customize the displayed layout and widgets as they choose to. Only the company administrator can edit the Homepage.

For more information about the Homepage structure, see [Layout](/pages/viewpage.action?pageId=236430048), [Slots](/pages/viewpage.action?pageId=236430047) and [Widgets](/pages/viewpage.action?pageId=236430046).

## Acess Home

---

**01.** Click on ![](/download/attachments/236429027/%C3%ADcone-home.png?version=1&modificationDate=1763733734043&api=v2) **Home** in the main menu.

Since it is the main page of the platform, the Home page can be viewed right after authentication – *login* – or from the **Home** option in the main menu.

**02.** View the content available on the main page of the platform (Home) that was defined by the company administrator and is usually the items that users access and use the most on a daily basis.

## Edit Home

---

Only those with permissions can edit the Home page.

**01.** Click on ![](/download/attachments/236429027/%C3%ADcone-home.png?version=1&modificationDate=1763733734043&api=v2) **Home** in the main menu.

 **02. **Click on **Edit page**.

When pressing this option, the Home page is displayed in edit mode, which allows the administrator user to change the layout and the widgets allocated in the slots of the page. For more details about the actions available when editing it, see [Edit page](/pages/viewpage.action?pageId=236430042).

Attention!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
