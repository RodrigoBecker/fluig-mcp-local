# Platform ❙ Evaluations

In the evaluations area, users can also manage available evaluations, evaluation questions, and evaluation application scheduling.

The evaluations area includes the following tabs:

- [Evaluations](/pages/viewpage.action?pageId=236429869): it allows for managing evaluations, i.e., creating , editing, deleting, disabling, previewing new evaluations, and viewing their versions;

- [Blocks](/pages/viewpage.action?pageId=236429872): it allows for managing question blocks, which are groups of questions for which weights within a specific evaluation can be assigned;

- [Topics and questions](/pages/viewpage.action?pageId=236429874): it allows for managing the catalog of available topics and questions. Questions are separated by topics, in which they can be managed and the use permissions can be assigned;

- [Sets of alternatives](/pages/viewpage.action?pageId=236429893): it allows for managing templates of alternatives; that is, a group of predefined alternatives that can be used in multiple questions.

- [Grading](/pages/viewpage.action?pageId=236429862): it is where evaluation graders can access essay questions;

- [History](/pages/viewpage.action?pageId=236429864): it allows for viewing all the evaluations taken by the authenticated users, as well as the ones they are grading;

- [Scheduling](/pages/viewpage.action?pageId=236429902): this area allows users to monitor the status of evaluation applications (i.e. completed, scheduled or canceled evaluations) and schedule new applications.
