# Identity | Como importar dados exportados a partir dos relatórios do Identity para o Excel 2013?

**Dúvida**

Como importar dados exportados a partir dos relatórios do Identity para o Excel 2013?

**Solução**

Os relatórios CSV do Identity são exportados na codificação Unicode (UTF-8).

Para importar os dados para uma planilha Microsoft Excel 2013, siga os passos abaixo:

**01.** Abra uma nova planilha em branco no **Microsoft Excel 2013**.

**02.** Clique sobre a aba **Dados** do menu superior.

**03.** Selecione a opção **De Texto**.

**04.** Navegue até a pasta em que o relatório exportado está salvo e selecione-o para importação.

**05.** Na etapa 1, selecione **65001 : Unicode (UTF-8)** no campo **Origem do arquivo** e clique em **Avançar**.

**06.** Na etapa 2, marque o delimitador **Ponto e vírgula** e clique em **Avançar**.

**07.** Na etapa 3, selecione **Concluir** para importar os dados.

**08.** Por último, pressione **OK** para que os dados sejam aplicados na célula selecionada.
