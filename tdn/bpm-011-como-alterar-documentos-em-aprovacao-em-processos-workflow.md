# BPM 011 - Como alterar documentos em aprovação em processos workflow?

# Índice

# Plataforma

**Produto:  **fluig

**Versão: **Todas as versões

# Ocorrência

Publicamos um documento em uma pasta que já havia *workflow* cadastrado, porém a pessoa que publicou o documento precisou efetuar uma revisão no documento. 

Quando o documento é publicado em uma pasta de *workflow* ele só aparece quando é aprovado, como foi preciso fazer esta revisão não conseguimos achar o documento no sistema para apagá-lo e publicar posteriormente o arquivo revisado. 

Gostaríamos de saber onde ficam localizados os arquivos em aprovação. Não conseguimos localizar para apagar o documento. Qual procedimento devemos tomar para estes casos?

# Causa

Processo em andamento.

# Solução

Para liberar o acesso ao documento ele deve ser Aprovado ou Reprovado, antes desta ação o mesmo fica no fluxo de aprovação não permitindo alterações. 

Após a ação (Aprovado ou Reprovado) o documento fica visível na pasta de origem.
