# LMS 019 - Por que um bloco existente não é exibido na criação de uma avaliação?

# Índice

# Plataforma

**Produto:**TOTVS Fluig Plataforma

**Card:** LMS

# Ocorrência

Durante a criação de uma avaliação, ao tentar importar um bloco existente, os blocos criados não são listados.

# Solução

Para que os blocos já existentes sejam listados na criação da avaliação é preciso que, pelo menos, uma versão deles esteja liberada.

Quando um bloco é criado, por padrão, a sua versão fica no modo de edição. Quando o bloco estiver completo é preciso liberar a versão para que esteja disponível para uso.

Para liberar a versão do bloco, no menu principal acione **Avaliações** e, em seguida, **Administrar** > **Blocos**. Depois de acessar a janela de blocos, siga os passos descritos em [Liberar versão de bloco](https://tdn.totvs.com/pages/viewpage.action?pageId=233766580#Plataforma%E2%9D%99Blocos-Liberarvers%C3%A3odebloco).

Se você não lembra se o LMS está incluso ou não no seu pacote, consulte sua proposta comercial ou entre em contato com o seu ESN.
