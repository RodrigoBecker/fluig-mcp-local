# BPM 060 - Como obter os processos da Experiência de Uso Datasul?

# Índice

# Plataforma

**Produto:  **fluig

# Ocorrência

Como realizar download das experiências de uso (free) para utilizá-las no fluig, como por exemplo: Solicitação de férias, desligamento, treinamento, justificativa de ponto e requisição de pessoal.

# Solução

Estes workflows fazem parte do produto Datasul e já estão embutidas no produto. Para utilizá-las, é necessário realizar as configurações de acordo com a documentação [Instalação de Workflow](https://tdn.totvs.com/x/ab5ICw).
