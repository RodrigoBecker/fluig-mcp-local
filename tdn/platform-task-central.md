# Platform ❙ Task Central

# Index

## Speaking of Task Central...

The Task Central item lists the tasks in which the user is engaged as either a requisitioner, user in charge, manager, author, or approver. Since TOTVS Fluig Platforma allows automating processes and controlling documents, as well as delegating tasks to users, this feature includes all user requests or pending tasks.

The Task Central consists of the following tabs:

- [Task summary](/pages/viewpage.action?pageId=236429490): it shows an overview of the tasks associated with the user, through charts and captions.

- [Due tasks](/pages/viewpage.action?pageId=236429493): it shows all the tasks originated in process requests and assigned to the respective user;

- [Pooled tasks](/pages/viewpage.action?pageId=236429498): it displays the tasks that are under the responsibility of a group of users and not just to the authenticated user or the one being substituted;

- [Tasks in consensus](/pages/viewpage.action?pageId=236429502): it shows all the tasks originated in process requests, but which do not depend solely on a single user;

- [My requests](/pages/viewpage.action?pageId=236429506): it shows all ongoing process requests submitted by the respective user.

- [My tasks under management](/pages/viewpage.action?pageId=236429516): it shows all the tasks for processes in which the user is assigned as the manager;

- [My documents](/pages/viewpage.action?pageId=236429518): it shows documents posted by the user that are currently awaiting approval;

- [Documents to approve](/pages/viewpage.action?pageId=236429522): it presents the tasks originated in document posting. These posts require the respective user’s approval;

- [Documents in consensus](/pages/viewpage.action?pageId=236429525): it shows the documents that have more than one approver, one of whom is the respective user that has already approved the document, while the approval from the other approvers is pending.

- [Documents in checkout](/pages/viewpage.action?pageId=236429528): it displays all the documents that have been checked out by the user, that is, have been transferred to the private folder, not allowing any other user to change the respective document.

In the Task Central, features such as the following are also available:

- [Filters](/pages/viewpage.action?pageId=236429456): they allow limiting the information displayed on screen, making it easier to find and view it. Such data restriction is applied by entering values used as criteria to select data;

- [Substitutes](/pages/viewpage.action?pageId=236429486): a feature that allows the substitute user to become responsible for the substituted user’s tasks, including pool and manager tasks.
