# Platform ❙ Collaborative editing -CP

# Speaking of collaborative editing...

---

This feature allows you to enable the collaborative editing of documents through Google Drive.

Besides being another editing option, the collaborative editing allows the document to be changed by multiple users, which may contribute to its drafting, making the process more collaborative.

Important!

To have this feature displayed, it is first necessary to install the integration artifact. More details in [Collaborative editing with Google Drive](https://tdn.totvs.com/x/ukQYDQ). After completing these procedures, this feature will be displayed in the **Applications container** of the Control Panel.

Users must have a Google account to be able to edit documents using this feature.

![](/download/attachments/236429950/Collaborative%20editing.png?version=2&modificationDate=1767378110360&api=v2)

## Collaboratively edit a document

---

**01.** In the main menu, click ![](/download/attachments/236429950/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1767377917977&api=v2) **Control Panel**.

**02.** Locate the **Applications** group.

**03.** Click ![](/download/attachments/236429950/%C3%ADcone-edi%C3%A7%C3%A3o-colaborativa.png?version=1&modificationDate=1767377827973&api=v2) **Collaborative editing**.

**04.** Define the requested information.

The requested information is:

**Enable Google Drive**
When enabled, it determines that the feature for collaborative editing of documents through Google Drive is active on the platform. In this case, the button is presented with the call **ON**, stating that the feature is active. When activated to disable the feature, the button is presented with the call **OFF**, meaning that the feature is disabled.

**Customer ID**
Customer code obtained when configuring Google Drive. Information on settings can be obtained from [Collaborative editing with Google Drive](https://tdn.totvs.com/x/ukQYDQ).

**Customer secret**
Customer secret key obtained when configuring Google Drive. Information on settings can be obtained from [Collaborative editing with Google Drive](https://tdn.totvs.com/x/ukQYDQ).

**Redirection URI**
Redirect URL that is requested when configuring Google Drive. Information on settings can be obtained from [Collaborative editing with Google Drive](https://tdn.totvs.com/x/ukQYDQ).

**05.** Press **Test connection** to test the validity of informed codes.

**06.** Click on **Save**.

Please note!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
