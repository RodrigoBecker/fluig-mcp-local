# Siscomex Web Importação

Quando o Protheus é executado em Sistema Operacional "Windows 10", é necessário atentar-se para as configurações abaixo.

O Protheus deve utilizar a versão do Java instalado pelo usuário que encontra-se, geralmente, no diretório “C:\Program Files\Java”, desta forma é possível efetuar a configuração abaixo para que o Protheus execute a versão correta ao efetuar a integração dos arquivos para o Siscomex.

**Procedimentos para Utilização:**

1. No Easy Import Control (SIGAEIC) acesse Atualizações / Integ. Siscomex Web. (EICDI100)
2. Na parte inferior da tela, clique em Ações/Configurações.![](/download/attachments/235335670/1.png?version=1&modificationDate=1460570655000&api=v2)
3. Clique no botão “...” para informar o diretório onde encontra-se o executavel Java "java.exe".![](/download/attachments/235335670/2.png?version=1&modificationDate=1460570656000&api=v2)
4. Informe o diretório onde encontra-se o “java.exe”. Exemplo: “C:\Program Files\Java\jre7\bin\java.exe”.
5. Clique em Salvar.![](/download/attachments/235335670/3.png?version=1&modificationDate=1460570658000&api=v2)
6. O diretório será informado no campo abaixo:![](/download/attachments/235335670/4.png?version=1&modificationDate=1460570659000&api=v2)
7. Clique em Confirmar.
8. Com este procedimento, o Protheus utilizará o Java informado pelo usuário para executar a transmissão dos arquivos ao Siscomex Web Importação.
