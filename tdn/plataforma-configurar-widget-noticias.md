# Plataforma ❙ Configurar widget Notícias

# Falando de configurar widget Notícias...

---

A configuração do *widget* Notícias permite definir o *link* para o formulário que contém os registros de notícias, configurar a quantidade de registros listados e como serão ordenados, bem como se o *widget* deve ou não ser exibido no aplicativo móvel.

Importante!

Para que esse *widget* seja exibido na lista de *widgets* disponíveis para páginas, primeiramente é necessário obter o artefato Kit Intranet do diretório [Git](https://git.fluig.com/projects/SAMPLES/repos/kit-intranet/browse). Depois, é necessário importar o artefato em [Importar e exportar páginas](/pages/viewpage.action?pageId=234455771). Após efetuados esses procedimentos, o *widget* estará disponível para utilização.

Mais informações podem ser obtidas em [Kit Intranet](https://tdn.totvs.com/x/nbBICw).

## Configurar widget Notícias

---

**01.** Edite a página onde será inserido o *widget* **Notícias.**

**02.** Inclua o *widget* no *slot* pretendido.

**03.** Defina as configurações desejadas.

**Link do formulário***Link* do formulário que contêm os registros de formulários das notícias que serão publicadas.

**Limite de registros**Quantidade de registros listados pelo *widget*.

**Ordenar registros por**

- **Id do documento**: as notícias serão apresentadas em ordem crescente a partir do código do registro;
- **Ordem alfabética (A - Z)**: as notícias serão apresentadas em ordem alfabética de A a Z;
- **Ordem alfabética (Z - A)**: as notícias serão apresentadas em ordem alfabética de Z a A;
- **Mais antigos**: as notícias serão apresentadas das mais antigas para as mais recentes;
- **Mais recentes**: as notícias serão ordenadas das mais recentes para as mais antigas.

**04.** Clique em **Salvar.**

**05**. Publique a página.

Fique atento!

Esta documentação é válida a partir da atualização **Voyager (2.0)**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
