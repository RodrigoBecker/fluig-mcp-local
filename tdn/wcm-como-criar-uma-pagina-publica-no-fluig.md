# WCM - Como criar uma página pública no Fluig?

# Índice

# Plataforma

**Produto:**TOTVS Fluig Plataforma

# Ocorrência

Como criar uma página pública no Fluig Plataforma?

# Solução

Uma página pública pode ser acessada por qualquer usuário, pois não exige a autenticação na plataforma. A partir da **atualização 1.6.5 (Liquid) **a construção de páginas pode ser realizada pelo recurso [Pages Beta](https://tdn.totvs.com/x/qwqVGQ), que oferece templates e componentes de modo a facilitar a construção de modernas páginas públicas. Assista ao vídeo para conhecer melhor esse recurso.

Se a sua plataforma estiver em uma atualização anterior a essa, ou caso prefira, você pode utilizar o recurso [Minhas páginas](/pages/viewpage.action?pageId=234455763), e criar a página pública seguindo os passos abaixo:

- [Passo 2](#)
- [Passo 3](#)
- [Passo 4](#)
- [Passo 5](#)
- [Passo 6](#)
- [Passo 7](#)

 - Após efetuar o *login* com um usuário administrador, acesse o recurso **Minhas Páginas**, disponível no agrupador **Personalização** do **Painel de Controle**.

Em atualizações anteriores a Liquid (1.6.5), esse recurso ficava na aba **WCM**do**Painel de Controle.**

![](/download/attachments/287053756/Image%20001.png?version=1&modificationDate=1551443819267&api=v2)

 - Clique em **Adicionar**, para inserir uma nova página.

![](/download/attachments/287053756/Image%20002.png?version=1&modificationDate=1551443875837&api=v2)

 - Selecione o *layout* de sua preferência e que se adeque melhor ao propósito da página.

![](/download/attachments/287053756/Image%20003.png?version=1&modificationDate=1551443988917&api=v2)

 - Informe um Título para a página.

 - Uma descrição, informando qual será o assunto abordado.

 - Um identificador, que será utilizado posteriormente para acessar a pagina.

 - Selecione a opção PUBLIC no campo autorização para que todos os usuários possam ter acesso.

 - E habilite as opções necessárias de acordo com as funcionalidades desejadas.

![](/download/attachments/287053756/Image%20004.png?version=2&modificationDate=1551444020450&api=v2)

Se a opção PUBLIC não for selecionada no campo Autorização, a página será visível apenas para usuários que possuem acesso ao Fluig Plataforma.

 - Após concluir o registro da nova página, adicione *widgets* de acordo com o *layout* escolhido e publique a página.

Alguns widgets podem exigir autenticação. Portanto para o correto funcionamento, adicione widgets que não precisam de autenticação para que a página pública apresente o comportamento correto.

![](/download/attachments/287053756/Image%20005.png?version=2&modificationDate=1551444058473&api=v2)

 - Após publicar a página, aparecerá a visualização em modo privado, para usuários que possuem a plataforma.

 - Para visualizar a página em modo público, é necessário sair da plataforma e digitar o endereço da página sem a letra **p**, que se encontra logo após a palavra portal, pois a letra p é o indicativo de que a página esta em modo privado. 

![](/download/attachments/287053756/Image%20006.png?version=2&modificationDate=1551446873220&api=v2)

 - Visualização da página pública.

![](/download/attachments/287053756/Image%20007.png?version=1&modificationDate=1551446905057&api=v2)

## Alterar páginas privadas para púbicas

Também é possível modificar a autorização de uma página privada para pública:

- [Passo 1](#)
- [Passo 2](#)
- [Passo 3](#)

 - Após efetuar o *login* com um usuário administrador, acesse o recurso **Minhas Páginas**, disponível no agrupador **Personalização** do **Painel de Controle**.

Em atualizações anteriores a Liquid (1.6.5), esse recurso ficava na aba **WCM**do**Painel de Controle.**

![](/download/attachments/287053756/Image%20001.png?version=1&modificationDate=1551443819267&api=v2)

 - Selecione a página desejada e clique em **Editar.**

![](/download/attachments/287053756/Image%20008.png?version=1&modificationDate=1551447354770&api=v2)

 - Altere o campo **Autorização** para PUBLIC.

![](/download/attachments/287053756/Image%20009.png?version=2&modificationDate=1551901373070&api=v2)

 - Após a conclusão, sua página já poderá ser acessada publicamente.
