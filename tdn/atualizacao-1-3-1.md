# Atualização 1.3.1

Confira abaixo as novidades na atualização 1.3.1 do Fluig:

# Arquitetura

**Otimização Fluig e banco de dados SQL Server**

Otimizamos o processo de atualização do Fluig 1.3.1 para clientes que utilizam banco de dados SQL Server 2008, permitindo a atualização e utilização de todos os benefícios e novidades da última atualização do Fluig.

# Atualização

**Melhoria nas etapas de atualização**

Foi aprimorado o processo de atualização do Fluig. Agora é possível realizar a atualização do Fluig para a atualização 1.3.1 com mais facilidade.
