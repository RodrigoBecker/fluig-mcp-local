# Platform ❙ Processes

# Index 

## Speaking of Processes...

Processes are developed to automate specific actions within the company (e.g. trip or purchase requests). In addition to configuring processes, you can also start, query, handle, convert, and delete requests.

The Processes area consists of:

- [Start requests](/pages/viewpage.action?pageId=236429393): it allows starting requests related to configured and released processes;

- [Configure processes](/pages/viewpage.action?pageId=236429375): in this space, you can create and edit processes by adding and configuring activities, flows, and properties, as well as link or change the form linked to the process;

- [Query requests](/pages/viewpage.action?pageId=236429401): it allows querying requests that are in progress, completed, or cancelled. The company administrator has permission to query all requests, while users can query only public requests or the ones in which they have participated;

- [Delete requests](/pages/viewpage.action?pageId=236429410): it allows the user who started a request, the process manager or the system administrator to delete finished and canceled requests;

- [Convert requests](/pages/viewpage.action?pageId=236429425): a feature to convert requests opened in older process versions to newer versions. After being converted, the request will have the same activities and settings as the version to which it was converted (except for the form, which is not changed);

- [List tasks](/pages/viewpage.action?pageId=236429436): it allows you to configure a specific list on a specific subject, and later allows you to associate activities and define people in charge to assist in completing this task.
