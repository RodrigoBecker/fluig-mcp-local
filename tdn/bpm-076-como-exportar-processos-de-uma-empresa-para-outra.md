# BPM 076 - Como exportar processos de uma empresa para outra?

# Índice

# Plataforma

**Produto:  **fluig

# Ocorrência

Temos vários processos na empresa 1 e agora criamos a empresa 2. Como migrar os processos de uma empresa para a outra?

# Solução

Para que os processos da empresa 1 também estejam na empresa 2, é necessário importá-los para o [Fluig Studio](/display/fluig/Fluig+Studio) e então exportá-los para a empresa 2. 

Atenção!

Importante mencionar que a transferência de processos somente pode ser feita através do fluig Studio seguindo os passos abaixo.

Veja o passo a passo de como exportar os processos para sua segunda empresa:

- [Passo 1](#)
- [Passo 2](#)
- [Passo 3](#)

 - Faça a importação do processo para o fluig Studio conforme a documentação [Importando processos](/display/fluig/Importando+processos).

![](/download/attachments/267789949/Image%204.jpg?version=1&modificationDate=1507292748000&api=v2)

  - Caso possua formulário em seu processo, é preciso fazer a definição dele. Deve colocar a definição como Local, para depois poder exportar.![](/download/attachments/267789949/2.png?version=1&modificationDate=1476387740000&api=v2)

 - Agora deve exportar para empresa 2. Para realizar a exportação veja a documentação [Exportando processos](/display/fluig/Exportando+processos).

Observação

Para fazer a exportação para empresa 2, você deve criar um servidor no fluig Studio para empresa 2. Verifique na documentação [Criando um projeto fluig no Studio](/display/fluig/Criando+um+projeto+fluig+no+Studio), no tópico Cadastrando o servidor fluig, onde o usuário e senha informados devem ser da empresa 2.
