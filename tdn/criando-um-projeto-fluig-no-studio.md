# Criando um projeto fluig no Studio

# Índice

# Objetivo

O objetivo desse guia é apresentar os passos necessários para criar um projeto fluig no Studio.

# Pré-requisito

É necessário instalar o [fluig Studio](/pages/viewpage.action?pageId=73078179) para criar seu projeto fluig.

# Acessando perspectiva fluig

Para acessar a perspectiva fluig, efetue os passos a seguir:

- [Passo 1](#)
- [Passo 2](#)

Após instalar o fluig Studio, acesse a perspectiva fluig de trabalho. Para isso, acesse o menu “Janela”, depois “Abrir perspectiva” e, por fim, acesse o item “outras “.

![](/download/attachments/185735250/a1.png?version=1&modificationDate=1439842063000&api=v2)

**Figura 1 - Abrir perspectiva**

Na tela exibida, selecione a perspectiva “fluig” e confirme a opção.

![](/download/attachments/185735250/a2.png?version=1&modificationDate=1439842073000&api=v2)

**Figura 2 - Perspectiva fluig**

## Cadastrando o servidor fluig

Para cadastrar o servidor fluig, efetue os passos a seguir:

- [Passo 1](#)
- [Passo 2](#)
- [Passo 3](#)

Com a perspectiva fluig aberta, o primeiro passo recomendado é o cadastro do fluig *Server*. Para cadastrar um servidor, acesse a aba de servidores do fluig chamada "fluig *Servers*". Sobre o ícone da lista de servidores, clique com o botão direito do *mouse*, abrindo o menu de contexto selecione o submenu “fluig” e, por fim, a opção “fluig *Server*”.

![](/download/attachments/185735250/b1.png?version=1&modificationDate=1439842082000&api=v2)

**Figura 1 - Opção fluig Server**

Informe os dados solicitados conforme apresentado na figura abaixo. Forneça o endereço *host* (IP ou nome DNS válido), SSL (opcional), porta, usuário e senha.

Integração com fluig Identity

Caso tenha configurada a autenticação integrada com o fluig Identity, forneça o endereço de email e senha de acesso ao Identity nos campos Usuário e Senha para conexão ao servidor fluig.

![](/download/attachments/185735250/Captura%20de%20Tela%2015_12%20001.png?version=1&modificationDate=1481813555000&api=v2)

**Figura 3 - Dados do servidor**

Confirme o cadastro e acione duplo clique no servidor recém cadastrado para verificar o acesso da IDE a ele. Depois, uma mensagem será exibida confirmando que a operação foi bem sucedida.

![](/download/attachments/185735250/servidor_fluig_conectado.png?version=1&modificationDate=1456173606000&api=v2)

**Figura 4 - Confirmação de conexão com o servidor criado**

## Criando um projeto fluig

Efetue os passos a seguir para criar um projeto fluig:

- [Passo 1](#)
- [Passo 2](#)

Agora vamos criar um projeto fluig que irá abrigar processos *workflow*, formulários, relatórios e *scripts* de desenvolvimento sobre a plataforma. Para criar um projeto fluig, acesse a aba “Explorador de pacote” ou “*Package Explorer*” e clique com o botão esquerdo do mouse na área em branco do explorador de pacotes. Então, selecione o menu “Novo” e o item “Projeto fluig”, conforme a figura abaixo:

![](/download/attachments/185735250/c1.png?version=1&modificationDate=1439842121000&api=v2)

**Figura 1 - Aba Explorador de pacote**

Informe o nome do seu projeto e clique em Concluir.

![](/download/attachments/185735250/c2.png?version=1&modificationDate=1439842147000&api=v2)

**Figura 2 - Novo projeto fluig**
