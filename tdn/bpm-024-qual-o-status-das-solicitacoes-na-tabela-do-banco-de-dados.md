# BPM 024 - Qual o status das solicitações na tabela do banco de dados?

# Índice

# Plataforma

**Produto:  **fluig

**Versão: **Todas as versões

# Ocorrência

Quais são os valores do campo IDI_STATUS na tabela TAR_PROCES?

# Solução

O status da solicitação (IDI_STATUS) é gravado conforme descrição abaixo:

0 - Não completada 
1 - Pendente de consenso 
2 - Concluída 
3 - Transferida 
4 - Cancelada
