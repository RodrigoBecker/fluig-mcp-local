# Platform ❙ Configuration of audit events

# Speaking of configuration of audit events...

---

Use this page to configure the [Audit events](https://tdn.totvs.com/x/WANZGg) feature specifically for each company registered in the platform. A special **Audit Events** license is required to use this feature, which you can obtain from the sales team. Refer to the technical document [Audit events](https://tdn.totvs.com/x/UhqbEg) to learn more about this feature.

![](/download/attachments/550332532/Configura%C3%A7%C3%A3o%20Eventos%20Auditoria.png?version=3&modificationDate=1765289808220&api=v2)

## Access configuration of audit events

---

**01.** Access the platform with the **wcmadmin** user.

**02**. In the main menu, click ![](/download/attachments/550332532/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1765289461153&api=v2) **Control Panel**.

**03.** Locate the **General** group.

**04.** Click ![](/download/attachments/550332532/%C3%ADcone-eventos-auditoria.png?version=1&modificationDate=1765289371270&api=v2)** Configuration of audit events**.

**05**. In the Configuration of audit events page, select the company for which you will perform the configuration. 

Current settings are loaded after selecting the company.

## Edit configuration of audit events

---

**01.** Access the platform with the **wcmadmin** user.

**02**. In the main menu, click ![](/download/attachments/550332532/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1765289461153&api=v2) **Control Panel**.

**03.** Locate the **General** group.

**04.** Click ![](/download/attachments/550332532/%C3%ADcone-eventos-auditoria.png?version=1&modificationDate=1765289371270&api=v2)** Configuration of audit events**.

**05.** Select the company for which the settings will be edited.

**06. **Define the desired settings to enable Audit Events.

Current settings are loaded after selecting the company. You can configure the following settings:

**Enable audit events?******By enabling this feature (ON), the platform records all changes made to features such as roles, users, groups, processes, documents, among others.

**Keep data history by******This field is only showed if the audit event register is enabled for the company. It defines for how long history data are kept. The options are: 1 month, 2 months, 4 months, 6 months, 1 year or permanently. Records are automatically deleted upon reaching the deadline.

Important!

The **Permanent** value in this field indicates that the data will never be removed from the query, which could generate a significant volume of records in your database.

**Enable audit events for personal data?**By enabling this option (ON), the platform records all queries, changes and deletions of fields registered as personal data. 

**Keep data history by******This field is only showed if the personal data audit event register is enabled for the company. It defines for how long history data are kept. Available options: 5 years, 10 years, 15 years, or permanently. Records are automatically deleted upon reaching the deadline.

**07**. Click **Save**.

## Disable audit events

---

**01.** Access the platform with the **wcmadmin** user.

**02**. In the main menu, click ![](/download/attachments/550332532/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1765289461153&api=v2) **Control Panel**.

**03.** Locate the **General** group.

**04.** Click ![](/download/attachments/550332532/%C3%ADcone-eventos-auditoria.png?version=1&modificationDate=1765289371270&api=v2)** Configuration of audit events**.

**05.** Select the company for which the settings will be edited.

**06.**Click the button on the field **Enable audit events**to disable the feature. **OFF **will be displayed.

**07**. Click **Save**.

Attention!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
