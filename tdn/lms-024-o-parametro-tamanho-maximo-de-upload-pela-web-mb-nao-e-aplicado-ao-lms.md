# LMS 024 - O parâmetro "Tamanho máximo de upload pela Web (MB)" não é aplicado ao LMS?

# Índice

# Plataforma

**Produto:**TOTVS Fluig Plataforma****

**Card:** LMS

# Ocorrência

Foi possível criar um vídeo e disponibilizar nos conteúdos de aprendizado mesmo com o arquivo ultrapassando o limite do tamanho máximo de *upload* pela Web definido nos parâmetros gerais. Essa configuração não é respeitada no LMS? Caso não, existe alguma forma de restringir isso?

# Solução

Esta configuração não é válida para o LMS. Atualmente, não é possível restringir o tamanho de upload de um arquivo pela Web.

Importante!

A partir da atualização **1.6.5-190219**, o **LMS** não faz mais parte da plataforma para **novas instalações**.

Mas, não se preocupe: se você adquiriu a plataforma com o **LMS incluso**, entre em contato com o [Suporte Fluig](https://suporte.fluig.com/) para que você consiga utiliza-lo normalmente – mesmo após a atualização **1.6.5-190219**. Se você não lembra se o LMS está incluso ou não no seu pacote, consulte sua proposta comercial ou entre em contato com o seu ESN.
