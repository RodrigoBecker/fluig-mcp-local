# Atualização 1.1.5

Confira abaixo as novidades na atualização 1.1.5 do Fluig:

# Administração

**Atualização Fluig: criação de novas páginas do sistema**
Nesta atualização do Fluig é possível garantir que todas as páginas de sistema estão disponíveis para uso. Em algumas situações ao atualizar do Fluig 1.0 para o Fluig 1.1, algumas páginas de sistemas não era criadas, fazendo com que alguns recursos não ficassem disponíveis para todos os usuários.
Para isso, acesse o gerenciamento de empresas do Fluig, edite a empresa desejada e acione a opção “Atualizar páginas da empresa”. Será verificado se existem páginas ausentes, para serem criadas. Não há nenhuma restrição em executar esta opção mais de uma vez.

![](/download/attachments/113803815/img1.png?version=1&modificationDate=1390920574000&api=v2)

# Studio

**Importação de processo no Fluig Studio**
Através do Fluig Studio nesta atualização do Fluig, é possível importar processos worfklow que possuam atividades automáticas sem mecanismo de atribuição definidos.

![](/download/attachments/113803815/img4.png?version=1&modificationDate=1390934501000&api=v2)

# ECM

**Receba notificações de aprovação de documento**
O usuário publicador de um documento que necessita de aprovação agora recebe um e-mail, assim que o documento é aprovado ou reprovado.

![](/download/attachments/113803815/img5.png?version=1&modificationDate=1390934517000&api=v2)

**Relatórios com conexão direta ao banco de dados**
É possível publicar relatórios que se comunicam diretamente com o banco de dados. Para mais informações, [clique aqui](https://tdn.totvs.com/pages/viewpage.action?pageId=74646056#DesenvolvimentodeRelatórios-Conexãodiretacomobancodedados).

# Social

**Visualize documentos de comunidades através do Fluig Mobile**
No Fluig Mobile, visualize corretamente a pasta configurada para documentos em uma comunidade.

![](/download/attachments/113803815/img2.png?version=2&modificationDate=1390934569000&api=v2)

**Crie enquetes em comunidades**
Nesta atualização do Fluig, a criação de formulários foi otimizada, evitando inconsistências com campos do tipo “Múltipla escolha”.

![](/download/attachments/113803815/img3.png?version=1&modificationDate=1390920626000&api=v2)
