# Plataforma ❙ Opções de permissão em widgets

# Falando de opções de permissão em widgets...

---

As opções de permissão existentes são as mesmas para cada um dos *widgets* e são detalhadas a seguir.

![](/download/attachments/285640267/Permiss%C3%B5es%20164.png?version=3&modificationDate=1749062349107&api=v2)

## Visualizar widget

---

Quando ativada, permite visualizar o *widget* em qualquer página na qual ele existir, desde que também tenha permissão para visualizar a página.

Por padrão essa permissão estará ativa para todos os *widgets*. Se for desejado ocultar um *widget* para um usuário, grupo ou papel, basta desativar essa permissão.

## Adicionar à página

---

Quando ativada, permite incluir o *widget* em páginas nas quais o usuário tenha permissão para modifica-las.

## Alterar widget

---

Quando ativada, permite alterar as configurações do *widget*– para *widgets* que possuem configurações próprias – dentro das páginas nas quais o usuário tenha permissão para modifica-las.

Fique atento!

Esta documentação é válida a partir da atualização **Voyager (2.0)**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
