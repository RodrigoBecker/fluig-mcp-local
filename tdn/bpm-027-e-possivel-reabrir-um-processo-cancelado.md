# BPM 027 - É possível reabrir um processo cancelado?

# Índice

# Plataforma

**Produto:  **fluig

**Versão: **Todas as versões

# Ocorrência

Finalizamos, erroneamente, um processo de não conformidade. Existe alguma forma de reabri-lo?

# Solução

Quando uma solicitação de processo é cancelada, não é possível reabri-la. Nestes casos deve-se iniciar uma nova solicitação.
