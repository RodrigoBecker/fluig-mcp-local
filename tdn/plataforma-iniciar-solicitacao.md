# Plataforma ❙ Iniciar solicitação

# Falando de iniciar solicitação...

---

Após o processo estar totalmente modelado e liberado para uso, os usuários com permissão podem iniciar solicitações. Cada solicitação criada seguirá exatamente as atividades e os fluxos definidos na versão vigente do processo no momento da criação, mesmo que novas versões sejam publicadas posteriormente.

![](/download/attachments/233763157/Iniciar%20Solicita%C3%A7%C3%B5es.PNG?version=2&modificationDate=1761650893187&api=v2)

Precisa de ajuda?

Acesse a central de ajuda da plataforma através do ícone ![](/download/attachments/233763157/question-off.png?version=1&modificationDate=1554225820960&api=v2), localizado no canto superior direito das páginas do menu Processos, para obter informações específicas sobre este recurso, além de*links* com documentações relacionadas. [Saiba mais](https://tdn.totvs.com/x/ZMhSDg).

## Boas-vindas à página de iniciar solicitações

---

Neste guia interativo, o usuário será guiado pelas principais funcionalidades, sendo recebido com um tour e uma breve descrição do que fazer e como se localizar na página de iniciar solicitações.

**Etapa 1 de 3:**

Aqui é mostrada a seção de últimos processos iniciados, que funciona como um atalho para iniciar novamente os últimos processos abertos.

[Ver imagem](https://tdn.totvs.com/download/attachments/974813305/Etapa%201.png?api=v2)

**Etapa 2 de 3:**

Já aqui, o usuário poderá visualizar suas últimas três solicitações abertas. Podendo ainda visualizá-las por completo em uma nova aba do navegador.

[Ver imagem](https://tdn.totvs.com/download/attachments/974813305/Etapa%202.png?api=v2)

**Etapa 3 de 3:**

E por fim, conseguirá visualizar todos os processos disponíveis para iniciar uma solicitação. Onde estarão organizados de acordo com suas categorias, podendo fazer uso dos filtros para encontrar o que precisa.

[Ver imagem](https://tdn.totvs.com/download/attachments/974813305/Etapa%203.png?api=v2)

Para voltar uma etapa, pressione o botão **Voltar**ou então acione **Concluir**, após finalizar as visualização de todas as etapas.

## Últimos processos iniciados

---

**01.** Na seção **Últimos processos iniciados**, serão exibidos os quatro últimos processos iniciados pelo usuário.

Ao acessar pela primeira vez, ela poderá estar vazia, pois os processos só são exibidos após terem sido iniciados pelo usuário. A partir daí, os processos passam a ser contabilizados, e os quatro últimos iniciados ficarão listados nessa área.

É possível definir um processo como favorito, para isso basta localizar o processo que deseja e acionar o ícone estrela![](/download/attachments/233763157/image-2025-8-15_10-3-41.png?version=1&modificationDate=1755611531907&api=v2). Automaticamente o ícone ficará destacado na cor amarela ![](/download/attachments/233763157/flaticon-star-active.png?version=1&modificationDate=1754595507650&api=v2), sinalizando aquele processo como favorito. 

Para removê-lo dos favoritos, clique no ícone de estrela ![](/download/attachments/233763157/flaticon-star-active.png?version=1&modificationDate=1754595507650&api=v2) — ele ficará cinza, indicando que o processo não está mais marcado como favorito.

## Últimas solicitações abertas

---

**01.** Na seção **Últimas solicitações abertas**, é possível visualizar as três últimas solicitações abertas pelo usuário. 

É possível ir direto para a Central de tarefas, clicando no ícone ![](/download/attachments/233763157/image-2025-8-15_9-41-22.png?version=1&modificationDate=1755611531970&api=v2)**Ir para Central de Tarefas**.

Para ir direto para a solicitação, basta clicar sobre o nome da solicitação ou então no acionar o ícone ![](/download/attachments/233763157/image-2025-8-15_9-43-52.png?version=1&modificationDate=1755611532050&api=v2) **Ir para a solicitação**.  

## Todos os processos

---

**01**. Na seção Todos os processos, é possível visualizar todos os processos disponíveis para iniciar uma solicitação. Eles estão organizados de acordo com suas categorias, para facilitar a visualização.

É possível pesquisar um processo específico pelo campo ![](/download/attachments/233763157/image-2025-8-15_10-12-2.png?version=1&modificationDate=1755611532117&api=v2)**Buscar processos**. A busca pode ser efetuada por processo, pela categoria ou pela subcategoria à qual o processo pertence.

Para filtrar os processos de acordo com a sua necessidade, basta acione o ícone![](/download/attachments/233763157/image-2025-8-15_10-14-4.png?version=1&modificationDate=1755611532203&api=v2) **Filtrar**:

- Apenas os processos favoritos
- Ver todos

Podendo ainda filtrar pelas categorias existentes.

A ordenação pode ser feita através do ícone ![](/download/attachments/233763157/image-2025-8-15_10-21-9.png?version=1&modificationDate=1755611532287&api=v2) **Ordenação**, podendo selecionar o tipo de ordenação que deseja nos processos: 

- Iniciados recentemente
- Ordem alfabética

 É possível ainda ocultar os processos da tela, deixando visível apenas as categorias. Para isso, acione o ícone de ![](/download/attachments/233763157/image-2025-8-15_10-26-9.png?version=1&modificationDate=1755611532347&api=v2) **Ocultar**. Para reverter, basta acionar novamente o ícone para que os processos voltem a aparecer.

É possível definir um processo como favorito, para isso basta localizar o processo que deseja e acionar o ícone estrela![](/download/attachments/233763157/image-2025-8-15_10-3-41.png?version=1&modificationDate=1755611531907&api=v2). Automaticamente o ícone ficará destacado na cor amarela ![](/download/attachments/233763157/flaticon-star-active.png?version=1&modificationDate=1754595507650&api=v2), sinalizando aquele processo como favorito. 

Para removê-lo dos favoritos, clique no ícone de estrela ![](/download/attachments/233763157/flaticon-star-active.png?version=1&modificationDate=1754595507650&api=v2) — ele ficará cinza, indicando que o processo não está mais marcado como favorito.

Para copiar o link de um processo, clique no ícone ![](/download/attachments/233763157/image-2025-8-15_10-34-52.png?version=1&modificationDate=1755611532437&api=v2)**Copiar****Link do processo**, localizado no lado direito do nome do processo.

**02.** Selecione o processo que deseja inicializar sendo necessário preencher as informações solicitadas.

**03.** Preencha os dados do formulário, se existir. 

Os campos exibidos no formulário são previamente definidos por intermédio do recurso **Formulário**, o qual permite padronizar o formato, a disponibilidade e os campos a serem preenchidos em determinada atividade.

**04. **Clique na aba **Formulário** para visualizar o formulário da solicitação, casou houver. 

**05.** Clique na aba **Informações** para visualizar mais informações sobre o processo, seu fluxograma e instruções.

- **Dados**: Neste campo é apresentado o fluxograma do processo, assim como em qual atividade a solicitação se encontra, o título do processo, a versão do processo e formulário, o título do processo e formulário se houver.
- **Instruções para a atividade**: Neste campo é apresentada instruções de preenchimento da atividade, caso haja instruções.
- **Instruções para o processo**: Neste campo é apresentada instruções de preenchimento do processo, caso haja instruções. 

**06. **Clique na aba **Histórico** para visualizar quais as ações a solicitação já teve ou inserir comentários na solicitações.

Essa aba permite inserir e registrar comentários sobre a execução da atividade por do campo apresentado, podendo formatar a fonte como desejado e por meio do botão **Comentar**, o conteúdo é inserido. Estes comentários são armazenados no histórico da solicitação. Porém, quando uma solicitação de um processo está sendo iniciada não são exibidas informações históricas nessa aba, pois ainda não houve movimentações, somente depois do primeiro registro de movimentação.

Dentro da solicitação, é possível pesquisar através das seguintes opções:

- **Por usuário**: ao digitar na busca por um usuário específico, ele irá pesquisar por este usuário e trazer todas as ações relacionadas a ele na solicitação.
- **Por atividade**: ao digitar na busca por uma palavra chave, ele irá pesquisar em todas as atividades já realizadas na solicitação;
- **Por comentário**: ao digitar na busca por uma palavra chave, ele irá pesquisar em todos os comentários já feitos na solicitação;

Ou ainda, podemos utilizar o filtro ![](/download/attachments/233763157/flaticon-filter.png?version=1&modificationDate=1689855542353&api=v2) para pesquisar por um período, incluindo uma data de início - **De**- e uma data de fim - **Até**. Podendo ainda, exibir as informações de acordo com as opções disponíveis:

- **Movimentações:**traz todas as movimentações realizadas na solicitação, no período selecionado;
- **Transferências:**traz todas as transferências realizadas na solicitação, no período selecionado;
- **Conversões:**traz todas as conversões realizadas na solicitação, no período selecionado;
- **Anexos:**traz todos os anexos incluídos na solicitação, no período selecionado;
- **Comentários:**traz todos os comentários realizadas na solicitação, no período selecionado.

Ao selecionar um período e assinalar as opções de exibição que deseja visualizar, clique em **Aplicar**.

**07.**Clique na aba **Anexos**para anexar documentos à solicitação, se desejado.

Essa aba permite anexar à solicitação qualquer tipo de documento existente na plataforma ou, ainda, fazer o *upload* de novos arquivos. Também é possível excluir anexos existentes. A execução destas ações depende da definição de segurança de anexos configurada para o processo.
Para visualizar um arquivo ainda não publicado, é possível fazer download e visualizá-lo na própria máquina. Basta clicar sobre o arquivo.

Dentro da solicitação, é possível pesquisar os anexos através das seguintes opções:

- **Pelo título**: na busca, digite o título do anexo que deseja buscar na solicitação;
- **Pelo usuário**: na busca, digite o nome do usuário que incluiu anexos na solicitação;
- **Pela atividade**: na busca, digite a atividade em que o anexo foi incluído.

Ou ainda, podemos utilizar o filtro ![](/download/attachments/233763157/flaticon-filter.png?version=1&modificationDate=1689855542353&api=v2) para pesquisar pelos anexos por um período, incluindo uma data de início - **De**- e uma data de fim - **Até**. 

Ao selecionar um período que deseja visualizar os anexos, clique em **Aplicar**.

**08.** Clique em **Adicionar**para expandir as opções – **Upload de arquivo**  ou **Documentos do ECM** – para anexar um documento que já está publicado na plataforma.

**09.** Localize o documento e clique em **Selecione**.

Também é possível inserir arquivos da máquina por meio da ação arrasta e solta. Com o diretório no qual está o arquivo a ser anexado clique sobre o mesmo e arraste-o para a área de anexos, note que a mensagem "Solte seus arquivos aqui" será apresentada, solte o arquivo e ele será anexado.

**10.** Clique em **Enviar**para enviar a solicitação.

O botão **Enviar** disponibiliza, além do envio da solicitação, outras ações complementares como:

**Enviar**
Ao clicar em Enviar a solicitação será criada e movimentada para a próxima atividade, que foi escolhida no campo **Próxima atividade**.

**Somente salvar**
Também é possível iniciar o processo clicando em Somente salvar. Nesse caso, as informações inseridas são salvas, mas a solicitação permanece na atividade inicial, sob responsabilidade do usuário que a criou. Para dar continuidade, será necessário acessá-la posteriormente pela Central de Tarefas e movimentá-la manualmente para a próxima atividade.

**11.** Na janela exibida, defina as informações solicitadas.

**Próxima atividade**
Atividade para a qual a solicitação será encaminhada. As atividades exibidas na caixa de seleção são as atividades de avanço ou de retorno que estão configuradas para a atividade em questão.

**Responsável**
Usuário que será o responsável por executar a atividade para a qual a solicitação será encaminhada. O usuário escolhido ficará responsável pela atividade escolhida no campo Próxima atividade. Existem casos em que esta opção não será exibida, isso ocorre quando a atividade escolhida no campo Próxima atividade possui alguma condição de atribuição que não necessite selecionar o usuário, como por exemplo um mecanismo de atribuição *pool* para grupo ou para papel, ou uma atividade conjunta para todos os usuários.

**Senha**
Senha do usuário autenticado que está iniciando a solicitação. Esse campo somente é exibido quando foi definido no processo que ela deve ser solicitada ao iniciar uma solicitação.

**Apontamentos**
Tempo gasto para iniciar a solicitação em horas. Esse campo somente é exibido quando foi definido no processo que deve ser feito apontamento de horas ao iniciar uma solicitação.

**Repositório**
Repositório no qual se encontra o certificado digital que será utilizado para assinar digitalmente a atividade de início da solicitação. Esse campo somente é exibido quando a atividade de início da solicitação exige assinatura digital.

**12.**Clique em **Enviar**, se for o caso.

Após o envio, o gestor ou o usuário designado receberá uma notificação por *e-mail* com as informações da solicitação, incluindo os complementos. Para o recebimento das notificações, é necessário que a [configuração de envio por *e-mail*](https://tdn.totvs.com/x/MIL5DQ) esteja corretamente habilitada.

**O que você deseja fazer?**

Logo após acionar **Enviar**, o usuário poderá definir qual ação deseja tomar, entre:

- **Iniciar nova solicitação com base nesta**: Esta opção permite ao usuário iniciar uma nova solicitação reaproveitando os dados utilizados na solicitação anterior.
- **Iniciar nova solicitação em branco**: Esta opção permite ao usuário iniciar uma nova solicitação em branco, a ser preenchida pelo usuário.
- **Ir para a tela de iniciar solicitações**: Esta opção redireciona o usuário para  tela de [Iniciar solicitações](https://tdn.totvs.com/x/VfHuDQ).
- **Ir para a central de tarefas**: Esta opção redireciona o usuário para a tela da [Central de Tarefas](https://tdn.totvs.com/x/AfDuDQ).
- **Voltar:** Esta opção redireciona o usuário para  tela de [Iniciar solicitações](https://tdn.totvs.com/x/VfHuDQ).

Ao clicar no número da solicitação ou no link de Acessar solicitação, o usuário será redirecionado diretamente para a solicitação.
