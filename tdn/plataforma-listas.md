# Plataforma ❙ Listas

# Falando de listas...

---

Listas são tabelas dinâmicas, uma tabela é composta por um ou muito campos, logo uma LISTA é uma tabela personalizada com finalidade de armazenar diversos tipos de dados, também são utilizadas para armazenar os dados de formulários criados através de novas solicitações de processos ou da criação de um formulário através de sua definição que se encontra publicado na área Documentos.

## Incluir lista

---

**01.** No menu principal, clique em ![](/download/attachments/234455493/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1749487151593&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Personalização**.

**03**. Clique em ![](/download/attachments/234455493/%C3%ADcone-listas.png?version=1&modificationDate=1749487021097&api=v2) **Listas**.

**04.** Clique em **Adicionar**.

**05.** Insira um nome para a lista que será criada.

**06.** Insira uma descrição.

A descrição é utilizada para informar sobre quais tipos de registros serão armazenados nesta nova lista.

EXEMPLO
**Descrição**: “Esta lista é utilizada para armazenar todos os ramais da empresa”.

**07.** Para incluir novos campos, clique em **Adicionar**.

**08.** Em **Nova coluna**, insira o nome de um campo da lista.

**09.** Assinale se deseja utilizar o campo como rótulo, assim seu conteúdo será exibido em um campo do tipo Metalista.

Pode ocorrer de nenhum campo ser definido como rótulo, neste caso será exibido o campo com o valor de identificação do registro (campo ID).

**10.** Selecione o tipo do novo campo.

As opções disponíveis são:

- **Texto**: utilizar quando o valor for um texto. Este tipo aceita qualquer caractere como letras, números e caracteres especiais (!@#$%¨&*) e a quantidade máxima de caracteres aceita é 50. Os espaços entre palavras também são contabilizados como um caractere.EXEMPLONome, Endereço, Telefone, entre outros. 

- **Área de texto**: utilizar quando o valor for um texto longo. Este tipo aceita qualquer caractere como letras, números e caracteres especiais (!@#$%¨&*) e a quantidade máxima de caracteres aceita é 250. Os espaços entre palavras também são contabilizados como um caractere.EXEMPLODescrições, Observações, entre outros. 

- **Inteiro**: utilizar quando o valor for um número inteiro. Este tipo aceita somente números, não é permitido letras, pontos (.), vírgulas (,) e demais caracteres especiais e a quantidade máxima de caracteres aceita é 10.EXEMPLOIdade, Número de residência, entre outros. 

- **Numérico**: utilizar quando o valor for um valor numérico conter casas decimais. Este tipo aceita somente números e uma vírgula (,) os demais caracteres não são permitidos e a quantidade máxima de caracteres aceita é nove ou oito mais vírgula.EXEMPLOValor monetário, Quantidade de um produto, entre outros. 

- **Data**: utilizar quando o valor for uma data. Este tipo aceita somente data, quando um campo do tipo data é exibido em tela também é apresentado um calendário para que a data desejada seja escolhida, este é o único modo de informar um valor para este tipo de campo.EXEMPLOData de nascimento, Data de admissão, entre outros. 

- **Meta Lista**: utilizar quando o valor estiver contido em uma segunda lista, uma lista estrangeira. Este campo é exibido em tela como uma caixa de seleção com os valores contidos na lista estrangeira seleciona. Os valores da caixa de seleção que são exibidos são os campos marcados como rótulos da lista estrangeira, caso nenhum campo esteja marcado como rótulo o valor exibido na caixa de seleção será o número identificador do registro (ID).EXEMPLOEstado, Sexo, Estado civil, entre outros. 

**11.** Clique em **Confirmar**.

**12.** Para editar campos durante a criação de uma Lista, caso haja necessidade de realizar alguma alteração em um campo já criado, assinale o campo desejado.

Só é permitida a alteração de um campo por vez.

**13.** Clique em **Editar**.

**14.** Faça as alterações desejadas.

**15.** Clique em **Confirmar**.

**16.** Para remover campos durante a criação de uma Lista, caso haja necessidade de remover algum campo já criado, assinale os campos que se deseja remover.

**17.** Clique em **Remover**.

**18.** Clique em **Confirmar**.

**03**. Clique em ![](/download/attachments/234455493/%C3%ADcone-listas.png?version=1&modificationDate=1749487021097&api=v2) **Listas**.

**04.** Assinale a lista que deseja editar.

**05.** Clique em **Editar**.

Só é permitida a alteração de uma lista por vez.

**06.** Caso necessário, insira um novo nome para a lista.

**07.** Caso necessário, insira uma nova descrição.

**08.** Para incluir novos campos, clique em **Adicionar**.

**09.** Em **Nova coluna**, insira o nome de um campo da lista.

**12.** Clique em **Confirmar**.

**13.** Caso haja necessidade de realizar alguma alteração em um campo, assinale o campo desejado.

Só é permitida a alteração de um campo por vez.

**14.** Clique em **Editar**.

A edição de um campo já criado anteriormente tem algumas restrições como, por exemplo, não pode ser alterado o nome e o tipo do campo. A opções disponíveis para alteração são **Rótulo** e **Desabilitar coluna**.

**15.** Marque ou desmarque a opção **Rótulo**.

**16.** Marque ou desmarque a opção **Desabilitar**.

**17.** Clique em **Confirmar**.

**18.** Caso haja necessidade de excluir algum campo já criado, assinale os campos desejados.

Esta ação é irreversível, esta operação é recomendada somente para o administrador do sistema.

**19.** Clique em** Remover**.

**20.** Após concluir, clique em **Confirmar**.

## Importar lista

---

**01.** No menu principal, clique em ![](/download/attachments/234455493/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1749487151593&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Personalização**.

**03**. Clique em ![](/download/attachments/234455493/%C3%ADcone-listas.png?version=1&modificationDate=1749487021097&api=v2) **Listas**.

**04.** Clique em **Importar**.

**05.** Em **Importando a lista**, escolha o tipo da importação.

As opções disponíveis são:

- **Definição (somente os campos da lista)**: cria uma nova lista somente com os campos da lista contida no arquivo XML, mesmo que existentes os registros não são importados.

- **Dados (todos os campos e dados da lista)**: cria uma nova lista com os campos e registros da lista contida no arquivo XML.

**06.** Clique em **Escolher arquivo** e localize o XML da lista desejada.

**07.** Clique em **Confirmar**.

## Exportar lista

---

**01.** No menu principal, clique em ![](/download/attachments/234455493/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1749487151593&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Personalização**.

**03**. Clique em ![](/download/attachments/234455493/%C3%ADcone-listas.png?version=1&modificationDate=1749487021097&api=v2) **Listas**.

**04.** Assinale a lista que deseja exportar.

**05.** Clique em **Exportar**.

**06.** Em **Exportando a lista**, escolha o tipo da exportação.

As opções disponíveis são:

- **Definição (somente os campos da lista)**: gera um arquivo XML somente com os campos da lista que foi selecionada, os registros existentes não são exportados. O arquivo XML gerado a partir da exportação pode ser salvo em um diretório de escolha do usuário.

- **Dados (todos os campos e dados da lista)**: gera um arquivo XML com os campos e registros da lista que foi selecionada. O arquivo XML gerado a partir da exportação pode ser salvo em um diretório de escolha do usuário.

**07.** Clique em **Confirmar**.

**08.** Escolha o local de destino para o arquivo XML.

## Ler os dados da lista

---

Para ler os dados de uma lista via código, é possível utilizar os seguintes métodos REST:

- <domínio>/ecm/api/rest/ecm/metaList/findAllListPaginator

- <domínio>/ecm/api/rest/ecm/metaList/findAllList

- <domínio>/ecm/api/rest/ecm/metaList/findListById/25

Para mais detalhes, acesse a documentação técnica [Fluig API](https://tdn.totvs.com/x/KAFlDw).
