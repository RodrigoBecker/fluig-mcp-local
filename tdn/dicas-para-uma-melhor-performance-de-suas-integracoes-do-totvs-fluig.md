# Etapas auxiliares para analisar a origem de um possível problema de integração

- Monitore o desempenho do sistema
- Teste API separadamente (por exemplo, com o [Postman](https://www.postman.com/))
- Avalie o código de sua customização
- Considere o tráfego da rede e a conectividade
- Consulte a [Central de Diagnóstico](https://tdn.totvs.com/x/rO9iJg) e logs da plataforma
