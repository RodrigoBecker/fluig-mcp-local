# Platform ❙ Security and access container

![](/download/attachments/444609173/%C3%ADcone-agrupador-seguran%C3%A7a-acesso.png?version=1&modificationDate=1767989064810&api=v2)

---

Nesse agrupador é possível gerenciar diversas ações relacionadas à segurança e acesso da plataforma. ![](/plugins/servlet/confluence/placeholder/unknown-macro?name=tooltip&locale=en_US&version=2)

It consists of the following resources:

- [Anonymize and export personal data](/pages/viewpage.action?pageId=550328850): allows searching and taking action regarding personal data in the platform. Actions may include anonymizing data found or exporting such data to a report in JSON format.

- [Personal data](/pages/viewpage.action?pageId=550328811): lists and manages requested personal data across all platform features.

- [Log control](https://tdn.totvs.com/x/aTcaDg): registers all actions performed by each user in order to help identify situations affecting platform use. By enabling this feature for a specific user, a separate log file containing all user actions is generated after such user’s next platform authentication.

- [Usage statistics](https://tdn.totvs.com/x/GQJoDg): allows an overview on how the platform is being used. Different usage information is extracted, namely number of users, registered groups and roles, number of registered and released processes, number of open and finished requests, number of posts, support, comments and communities, number of published documents and further information related to the use of features the platform provides.

- [Controlled copy log](https://tdn.totvs.com/x/gaIXDg): Issued controlled copy log is the information record of each controlled copy printing. The record is important because it offers total control and traceability of the copies. Through this function, you can also analyze and verify the controlled copies already issued, since it shows the following information: document number, description, issuer, printing date, target area, person responsible for the area and others.

Please note!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
