# Platform ❙ Applications container

![](/download/attachments/444609166/%C3%ADcone-agrupador-aplicativos.png?version=1&modificationDate=1767375320477&api=v2)

---

In this group, it is possible to manage various actions related to applications.![](/plugins/servlet/confluence/placeholder/unknown-macro?name=tooltip&locale=en_US&version=2)

It consists of the following resources:

- [Component center](https://tdn.totvs.com/x/yKIXDg): allows you to manage all the existing components on TOTVS Fluig Platform. You can add components purchased from the [TOTVS Store](http://www.fluigstore.com/) and also download components to customize them and import them again. The download option is displayed only for components that allow developments on the platform.

- [Collaborative editing -CP](https://tdn.totvs.com/x/fqIXDg): This feature allows you to enable the collaborative editing of documents through Google Drive. Besides being another editing option, the collaborative editing allows the document to be changed by multiple users, which may contribute to its drafting, making the process more collaborative.

- [Audit Events](https://tdn.totvs.com/x/WANZGg): This feature registers platform events focused on audits. These are basically logs recording the creation, editing and deletion of business items.

- [Gamification](https://tdn.totvs.com/x/kD0aDg): aims to engage users of the platform in a variety of activities, allowing for monitoring the results obtained and the progress achieved. Through engagement actions users can earn titles, trophies, achievements, acquire experience in certain areas of knowledge, and strengthen their profiles on the platform.

- [Store Items](https://tdn.totvs.com/x/fwUkFw): This feature allows easily and almost instantaneously installing [TOTVS Store](http://www.fluigstore.com/) solutions directly in the platform. This type of offering is implemented by TOTVS Fluig developers or partners, based on standard platform components such as widgets, layouts and pages. All of the solutions available in this feature underwent rigorous quality control before being made available for installation.

Please note!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
