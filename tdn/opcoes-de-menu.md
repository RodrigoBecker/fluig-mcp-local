# Opções de Menu

# Índice

# Sobre o menu principal

O acesso aos principais recursos da plataforma Fluig ocorre pelo menu principal, posicionado à direita na tela do usuário. O WCM permite que as páginas criadas pelo usuário na plataforma sejam adicionadas e organizadas no menu de diferentes formas.

# Objetivo

O objetivo deste guia é auxiliar o usuário na criação e organização de páginas no menu de navegação do TOTVS Fluig Plataforma.

# Opções de menu

Ao [criar uma nova página](https://tdn.totvs.com/pages/viewpage.action?pageId=185732957), é possível controlar a exibição desta página no menu principal através das **Opções de Menu**:

![](/download/attachments/126714715/op%C3%A7oes_menu.png?version=1&modificationDate=1500320447000&api=v2)

### Habilitar sub-páginas

Esta opção permite que a página atual possa ser referenciada como página pai por outras páginas, denominadas "sub-páginas" ou "páginas filhas".

### Exibir sub-páginas no sub-menu

Esta opção só pode ser habilitada em conjunto com a opção "Habilitar sub-páginas".

- [Habilitada](#)
- [Desabilitada](#)

 - Com a opção **Exibir sub-páginas no sub-menu** habilitada, as sub-páginas são exibidas ao posicionar o ponteiro do *mouse* sobre a página pai no menu, sem necessidade de clicar para exibir as páginas filhas.

![](/download/attachments/126714715/subp%C3%A1ginas_submenu_ON.png?version=1&modificationDate=1500321358000&api=v2)

 - Com a opção **Exibir sub-páginas no sub-menu** desabilitada, as sub-páginas são exibidas no mesmo nível que a página pai, ou seja, são exibidas logo abaixo da página pai no menu do Fluig Plataforma.

![](/download/attachments/126714715/subp%C3%A1ginas_submenu_OFF.png?version=1&modificationDate=1500321546000&api=v2)

### Página Agrupadora

Ao definir uma página como agrupadora, seu conteúdo não é mais exibido. A página tem somente a função de agrupar e organizar páginas filhas no menu.
