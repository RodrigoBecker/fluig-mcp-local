# Plataforma ❙ Agrupador Desenvolvimento

![](/download/attachments/385853293/%C3%ADcone-agrupador-desenvolvimento.png?version=1&modificationDate=1749669796193&api=v2)

---

Este agrupador possui recursos para gerenciamento da plataforma. ![](/plugins/servlet/confluence/placeholder/unknown-macro?name=tooltip&locale=en_US&version=2)

Ele é composto pelos seguintes recursos:

- [Adapters:](https://tdn.totvs.com/x/uID5DQ) os adapters são componentes JAVA responsáveis pela comunicação da plataforma com o aplicativo a ser executado. O TOTVS Fluig disponibiliza dois adapters padrão são eles:**CommandLine** – o qual permite a utilização de qualquer aplicativo via linha de comando. Esse adapter possui o parâmetro padrão “WORKDIR”, que tem a mesma função do “Iniciar em” nos atalhos do Windows;
- **Web** – o qual permite a utilização de aplicativos Web. Esse adapter possui o parâmetro padrão “TARGET”, o qual permite definir a janela na qual a página será aberta;

[Datasets:](https://tdn.totvs.com/x/OvIKDg) permite criar *datasets* e definir quais serão *offline* em dispositivos móveis, quais devem ser sincronizados com o provedor externo de dados, a frequência de sincronização, dentre outras opções. *Datasets* são componentes que permitem padronizar o acesso às informações provenientes de locais externos à plataforma;
- [Operações](/pages/viewpage.action?pageId=394220928):  possibilita o cadastro de operações de serviços, para que os usuários possam utilizar as operações de serviços em integrações;

- [Serviços:](https://tdn.totvs.com/x/-PeFDg) permitem acessar com segurança recursos e serviços externos à plataforma, utilizando os protocolos de autenticação OAuth 1, OAuth 2 e *Basic authentication*. Nesse recurso é possível cadastrar e configurar os serviços;

- [Servidores:](https://tdn.totvs.com/x/jYtJF) possível cadastrar servidores para que possa ser realizada a exportação de páginas de servidor para o outro sem precisar baixar e importar arquivos;

- [Temas de formulários:](https://tdn.totvs.com/x/7P-uDQ) são estilos que podem ser aplicados aos formulários que são criados em processos para personalizar sua aparência.

Fique atento!

Esta documentação é válida a partir da atualização **Voyager (2.0)**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
