# Platform ❙ Component center

# Speaking of component center...

---

Component Center allows you to manage all the existing components on TOTVS Fluig Platform. You can add components purchased from the [TOTVS Store](http://www.fluigstore.com/) and also download components to customize them and import them again. The download option is displayed only for components that allow developments on the platform.

You can enable and disable components whenever wanted or needed.

![](/download/attachments/236430024/Component%20center.png?version=1&modificationDate=1767378580790&api=v2)

## Access component center

---

**01.** In the main menu, click ![](/download/attachments/236430024/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1767378521857&api=v2) **Control Panel**.

**02.** Locate the **Applications** group.

**03.** Click ![](/download/attachments/236430024/%C3%ADcone-central-componentes.png?version=1&modificationDate=1767378432440&api=v2) **Component center**.

**04.** View the existing components on the platform and their related information.

You can search for a specific component through the “Search” field located in the upper right corner of the window.

## Add component

---

**01.** In the main menu, click ![](/download/attachments/236430024/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1767378521857&api=v2) **Control Panel**.

**02.** Locate the **Applications** group.

**03.** Click ![](/download/attachments/236430024/%C3%ADcone-central-componentes.png?version=1&modificationDate=1767378432440&api=v2) **Component center**.

**04.** Click **Select file**.

**05.** Search and select the .ear artifact for the component to be added.

**06.** Click **Send**.

## Enable component

---

**01.** In the main menu, click ![](/download/attachments/236430024/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1767378521857&api=v2) **Control Panel**.

**02.** Locate the **Applications** group.

**03.** Click ![](/download/attachments/236430024/%C3%ADcone-central-componentes.png?version=1&modificationDate=1767378432440&api=v2) **Component center**.

**04.** Select the component to be enabled.

**05.** Click **Enable**.

## Disable component

---

**01.** In the main menu, click ![](/download/attachments/236430024/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1767378521857&api=v2) **Control Panel**.

**02.** Locate the **Applications** group.

**03.** Click ![](/download/attachments/236430024/%C3%ADcone-central-componentes.png?version=1&modificationDate=1767378432440&api=v2) **Component center**.

**04.** Select the component to be disabled.

**05.** Click **Disable**.

**06.** In the message displayed, press **Yes** to confirm the disabling of the component.

## Download component

---

**01.** In the main menu, click ![](/download/attachments/236430024/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1767378521857&api=v2) **Control Panel**.

**02.** Locate the **Applications** group.

**03.** Click ![](/download/attachments/236430024/%C3%ADcone-central-componentes.png?version=1&modificationDate=1767378432440&api=v2) **Component center**.

**04.** Select the component to be downloaded.

**05.** Click on **Download**.

The download option is displayed only for components that allow developments on the platform.

Please note!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
