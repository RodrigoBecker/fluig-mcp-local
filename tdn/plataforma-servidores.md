# Plataforma ❙ Servidores

# Falando de servidores...

---

Por meio deste recurso é possível cadastrar servidores para que possa ser realizada a [exportação de páginas](https://tdn.totvs.com/x/24L5DQ) de um servidor para o outro sem precisar baixar e importar arquivos.

Para realizar o cadastro de servidores, é necessário criar uma [Chave OAuth](https://tdn.totvs.com/x/64L5DQ#Plataforma%E2%9D%99OAuthprovider-CadastrarOAuthProviderparaservidores) específica para servidores e um [Usuário Aplicativo](https://tdn.totvs.com/x/54L5DQ#Plataforma%E2%9D%99Oauthapplication-CadastrarOAuthapplicationparaservidores) com permissões de administrador da plataforma, ambos para o servidor de destino.

![](/download/attachments/340364173/servidores.png?version=3&modificationDate=1750447121340&api=v2)

## Ver servidores

---

**01.** No menu principal, clique em ![](/download/attachments/340364173/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1750447280823&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Desenvolvimento**.

**03**. Clique em ![](/download/attachments/340364173/%C3%ADcone-servidores.png?version=2&modificationDate=1750447368247&api=v2) **Servidores**.

**04**. Veja os servidores existentes.

## Cadastrar servidor

---

![](/plugins/servlet/confluence/placeholder/unknown-macro?name=tooltip&locale=en_US&version=2)

**01.** No menu principal, clique em ![](/download/attachments/340364173/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1750447280823&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Desenvolvimento**.

**03**. Clique em ![](/download/attachments/340364173/%C3%ADcone-servidores.png?version=2&modificationDate=1750447368247&api=v2) **Servidores**.

**04.** Clique em **Novo**.

**05. **Defina um Nome**.**

**06**. Informe o **Endereço** do servidor a ser cadastrado.

**07.** Informe a**Consumer key** do OAuth App cadastrado no servidor de destino.

A Consumer Key pode ser localizada no servidor de destino ao acessar Painel de controle > agrupador Parâmetros técnicos > OAuth App. Para mais informações acesse [Cadastrar OAuth App para servidores](https://tdn.totvs.com/x/54L5DQ#Plataforma%E2%9D%99Oauthapplication-CadastrarOAuthapplicationparaservidores)

**08.** Informe a **Consumer Secret ** do OAuth App cadastrado no servidor de destino.

A *Consumer Secret* pode ser localizada no servidor de destino ao acessar Painel de controle > agrupador Parâmetros técnicos > OAuth App, selecionar o OAuth App cadastrado e acionar editar. Para mais informações acesse [Cadastrar OAuth App para servidores](https://tdn.totvs.com/x/54L5DQ#Plataforma%E2%9D%99Oauthapplication-CadastrarOAuthapplicationparaservidores)

**09.** Informe o **Access Token** do Usuário Aplicativo cadastrado no servidor de destino.

O *Access Token*pode ser localizado no servidor de destino ao acessar Painel de controle > agrupador Parâmetros técnicos > OAuth App, selecionar o OAuth App cadastrado e acionar Usuário Aplicativo. Para mais informações acesse [Cadastrar OAuth App para servidores](https://tdn.totvs.com/x/54L5DQ#Plataforma%E2%9D%99Oauthapplication-CadastrarOAuthapplicationparaservidores).

**10.**Informe o **Secret Token** do Usuário Aplicativo cadastrado no servidor de destino.

 O *Secret Token***pode ser localizado no servidor de destino ao acessar Painel de controle > agrupador Parâmetros técnicos > OAuth App, selecionar o OAuth App cadastrado e acionar Usuário Aplicativo. Para mais informações acesse [Cadastrar OAuth App para servidores](https://tdn.totvs.com/x/54L5DQ#Plataforma❙Oauthapplication-CadastrarOAuthapplicationparaservidores).

**11.**Clique em **Cadastrar.**

## Editar servidor

---

**01.** No menu principal, clique em ![](/download/attachments/340364173/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1750447280823&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Desenvolvimento**.

**03**. Clique em ![](/download/attachments/340364173/%C3%ADcone-servidores.png?version=2&modificationDate=1750447368247&api=v2) **Servidores**.

**04.** Clique em **Editar**  ![](/download/attachments/340364173/icon-pencil.png?version=1&modificationDate=1519827046000&api=v2)  localizado ao lado direito do servidor que deseja editar.

**05.** Efetue as alterações desejadas.

**06.** Clique em **Atualizar.**

## Excluir servidor

**01.** No menu principal, clique em ![](/download/attachments/340364173/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1750447280823&api=v2) **Painel de controle**.

**02**. Localize o agrupador **Desenvolvimento**.

**03**. Clique em ![](/download/attachments/340364173/%C3%ADcone-servidores.png?version=2&modificationDate=1750447368247&api=v2) **Servidores**.

**04.** Clique em **Excluir**  ![](/download/attachments/340364173/icon-remove-circle.png?version=1&modificationDate=1519827079000&api=v2)  localizado ao lado direito do servidor que deseja excluir.

**05.** Clique em **Sim**.
