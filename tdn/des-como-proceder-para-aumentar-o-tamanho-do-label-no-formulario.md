# DES - Como proceder para aumentar o tamanho do label no formulário?

# Índice

# Plataforma

**Produto:**TOTVS Fluig Plataforma****

# Ocorrência

Como proceder para aumentar o tamanho do *label* no formulário?

# Solução

Trocar o tipo do campo, de acordo com a quantidade de caracteres que deseja:

O campo Label *textfield* grava 30 caracteres.

O campo Label *textarea*  grava 255 caracteres.

O campo Label parágrafo grava  65535 caracteres.
