# MOB - Por que os processos no Fluig Mobile não possuem todos os recursos apresentados no TOTVS Fluig?

# Índice

# Plataforma

**Produto:**Fluig Mobile

# Ocorrência

Ao movimentar uma atividade de um processo pelo Fluig Mobile, existe apenas o botão **Enviar**. Ao movimentar pela plataforma Fluig tem outras opções como salvar e transferir.

# Causa

Atualmente, nem todos os recursos disponíveis na plataforma Fluig estão disponíveis no Fluig Mobile, esta é uma destas situações. Na plataforma, ao clicar em Enviar, o fluxo segue automaticamente para a próxima atividade e caso queira escolher outra atividade, existe a opção Transferir. Já no Fluig Mobile a opção Transferir não existe, por isso ele sempre pede para selecionar a próxima atividade após clicar em Enviar.

# Solução

Atualmente este realmente é o comportamento esperado, este item e novos recursos são aprimorados com o tempo, durante a evolução do Fluig.
