# Identity | Por que um usuário do Active Directory não está sendo importado pelo SmartSync?

---

O SmartSync só realiza a importação de usuários cujo cadastro no Active Directory possua os campos Nome (First Name), Sobrenome (Last Name) e E-mail preenchidos.

Tente preencher os três campos obrigatórios no cadastro do usuário no Active Directory. Logo após a alteração, o SmartSync irá detectar o usuário e importá-lo para a lista de Pendentes no Identity.
