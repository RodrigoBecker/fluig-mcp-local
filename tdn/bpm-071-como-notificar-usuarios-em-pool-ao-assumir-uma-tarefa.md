# BPM 071 - Como notificar usuários em Pool ao assumir uma tarefa?

# Índice

# Plataforma

**Produto:  **fluig

**Versão:** 1.5.6 e superior

# Ocorrência

No ECM 3.0, nas configurações das atividades, aba Acompanhamento, existe a opção "Notifica usuários em Pool ao assumir tarefa". Existe esse recurso no fluig?

# Solução

Na Atualização 1.5.6 do fluig houve uma alteração para não notificar mais os usuários do pool, ou seja, o fluig não dispõe deste recurso.
