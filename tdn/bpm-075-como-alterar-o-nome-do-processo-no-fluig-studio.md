# BPM 075 - Como alterar o nome do processo no fluig Studio?

# Índice

# Plataforma

**Produto:  **fluig

**Versão:** 1.5

# Ocorrência

Gostaria de saber como mudar o nome de um processo no TDS.

# Solução

A alteração do nome do processo é feita no campo Descrição, localizado nas propriedades do processo.

Para que seja alterado no fluig também, deve-se exportar o processo para o servidor, conforme a documentação [Exportando processos](/display/fluig/Exportando+processos).
