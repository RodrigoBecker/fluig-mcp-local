# BPM 042 - Por que configurar determinados processos como privado?

# Índice

# Plataforma

**Produto:  **fluig

**Versão:** todas

# Ocorrência

É necessário ocultar alguns processos de determinados usuários. Eles não poderão iniciar as solicitações e nem acessar o histórico dos processos.

# Solução

1. Configurar o mecanismo de atribuição na atividade inicial para que as solicitações do processo só possam ser iniciadas pelos usuários definidos no mecanismo.
2. Configurar o processo como privado. Para isso acesse o menu Processos → Configurar Processos → (Selecione o processo desejado) → Editar → Propriedades → aba Geral e desmarque a opção "Público".
