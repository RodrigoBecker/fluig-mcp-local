# DES - É possível realizar buscas em dois campos diferentes e simultâneos utilizando o data-zoom?

# Índice

# Plataforma

**Produto:**TOTVS Fluig Plataforma

# Ocorrência

É possível realizar buscas utilizando o data-zoom pesquisando em dois campos diferentes e simultâneos?

Exemplo:

Como faço para que o elemento abaixo consiga fazer pesquisar por colleagueName e colleagueId se eu digitar um ou outro no campo?

[?](#)

| ``data-zoom="{``'datasetId':'colleague',``'fields':[ {``'field':'colleagueName',``'label':'Colaborador',``'standard':'true',``'search':'true'``},``{``'field':'colleagueId',``'label':'Matrícula'``}``]}" />` |
| --- |

# Solução

Hoje na plataforma não é possível realizar uma busca por dois campos de formulários.
