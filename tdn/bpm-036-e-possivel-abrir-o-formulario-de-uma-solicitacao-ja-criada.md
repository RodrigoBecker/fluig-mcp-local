# BPM 036 - É possível abrir o formulário de uma solicitação já criada?

# Índice

# Plataforma

**Produto:  **fluig

**Versão:** 1.6.0

# Ocorrência

Não é possível abrir o formulário de uma solicitação já criada.  Conforme o print a seguir, aparece "HTTP Status 404" quando é clicado na aba "Detalhes".

![](/download/attachments/239010110/Screenshot_3.jpg?version=1&modificationDate=1464952713000&api=v2)

**Solicitação sem formulário.**

# Causa

A solicitação estava sem registro de formulário. Verificamos na pasta do formulário dessa solicitação, em "Documentos" e estava sem registro.

# Solução

Após acessar a "Lixeira" e restaurar o registro, o problema foi resolvido.
