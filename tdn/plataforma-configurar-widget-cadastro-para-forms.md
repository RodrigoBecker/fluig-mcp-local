# Plataforma ❙ Configurar widget Cadastro para Forms

# Índice

Importante

O recurso "**Widget Cadastro para Forms**" ficará indisponível para novas instalações a partir do lançamento da Atualização **Lake 1.7** (05/2020).

Para ambientes atualizados até a versão **Atualização Liquid 1.6.5**, o recurso permanece.

## Falando de widget Cadastro para Forms

O *widget* Cadastros permite gerenciar seus registros de formulário de forma rápida. Além de incluir novos registros e visualizá-los de forma prática na sua página inicial, é possível editar os registros de formulário selecionando o registro necessário para edição. Com o *widget* Cadastros também é possível excluir os registros de formulário que não são mais necessários para consulta. 

Esses dados do formulário adicionado na *widget,* poderão ser exportados em arquivos CSV ou Excel para consultas ou controle desses dados.

A partir do dia **13/01/2023** a oferta gratuita do TOTVS Fluig No-Code deixou de existir. Dessa forma, não é mais possível ativar o plano gratuitamente.  Clientes que já ativaram a oferta, continuam tendo acesso aos aplicativos normalmente e com isso as widgets do plano No-Code podem ser utilizadas normalmente. 

Já para clientes que não ativaram o plano até a data mencionada acima, não terão mais acesso aos aplicativos e não com isso não terão acesso as widgets.

### Inserir o widget Cadastro para Forms

---

Siga os passos abaixo para adicionar o widget

**01.** Acionar o ícone de engrenagem localizado ao lado do nome do usuário.

No tema Liquid, acionar o ícone de engrenagem ao lado direito da tela. ![](/download/attachments/347439743/widget%20para%20forms.png?version=1&modificationDate=1542718158827&api=v2)

**02.** Selecionar **Editar página**.

**03.** Escolher o *slot* para incluir o widget.

**04.** Após definir qual slot irá receber o widget, acessar Forms e localizar a widget **Cadastro para Forms**.

**05.** Acionar **Adicionar**e o widget será apresentado no slot escolhido anteriormente.

### Preencher o widget Cadastro para Forms

---

Para preencher o widget siga os passos abaixo:

**01.** No campo título é possível definir um título para o widget.

**02.** Selecionar o formulário que será incluído no widget no campo **Selecione...**

O widget Cadastros só poderá ser utilizado com formulários criados utilizando o Forms Beta à partir das Atualizações **Waterdrop 1.6.4** e **Liquid 1.6.5**.

**03.**

Definir o número de linhas exibido no widget em 

**Resultados por página**. Varia entre **10** a **30** linhas.

**04.** Os campos do formulários serão exibidos em forma de lista, com o Nome da coluna, o ID do campo e oTipo do campo. Também é possível ordenar os campos conforme a necessidade nas setas apresentadas ao lado de cada campo.

**05.** Selecionar os campos necessários para exibição dos registros.

Atenção

Para utilizar campos de formulário com nome iguais no widget Cadastros, é preciso verificar o ID do campo para diferenciar um campo do outro caso não precise mostrar a informação dos dois campos.

**Exemplo:** No formulário existem dois campos com o nome DATA porém na widget é preciso mostrar a informação somente do primeiro campo, para isso, é necessário vefiricar o **ID** do campo em **Opções Avançadas** do Forms e assim, selecionar o registro necessário para exibir no widget conforme o ID verificado no formulário.

**06.**Escolher os botões que serão apresentados no menu da widget** Mais Opções...**Os botões disponíveis para inclusão do widget são: Adicionar, Editar, Remover e Visualizar.

Por padrão, todos os botões serão apresentados na coluna **Permitir.**

Para realizar a alteração é necessário arrastar e soltar os botões que serão apresentados na coluna **Permitir** e os botões que não serão apresentados na coluna **Esconder**.

Os botões podem ser definidos no widget conforme a necessidade apresentada e poderão ser alterados à qualquer momento, basta editar a página novamente e realizar a alteração.

**07.** Acionar **Salvar**. 

Uma mensagem confirmando a configuração do *widget* será apresentada. Acionar **Fechar**.

Importante!

A busca da widget só será apresentada quando o forms tiver entre os 5 primeiros campos, algum dos campo de tipo: Texto, Numérico, Data e Avaliação, nessas condições será possível filtrar os registros dos campos citados acima.

Contudo nenhum campo de tipo: Escolha única, Múltipla escolha, Lista, Lista suspensa, Busca usuário, Pesquisa, Parágrafo e Texto rico será filtrado pela busca da widget.

**Mas fique tranquilo**

A configuração da widget ao ser incluída nas páginas da plataforma continuará a mesma. Poderá ser configurada com os campos de maior necessidade sem problema algum. Somente terá a condição que de se for campos do tipo Escolha única, Múltipla escolha, Lista, Lista suspensa, Busca usuário, Pesquisa, Parágrafo e Texto rico os registros destes campos não poderão ser filtrados pela busca da widget pois são campos não filtráveis.

### Publicar a página com Widget Cadastro para Forms

---

Após adicionar e configurar o widget, é necessário publicar a página que está em edição.

**01.** Acionar o ícone de engrenagem ao lado do nome do usuário.

No tema Liquid, acionar o ícone de engrenagem ![](/download/attachments/347439743/widget%20para%20forms.png?version=1&modificationDate=1542718158827&api=v2)e acionar **Publicar página**.

**02.** Inserir uma descrição com as alterações realizadas na página e acionar **Publicar página**.

### Adicionar registro de formulário no widget Cadastro para Forms

---

É possível inserir novos registros de formulário no widget. Siga os passos abaixo:

**01.** Acionar **Adicionar**.

**02.** O formulário selecionado no widget será aberto para a inclusão de um novo registro de formulário.

**03.** Inserir os registros necessários.

**04.** Acionar **Salvar**.

### Editar registro de formulário no widget Cadastro para Forms

---

Para editar um registro de formulário, siga os passos abaixo:

**01.** Selecionar a linha de registro que deseja editar clicando em cima do registro.

**02.** Acionar **Mais opções** e logo depois **Editar**.

**03.** O formulário selecionado no widget será aberto com os registros de formulários para realizar a edição.

**04.** Editar os registros necessários.

**05.** Acionar **Salvar**.

### Remover registro de formulário no widget Cadastro para Forms

---

Siga os passos abaixo para remover os registros de formulário que não são necessários.

**01.** Selecionar o registro a ser excluído clicando sobre a linha do registro escolhido.

02. Acionar **Mais opções** e logo depois **Remover**.

Uma mensagem para confirmar a ação será apresentada. Acionar **Sim**.

### Exportar registros de formulário do widget Cadastro para Forms

---

Após a inclusão dos registros necessários, é possível exportar os registros para controle desses dados.

**01.** Acionar **Exportar**.

**02.** Escolher entre **CSV** ou **Excel** para a exportação dos dados.

Uma mensagem será apresentada informando que o arquivo está sendo gerado e ficará disponível na pasta particular do usuário.

Importante

A quantidade de itens exportados poderá ser definida pelo usuário no momento de exportar os registros. No Forms, atualmente, somente 5 registros são exportados, não importando a quantidade de registros que o formulário possui. Somente através da widget será possível extrair todos estes registros no momento da exportação, definindo manualmente. Para isso, é necessário marcar o checkbox de todos os registros que deseja exportar, ficando atento ao número de registros por página, para que todos sejam visualizados e marcados.
Veja aqui como [exportar os registros](https://tdn.totvs.com/pages/viewpage.action?pageId=440835367#Navega%C3%A7%C3%A3odeForms-Formspublicados) diretamente da visualização de registros do [Forms](https://tdn.totvs.com/x/2CicG).

**03.** Acionar a pasta **Meus documentos**.

**04.** Para acessar é necessário clicar sobre o nome do arquivo.

**05.** O arquivo será baixado automaticamente para o desktop do usuário e será exibido conforme a opção baixada e a configuração do desktop do usuário. 

Fique atento!

Esta documentação é válida a partir da **atualização 1.6.5 Liquid**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
