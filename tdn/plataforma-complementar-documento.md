# Plataforma ❙ Complementar documento

# Índice

## Falando de complementar documento...

Esse recurso permite fazer anotações nos documentos, incluir setas e outras formas, destacar conteúdos, inserir tarjas de bloqueio de conteúdo nas páginas do documento, entre outras funções. 

Para incluir complementos, é necessário utilizar o [Visualizador interno](/pages/viewpage.action?pageId=244736364), por isso a opção "Utiliza visualizador interno" precisa estar marcada nas propriedades do documento.

### Incluir complemento

---

Para efetuar essa ação, é necessário que o usuário tenha permissão de modificação no documento escolhido. A opção Complementar não será disponibilizada para todos os usuários caso o documento esteja em [check-out](/pages/viewpage.action?pageId=235325675), somente para o usuário que efetuou o check-out.

**01.** Na navegação de documentos, localizar o documento que deseja complementar.

**02.** Acionar o ícone ![](/download/attachments/561630856/Barras%20horizontais2.png?version=1&modificationDate=1598880837283&api=v2)**Mais opções**  e selecionar a opção **Complementar**.

Será aberto o [visualizador interno](/pages/viewpage.action?pageId=244736364), permitindo incluir complementos no documento visualizado. Na inclusão de complementos, é possível utilizar os recursos **Anotar** e **Redigir**do visualizador.

#### Anotar

---

**** [Assista ao vídeo](/download/attachments/561630856/Anotar.gif?version=1&modificationDate=1599162706343&api=v2) 

![](/download/attachments/561630856/image2020-8-31_9-43-6.png?version=2&modificationDate=1599163716817&api=v2)

Utilizando essas ferramentas, é possível adicionar diversas formas, realçar texto, criar links para sites, entre outros. Para adicionar uma anotação, pressione o botão da marca que deseja adicionar. Dependendo da ferramenta escolhida, é necessário pressionar e arrastar para adicionar uma forma em qualquer lugar do documento e do tamanho desejado, ou selecionar um bloco de texto para adicionar um tachado.

Depois de adicionar uma anotação, um menu de contexto será apresentado na parte direita do visualizador, permitindo que sejam alteradas as configurações para essa marca, dependendo do tipo de anotação selecionada:

![](/download/attachments/561630856/image2020-8-31_9-48-31.png?version=1&modificationDate=1598880837100&api=v2)

#### Redigir

---

**** [Assista ao vídeo](/download/attachments/561630856/Redigir.gif?version=2&modificationDate=1600172554027&api=v2) 

![](/download/attachments/561630856/image2020-8-31_9-57-13.png?version=2&modificationDate=1599163785863&api=v2)

Esse recurso é muito interessante para documentos que contenham conteúdo sensível. Mais do que simplesmente ocultar o conteúdo visualmente, o conteúdo redigido é removido com segurança do documento resultante. A guia Redigir oferece duas maneiras diferentes: é possível desenhar tarjas de bloqueio de qualquer tamanho ou criar tarjas de bloqueio a partir do texto selecionado. 

Assim como as anotações, as tarjas de bloqueio têm um menu de contexto que dá acesso a configurações como cor de preenchimento, cor da borda e a chance de adicionar texto explicando o motivo pelo qual o conteúdo foi redigido.

![](/download/attachments/561630856/image2020-8-31_10-1-52.png?version=1&modificationDate=1598880836920&api=v2)

**03**. Para salvar os complementos adicionados, acionar**Salvar complementos** no canto superior direito do visualizador.

Após acionar essa opção, será apresentada uma mensagem de confirmação, permitindo salvar os complementos incluídos, ou cancelar para permanecer no visualizador.

Quando os complementos são salvos, é gerado um arquivo PDF a ser apresentado nas ações de visualização, download, impressão, indexação (busca). É importante ressaltar que os conteúdos que foram ocultados por tarjas no documento não serão apresentados na busca geral.

O documento sem complementos continuará disponível para edição de conteúdo e download da versão original, para usuários com permissão de modificação no documento. 

### Remover complementos

---

**01.** Localizar o documento ao qual deseja remover os complementos.

**02.** Acionar o ícone ![](/download/attachments/561630856/Barras%20horizontais2.png?version=1&modificationDate=1598880837283&api=v2)**Mais opções**  e selecionar a opção **Propriedades**.

**03**. Acionar **Salvar**.

Ao salvar as propriedades do documento, será verificado que o documento possui complementos, e com isso a plataforma questiona se o usuário deseja manter ou descartar os complementos.

**04.** Para remover os complementos, acionar **Descartar**. 

Fique atento!

Esta documentação é válida a partir da **atualização 1.7.0 - Lake**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
