# Plataforma ❙ Agrupador Pessoas

![](/download/attachments/385853276/%C3%ADcone-agrupador-pessoas.png?version=1&modificationDate=1749125635103&api=v2)

---

Nesse agrupador é possível gerenciar diversas ações relacionadas à pessoas. ![](/plugins/servlet/confluence/placeholder/unknown-macro?name=tooltip&locale=en_US&version=2)

Ele é composto pelos seguintes recursos: 

- [Comunidades](https://tdn.totvs.com/x/GIL5DQ): permite adicionar, ativar ou desativar comunidades, definir as nuvens de relacionamento nas quais a comunidade será inserida, bem como permissão para a execução de diversas ações na comunidade;

- [Convite de usuários](https://tdn.totvs.com/x/HIL5DQ): possibilita enviar convite via e-mail para um novo participante ou um participante já existente a ingressar a uma rede, o envio pode ser feito por uma lista de e-mails e por arquivo CSV;

- [Denúncias](https://tdn.totvs.com/x/IoL5DQ): permite gerenciar as denúncias feitas pelos usuários nas funcionalidades sociais. A partir deste recurso é possível acompanhar denuncias feitas e tomar uma decisão sobre elas, possibilitando revogá-las ou arquivá-las;

- [Expedientes](https://tdn.totvs.com/x/uP-uDQ): corresponde aos horários em que a empresa está em funcionamento, ou seja, os horários regulares de trabalho;

- [Feriados](https://tdn.totvs.com/x/w--uDQ): define os dias onde não há expediente na empresa. Esse cadastro funciona como um complemento às informações referentes aos expedientes da empresa;

- [Grupos](https://tdn.totvs.com/x/YIH5DQ): este recurso possibilita relacionar usuários em grupos novos ou previamente criados. Essa reunião dos usuários em grupos facilita a definição de permissões de acesso aos variados recursos da plataforma;

- [Locais](https://tdn.totvs.com/x/wxwMEQ): permite a definição de localidades, que complementarão os feriados, para que cada localidade possua os seus feriados específicos;

- [Notificações](https://tdn.totvs.com/x/MIL5DQ): permite que seja definido um padrão de envio de notificações para os novos usuários relacionados à empresa. É possível definir as notificações para eventos relacionados a Documentos, a Processos, ao Portal, à Colaboração, a Aprendizado e Gerais;

- [Nuvens de relacionamento:](https://tdn.totvs.com/x/NYL5DQ) recurso utilizado para restringir o acesso aos conteúdos sociais. Quando o recurso nuvem de relacionamento está ativo, usuários e comunidades somente podem interagir com quem está presente na mesma nuvem de relacionamento. É possível inserir usuários avulsos, grupos de usuários e comunidades;

- [Papéis](https://tdn.totvs.com/x/ZoH5DQ): configuração de papéis visando identificar as diferentes funções disponíveis na empresa. O relacionamento entre Usuário e Papéis é efetuado na criação e/ou edição de um papel;

- [Permissões](https://tdn.totvs.com/x/8IL5DQ): permite gerenciar permissões de acesso a determinados recursos da plataforma. É possível atribuir permissões a determinados usuários, papéis e grupos, com exceção do usuário administrador. O usuário administrador sempre tem acesso total ao conteúdo da empresa, essas permissões não se aplicam a ele;

- [Política de uso](https://tdn.totvs.com/x/UoH5DQ): permite a inclusão de documentos no formato PDF ou de artigos publicados na plataforma – na navegação de documentos ou em comunidades – para representar a política de uso da empresa;

- [Restrição de conteúdo indesejado](/pages/viewpage.action?pageId=234455608): permite incluir palavras que devem fazer parte de uma lista restrita, ou seja, que não devem ser publicadas. Quando o usuário utilizar em alguma publicação estas palavras, automaticamente ela será denunciada pelo sistema, assim a publicação não será exibida no mural;

- [Substitutos:](https://tdn.totvs.com/x/o4H5DQ) possibilita que, por determinado período, um usuário (substituto) possa realizar as tarefas de outro usuário (substituído). É permitido definir vários substitutos para um mesmo usuário origem, inclusive no mesmo período. Mas um usuário pode ser substituto do mesmo usuário origem apenas uma vez;

- [Transferir pendências](https://tdn.totvs.com/x/lIH5DQ): este recurso é de grande utilidade nas situações de desligamento, saída de férias, promoção de determinado usuário responsável pelas atividades. Para efetuar a transferência de pendências é necessário informar a matrícula do usuário origem e do usuário destino, além de selecionar quais os tipos de pendências devem ser transferidas;

- [Usuários](https://tdn.totvs.com/x/c4H5DQ): esta tela permite incluir, editar, ativar ou desativar usuários na plataforma. Os campos login e matrícula do usuário, definidos durante a criação, não poderão ser alterados. Usuários desativados não contarão no limite de licenças.

Fique atento!

Esta documentação é válida a partir da atualização **Voyager (2.0)**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
