# CON - Ao utilizar a opção de pesquisa global, a plataforma não retorna resultados

# Índice

# Plataforma

**Produto:** TOTVS Fluig Plataforma

# Ocorrência

Ao utilizar a opção de pesquisa global, o sistema não retorna dados.

# Causa

Os arquivos da plataforma não estão indexados. É necessário fazer uma indexação.

# Solução

Para realizar a indexação, siga os passos abaixo:

1. Selecionar a funcionalidade **Painel de Controle** no menu lateral.
2. Acessar o agrupador **Parâmetros técnicos**.
3. Acionar a opção **Indexação**.
4. Em Indexar selecionar uma das duas opções: Todo o repositório ou Somente documentos alterados ou novos documentos.Todo o Repositório – Quando assinalada, determina que deve ser feita uma indexação completa sobre todos os documentos publicados e ativos até o momento na plataforma.
5. Somente documentos alterados ou novos documentos – Quando assinalada, determina que deve ser feita uma indexação incremental adicionando à busca por conteúdo apenas os documentos novos ou que foram modificados desde o último processo de indexação.

Em Iniciar pelos documentos, selecionar uma das opções: Mais antigos ou Mais recentes.
1. Mais Antigos – Inicia a indexação em ordem crescente, ou seja indexa dos documentos mais antigos aos mais recentes.
2. Mais Recentes – Inicia a indexação em ordem decrescente, ou seja indexa dos documentos mais recentes aos mais antigos.

Acionar **Indexar**.

# Observação

Este procedimento pode ser agendado para um período de menor utilização da plataforma. Siga este procedimento:

1. Selecionar **Painel de Controle** no menu principal.  
2. No agrupador **Parâmetros técnicos**, clique em **Agendador de Tarefas**.
3. Cadastre uma atividade de indexação para o período desejado.
