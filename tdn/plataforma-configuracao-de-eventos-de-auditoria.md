# Plataforma ❙ Configuração de eventos de auditoria

# Falando de configuração de eventos de auditoria...

---

Essa página permite a configuração do recurso de [Eventos de auditoria](https://tdn.totvs.com/x/DdMTEQ), de forma específica para cada empresa cadastrada na plataforma. Para uso desse recurso é necessário obter uma licença especial de **Eventos de Auditoria**, que é ofertada pelo time comercial. Para saber mais sobre o recurso, consulte a documentação técnica de [Eventos de auditoria](https://tdn.totvs.com/x/UhqbEg).

![](/download/attachments/544206930/Configura%C3%A7%C3%A3o%20Eventos%20Auditoria.png?version=7&modificationDate=1752066618267&api=v2)

## Acessar configuração de eventos de auditoria

---

**01.** Acesse a plataforma com o usuário **wcmadmin**.

**02.** No menu principal, clique em ![](/download/attachments/544206930/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1750853251547&api=v2) **Painel de controle**.

**03**. Localize o agrupador **Gerais**.

**04**. Clique em ![](/download/attachments/544206930/%C3%ADcone-eventos-auditoria.png?version=1&modificationDate=1750853172567&api=v2) **Configuração de eventos de auditoria**.

**05**. Selecione a empresa para a qual deve ser realizada a configuração.  

Assim que for selecionada a empresa, as configurações atuais serão carregadas.

## Editar configurações dos eventos de auditoria

---

**01.** Acesse a plataforma com o usuário **wcmadmin**.

**02.** No menu principal, clique em ![](/download/attachments/544206930/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1750853251547&api=v2) **Painel de controle**.

**03**. Localize o agrupador **Gerais**.

**04**. Clique em ![](/download/attachments/544206930/%C3%ADcone-eventos-auditoria.png?version=1&modificationDate=1750853172567&api=v2) **Configuração de eventos de auditoria**.

**05**. Selecione a empresa para a qual as configurações serão editadas.

**06**. Defina as configurações desejadas para ativar os eventos de auditoria.

Assim que for selecionada a empresa, as configurações atuais serão carregadas. É possível configurar:

**Deseja habilitar os eventos de auditorias?**Quando este recurso é habilitado (ON), a plataforma passa a registrar as alterações realizadas em recursos como: papeis, usuários, grupos, processos, documentos, entre outros.

**Manter histórico de dados por**Esse campo será apresentado somente se o registro de eventos de auditoria estiver habilitado para a empresa. Define por quanto tempo os dados de histórico devem ser armazenados. As opções são: 1 mês, 2 meses, 4 meses, 6 meses, 1 ano ou permanente. Conforme forem alcançando esse período, os registros serão automaticamente excluídos.

Importante!

O valor **Permanente** nesse campo indica que os dados nunca serão removidos da consulta, o que pode gerar um grande volume de registros em seu banco de dados.

**Deseja habilitar os eventos de auditorias para dados pessoais?**

Quando essa opção for habilitada (ON), a plataforma passa a registrar toda consulta, alteração e exclusão dos campos cadastrados como dado pessoal.
**Manter histórico de dados por**Esse campo será apresentado somente se o registro de eventos de auditoria para dados pessoais estiver habilitado para a empresa. Define por quanto tempo os dados de histórico devem ser armazenados. As opções são 5 anos, 10 anos, 15 anos ou permanente. Conforme forem alcançando esse período, os registros serão automaticamente excluídos.

**07**. Clique em **Salvar**.

## Desativar eventos de auditoria

---

**01.** Acesse a plataforma com o usuário **wcmadmin**.

**02.** No menu principal, clique em ![](/download/attachments/544206930/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1750853251547&api=v2) **Painel de controle**.

**03**. Localize o agrupador **Gerais**.

**04**. Clique em ![](/download/attachments/544206930/%C3%ADcone-eventos-auditoria.png?version=1&modificationDate=1750853172567&api=v2) **Configuração de eventos de auditoria**.

**05**. Selecione a empresa para a qual deseja desativar os eventos de auditoria.

**06**. Clique no botão referente ao campo **Habilitar eventos de auditoria **para desativar o recurso. Será exibido o indicativo **OFF.**

**07**. Clique em **Salvar**.

Fique atento!

Esta documentação é válida a partir da atualização **Voyager (2.0)**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
