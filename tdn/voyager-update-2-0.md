Minimum requirements to upgrade to Voyager (2.0)

- Your platform must be on update **1.8.2**. If your environment is on a lower update, first update it to the **latest package of 1.8.2 (at least 1.8.2-260127)** and only then apply the **2.0** update. Check out some useful links: [Platform installation guide](/pages/viewpage.action?pageId=257622732), [Platform upgrade guide](/pages/viewpage.action?pageId=271666186), [Installation and upgrade](/pages/viewpage.action?pageId=144409653).

- If you are using the **MySQL** database, it is **required** to be on **MySQL** **version 8.0**. If you need to upgrade your database to version 8.0, we recommend consulting a database specialist due to the complexity of the procedures. Get more details at: [MySQL database configuration](https://tdn.totvs.com/pages/viewpage.action?pageId=257623464#Configura%C3%A7%C3%A3odebancodedadosMySQL-Passoapassoparaconfigura%C3%A7%C3%A3odoMySQL).

- For the proper functioning of features that use **Artificial Intelligence (AI)** and **Net Promoter Score (NPS)**, you are required to grant HTTPS access to the address [https://api-fluig.totvs.app](https://api-fluig.totvs.app) in the network infrastructure. Get more details at: [Ports and addresses](/pages/viewpage.action?pageId=275591571).

### The platform configuration file has changed!

As we are always looking to improve our platform, from this update on, the configuration file will no longer be domain.xml and will now be **standalone.xml**.

This change aims to enhance the platform's efficiency, as the standalone mode initializes fewer services and optimizes resource consumption, making it faster and more suitable for running both in containers and in the cloud. Additionally, it is much simpler to configure.

Thus, we reinforce our commitment to simplifying our architecture, improving scalability and flexibility with a focus on innovation and performance, offering solutions adaptable to market needs.

Rest assured!

- When you update your platform to **Voyager (2.0)**, the conversion of the configurations to standalone.xml is automatic, and no action is required on your part. 

- Once the platform is up to date, if you need to make any changes to the configurations, you should make them directly in the standalone.xml file, available at [installation_directory]\appserver\standalone\configuration.

Important!

The **temporary folders** and the **server.log** file have also changed locations. Now, the folders are located at [installation_directory]\appserver\standalone and the server.log at [installation_directory]\appserver\standalone\log.

## Discontinuations

---

### Discontinuation of the LMS

The LMS (Learning Management System) has not received innovations since 2019 and, as announced in [November 2024](https://centraldeatendimento.totvs.com/hc/pt-br/articles/27913972778519-Descontinua%C3%A7%C3%A3o-Recurso-LMS-Learning-Management-System-TOTVS-Fluig), was discontinued in **April 2025**.

Starting from this release, the LMS is no longer part of the Fluig platform.

### Discontinuation of the Snowflake and Classic themes

With the advancement of releases, new technologies are emerging in TOTVS Fluig, and we are working to make our platform lighter, more modern, and easier to maintain. Therefore, we will discontinue the old themes in the future.

We believe that with the availability of the responsive theme, which is lighter and aligned with current technologies, the old themes will eventually become obsolete.

### Future discontinuation of the jQuery Migrate plugin

The jQuery Migrate plugin will be discontinued in the future to allow for future evolutions in the platform, making it increasingly robust, modern, and secure.

As [previously announced](https://tdn.totvs.com/x/T5iWK) in the Mist 1.8 release, we have now disabled the plugin by default, but if necessary, you can re-enable it by following the steps described in the [documentation](https://tdn.totvs.com/x/I-Z5IQ).
