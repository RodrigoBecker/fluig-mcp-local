# BPM 007 - É possível salvar a imagem do fluxo de um processo?

# Índice

# Plataforma

**Produto:  **fluig

**Versão: **Todas as versões

# Ocorrência

É possível salvar a imagem do fluxo de um processo?

# Solução

Para exportar uma imagem de um processo workflow é preciso acessar o fluig com o usuário administrador e seguir os passos abaixo:
 - Acesse Processos > Configurar Processos; 
 - Edite o processo desejado; 
 - Ao visualizar o fluxo, clique em "Exportar"; 
 - Escolha a opção "Imagem" e confirme.
