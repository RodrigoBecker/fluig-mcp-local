# ARQ - É possível instalar a plataforma no mesmo servidor do TOTVS 12 ou outro sistema?

# Índice

# Plataforma

**Versão:** 1.5 e superiores

# Ocorrência

Por que ao tentar instalar o TOTVS Fluig Plataforma no mesmo servidor em que está instalado o TOTVS 12 (Datasul - Totvs 12 12.1.11) ocorre conflito?

# Causa

Servidor não atende a necessidade que cada produto precisa para funcionar ou está ocorrendo conflito entre as portas.

# Solução

Atenção

**Não é recomendado** instalar ambos os produtos no mesmo servidor, pois conforme descrito na documentação de [Dimensionamento](/display/fluig/Dimensionamento), sua plataforma exige um **servidor dedicado**.

**É obrigatório** que o ambiente de instalação esteja de acordo com o [dimensionamento](/display/fluig/Dimensionamento) e a [Matriz de Portabilidade](/display/fluig/Matriz+de+Portabilidade) para que o cliente possa obter suporte junto ao Atendimento TOTVS Fluig.

- Verificar se o servidor atende os requisitos necessários para a execução de ambos os produtos.

- Confirmar se as portas configuradas para cada produto são diferentes para que não ocorra conflito, o que impede que as duas instalações estejam iniciadas ao mesmo tempo.
