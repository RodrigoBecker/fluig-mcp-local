# Personalização do título na aba do navegador

# Índice

# Objetivo

---

O objetivo deste guia é apresentar como personalizar o título das guias de navegação (abas) da plataforma TOTVS Fluig.

# Configurando o título de guia para uma empresa no TOTVS Fluig

---

Para maior personalização da plataforma TOTVS Fluig, é possível indicar qual o título das guias (abas). Para realizar esta alteração realize os seguintes passos:

1. Efetue a autenticação no fluig utilizando o usuário **wcmadmin**, e então acesse **Painel de Controle  ► WCM ► Empresas**.
2. Selecione a empresa que deseja alterar o título das guias (abas) e então clique na opção **Editar**.
3. A tela de edição de empresa será apresentada. Clique no botão **Cadastrar dados adicionais****.**
4. A tela de dados adicionais da empresa será apresentada. No campo **Chave **informe o valor **portalTitle **e no campo **Valor **informe o título desejado para as guias.
5. Clique no botão **Salvar** para salvar os dados adicionais. O item **portalTitle **será adicionado na listagem de dados adicionais da empresa:![](/download/attachments/187831460/portalTitle.png?version=2&modificationDate=1434490762000&api=v2)
6. Clique no botão **Salvar** para salvar as alterações na empresa e efetivar a alteração do título das guias para esta empresa. O resultado ficará como no exemplo abaixo:
