# BPM 064 - Como ajustar a codificação do arquivo de texto para que os caracteres especiais contidos no dataset não causem conflito ao processar a solicitação?

# Índice

# Plataforma

**Produto:**fluig

# Ocorrência

Ao exportar os processos do TDS para o fluig é observado que os caracteres especiais contidos nos datasets, mesmo estando em formato String entre parênteses causa conflito no momento de processar a solicitação.

# Causa

Codificação do arquivo de texto está incorreta.

# Solução

Alterar a codificação do arquivo de texto conforme a documentação [Configuração para uso inicial do Fluig Studio](/pages/viewpage.action?pageId=172297237).
