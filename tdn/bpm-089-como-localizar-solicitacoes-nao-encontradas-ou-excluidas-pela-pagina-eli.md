# BPM 089 - Como localizar solicitações não encontradas ou excluídas pela pagina Eliminar Solicitações?

# Índice

# Plataforma

**Produto:  **fluig.

# Ocorrência

Constatamos que algumas solicitações não foram localizada no sistema, ao utilizar a tela de consulta de solicitações independente da 

data seleciona não retorna nenhuma solicitação.

# Causa

Possivelmente a solicitação pode ter sido excluída por engano, por algum usuário que tenha a permissão de visualizar a pagina de Eliminar solicitações.

# Solução

Como sugestão uma alternativa para controlar a responsabilidade de excluir solicitações é possivel configurar as permissões da visualização da pagina de Eliminar solicitações.

 - Acessar Painel de controle, Permissões.

![](/download/attachments/271174594/Painel%20de%20Controle.PNG?version=1&modificationDate=1553534392573&api=v2)

  - Aparecerá a tela de permissões clique em Próxima etapa.![](/download/attachments/271174594/Permiss%C3%B5es.PNG?version=1&modificationDate=1553534412710&api=v2)

 - Busque a pagina de Eliminar Solicitações.

![](/download/attachments/271174594/Buscando%20Pagina.PNG?version=1&modificationDate=1553534573450&api=v2)****

 - Selecione a pagina de Eliminar solicitações.

![](/download/attachments/271174594/Seleciona%20Pagina.PNG?version=1&modificationDate=1553534604770&api=v2)

 - A pagina de Eliminar solicitações está configurada para visualização por papel removeremos os papeis e configuraremos por usuário.

![](/download/attachments/271174594/Configura%C3%A7%C3%A3o%20Permiss%C3%A3o.PNG?version=1&modificationDate=1553534751547&api=v2)

 - Clique em adicionar e adicione o usuário desejado.

 - Apos selecionar o usuário acione o botão de OFF para ON, para que o usuário possa Visualizar a página, Exluir a página e Alterar a página.

![](/download/attachments/271174594/configurar%20Permiss%C3%A3o2.PNG?version=1&modificationDate=1553534823110&api=v2)

 - Para finalizar clique em Aplicar Permissões uma nova janela para confirmar as alterações aparecera, clique em confirmar.

 - Após esses passos somente o usuário configurado poderá visualizar e eliminar as solicitações.

![](/download/attachments/271174594/Confirmar%20Configura%C3%A7%C3%B5es.PNG?version=1&modificationDate=1553534864993&api=v2)
