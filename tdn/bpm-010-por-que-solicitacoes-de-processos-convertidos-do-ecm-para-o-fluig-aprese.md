# BPM 010 - Por que solicitações de processos convertidos do ECM para o fluig apresentam problemas?

# Índice

# Plataforma

**Produto:  **fluig

**Versão: **Todas as versões

# Ocorrência

Problemas para visualizar solicitações de processos do ECM convertidos para o fluig.

# Solução

Para processos com solicitações em andamento no ECM, quando convertido o processo para ser utilizado no fluig, é necessário converter também todas as solicitações em andamento, caso contrário ocorrerá erros para verificar essas solicitações no fluig.
