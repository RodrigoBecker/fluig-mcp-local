# WCM - Por que widget aniversariantes não apresenta conteúdo para todos os usuários?

# Índice

# Plataforma

**Produto:  **TOTVS Fluig Plataforma

# Ocorrência

O widget Aniversariantes do Kit Intranet não está disponível para todos os usuários do Fluig Plataforma. O widget configurado para utilizar registros do formulário é apresentado na página onde está publicado, mas não exibe nenhum aniversariante, mesmo tendo aniversariantes para o mês.

# Causa

Falta permissão no formulário e/ou pasta dos formulários do Kit Intranet.

# Solução

Aplicar permissão mínima de Leitura na pasta de formulários do Kit Intranet ou no próprio formulário de aniversariantes para os usuários e/ou grupos ou Todos usuários do Fluig Plataforma.

# Observações

Deve ser verificado a herança entre a pasta de formulários e os formulários.
