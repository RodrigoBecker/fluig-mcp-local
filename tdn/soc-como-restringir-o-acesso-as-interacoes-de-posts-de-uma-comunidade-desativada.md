# SOC - Como restringir o acesso às interações de posts de uma comunidade desativada?

# Índice

# Plataforma

**Produto:**TOTVS Fluig Plataforma

# Ocorrência

Ao desativar uma comunidade os participantes ainda podem interagir (curtir, comentar, compartilhar) com as publicações existentes.

Dica

Saiba como [ativar/desativar](https://tdn.totvs.com/display/HF/Comunidades#Comunidades-Ativar/desativarcomunidade) uma comunidade através do **Help Fluig**.

# Solução

Para que os usuários não tenham mais acesso às ações sociais das publicações, é preciso restringir as permissões da comunidade. Veja os procedimentos abaixo:

- [Passo 1](#)
- [Passo 2](#)
- [Passo 3](#)
- [Passo 4](#)
- [Passo 5](#)

 - Para editar as permissões da comunidade desativada, acesse a plataforma com o usuário administrador.

 - Em seguida, acesse o menu **Painel de Controle**, localize o agrupador**Pessoas**e acione o recurso **Comunidades.**

Em atualizações anteriores à **Liquid (1.6.5)** esse recurso se encontra na aba **Colaboração** do **Painel de Controle**.

![](/download/attachments/244737226/Comunidades%20165.png?version=1&modificationDate=1551719775900&api=v2)

 - Clique sobre o nome da comunidade desativada para acessá-la.

![](/download/attachments/244737226/Acessar%20comunidade.png?version=1&modificationDate=1633629997233&api=v2)

 - Clique no menu **Administrar** e selecione **Editar comunidade**.

![](/download/attachments/244737226/Editar%20comunidade1.png?version=1&modificationDate=1633630043280&api=v2)

 - Clique no botão **Permissões**.

![](/download/attachments/244737226/Permiss%C3%B5es%20comunidade.png?version=1&modificationDate=1633630077307&api=v2)

 - Selecione os grupos ou papéis dos quais os usuários desta comunidade fazem parte e desabilite as ações sociais desejadas.

 - Para confirmar, clique no botão **Aplicar Permissões**.

![](/download/attachments/244737226/Permiss%C3%A3o%20desabilitada.png?version=1&modificationDate=1633630108520&api=v2)
