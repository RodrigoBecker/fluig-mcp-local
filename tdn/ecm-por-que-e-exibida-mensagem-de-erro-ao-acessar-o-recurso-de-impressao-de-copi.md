# ECM - Por que é exibida mensagem de erro ao acessar o recurso de impressão de cópia controlada?

# Índice

# Plataforma

**Produto**: TOTVS Fluig Plataforma

# Ocorrência

Ao acessar o recurso de impressão de documento com cópia controlada, está exibindo a mensagem de erro: "Não é possível salvar ou criar este arquivo. Verifique se o disco no qual deseja salvar o arquivo não está cheio, protegido contra gravação ou danificado.”

![](/download/attachments/378277123/erro.png?version=1&modificationDate=1530025568000&api=v2)

# Solução

Para corrigir o problema, será necessário efetuar os passos abaixo:

1. Acessar a plataforma com o usuário WCMADMIN e habilitar o OpenOffice conforme o item [Configurações do sistema](/pages/viewpage.action?pageId=235597328).
2. Reiniciar os serviços. 

Após seguir estes passos, será possível imprimir os documentos corretamente.
