# Identity | Quais permissões o usuário integrador do Active Directory deve possuir?

**Dúvida**

Quais permissões o usuário integrador do Active Directory deve possuir?

**Solução**

O usuário informado neste campo deve ser obrigatoriamente administrador do domínio, conforme informado na aba Domain LDAP da documentação [Configuração do SmartSync](/pages/viewpage.action?pageId=286520624).
