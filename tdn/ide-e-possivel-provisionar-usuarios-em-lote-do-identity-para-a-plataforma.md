# IDE - É possível provisionar usuários em lote do Identity para a plataforma?

# Índice

# Plataforma

**Produto: **TOTVS Fluig Plataforma integrado ao TOTVS Identity

# Ocorrência

É possível provisionar, ou seja, enviar usuários em lote do Identity para uma empresa na plataforma?

# Solução

Sim, através do [Modo de Provisionamento Fluig](/display/fluig/Modo+de+Provisionamento+Fluig). Porém, caso a quantidade de usuários seja elevada, o processo de criação dos usuários na plataforma pode demorar várias horas para ser finalizado.

# Observações

O procedimento inverso, ou seja, provisionar todos os usuários de uma empresa da plataforma para um contexto no Identity, também é suportado. O passo a passo está disponível na documentação [Integração da plataforma com o Identity](https://tdn.totvs.com/pages/viewpage.action?pageId=73080143#Integra%C3%A7%C3%A3odofluigcomoIdentity-Enviarusu%C3%A1riosdofluigparaofluigIdentityenviar).
