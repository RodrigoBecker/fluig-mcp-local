# Widget Analytics

---

O *widget* Analytics, após configurado, permite que informações de*dashboards* de indicadores do Fluig Analytics sejam exibidas no TOTVS Fluig Plataforma de forma fácil e rápida.

No exemplo abaixo é exibido o indicador **Social** de acesso as comunidades (ao passar com o *mouse* sobre o gráfico é possível ver detalhes dos indicadores).

Também é possível monitorar indicadores relacionados a processos, documentos, páginas, entre outros.
