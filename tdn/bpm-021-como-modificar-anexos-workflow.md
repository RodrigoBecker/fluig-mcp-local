# BPM 021 - Como modificar anexos workflow?

# Índice

# Plataforma

**Produto:  **Fluig

**Versão: **Todas as versões

# Ocorrência

Foi exposta a necessidade de modificar os anexos workflow durante o andamento do processo.

# Solução

A edição de conteúdo dos anexos workflow será possível apenas se os documentos estiverem publicados em alguma pasta do fluig, no menu Documentos.

Incluído novo modelo de pesquisa dos anexos, sendo possível pesquisar através do título, usuário ou atividade. Podendo ainda utilizar o filtro para pesquisar pelos anexos por um determinado período. Acesse a documentação de [Iniciar solicitações](https://tdn.totvs.com/x/VfHuDQ) para saber mais detalhes.
