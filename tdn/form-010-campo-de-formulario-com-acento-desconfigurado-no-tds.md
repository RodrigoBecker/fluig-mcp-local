# FORM 010 - Campo de formulário com acento desconfigurado no TDS

# Índice

# Plataforma

**Produto:  fluig**

**Versão: Todas**

# Ocorrência

Ao importar um processo do fluig para o TDS, os campos que contém acentuação ficam desconfigurados:

![](/download/attachments/244724041/image2016-8-9%2016%3A28%3A5.png?version=1&modificationDate=1470770997000&api=v2)

# Causa

Este problema ocorre devido a codificação do TDS não ter sido efetuada corretamente.

# Solução

Para configurar a codificação, deverão ser efetuados os procedimentos que constam na documentação: [Configuração para uso inicial do Fluig Studio](/pages/viewpage.action?pageId=172297237)
