# Plataforma ❙ Conversor de base

# Falando de conversor de base...

---

Esse recurso permite realizar o processo de conversão de dados de uma base do ECM 3.0 para a plataforma. O processo é responsável por atualizar dados existentes em uma base, para que atendam a estrutura da plataforma.

Importante!

Esse recurso existe apenas **até** a atualização **1.5.13** do TOTVS Fluig, visto que a conversão de bases do ECM precisa ser feita nessa atualização e, só depois, aplicar as próximas atualizações da plataforma. Obtenha mais detalhes em [Conversão TOTVS ECM para plataforma TOTVS Fluig](/pages/viewpage.action?pageId=257622952).

## Acessar o conversor de base

---

**01.** Acesse a plataforma com o usuário **wcmadmin**.

**02.** No menu principal, clique em **Painel de controle**.

**03**. Localize o agrupador **ECM**.

**04**. Clique em **Conversor de base**.

## Converter base

---

**01**. Clique em **Converter.**

**02**. Ao final do processo de conversão, é exibida a frase** "Conversão finalizada com sucesso!!!"**.

A base convertida contém todos os usuários e senhas da empresa anterior.

Para mais detalhes, acesse a documentação técnica de [Conversão TOTVS ECM para plataforma TOTVS Fluig](/pages/viewpage.action?pageId=257622952).

Fique atento!

Esta documentação é válida **até** a **atualização 1.5.13**. Se você utiliza uma atualização anterior ou posterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
