# Platform ❙ Checking out a document

# Index 

## Speaking of checking out a document...

Check out is the routine used to transfer a document to a user's private folder, so that the user can edit its content, and does not allow any other user to modify the document until its changes are posted.

A document that has been checked out remains available in the Check out folder, in My documents, as well as in its source folder, identified by a padlock icon. The check out feature will not be available if the My documents folder is disabled in the platform’s [Parameters](/pages/viewpage.action?pageId=236429984).

You can edit a document that has been checked out from document browsing or the [Checked out documents tab in](/pages/viewpage.action?pageId=236429528) Task Central.  

### Check out a document

---

**01.** In document browsing, access the folder that where the document is posted*.*

**02.** Find the document for which you wish to check out.

**03.** Click on the **Check-out** option, located in the document view window.

**04**. Define the requested information.

**C****omment**
Description of the reason for checking out the document. This comment will be temporary, i.e., it will exist only during the life cycle of the check out. When checking in the document after you have completed the changes, the comment is deleted. You can view this comment during the life cycle of the check out in the check out details. For more information, see the item [View details of document check out](#Platform❙Checkingoutadocument-Viewdetailsofdocumentcheckout).

**Edit when confirming**
When checked, this option determines that the document will automatically open in edit mode immediately right after the check out is confirmed. When this option is not checked, you need to access the Check out folder – located in the My Documents folder in document browsing – or go to the [Checked out documents](/pages/viewpage.action?pageId=236429528) tab in Task Central to change the document.

**05.** Click on **Confirm**.

When the check out is confirmed, the document is displayed in two paths:

- the Check out folder – located in the My Documents folder in document browsing
- the Checked out documents tab in Task Central.

### View details of document check out

---

**01.** In document browsing, access the folder that where the document is posted*.*

**02.** Find the document for which you wish to view the check out details.

**03.** Click on ![](/download/attachments/236429288/Barras%20horizontais2.png?version=1&modificationDate=1596660822467&api=v2)**More options**, located to the right of the document name.

**04.** Click on **Properties**.

**05.** In the **Check out details**, view the document check out information.

**06.** If desired, click on the **Security** tab to view the security criteria for the document.

When confirming the cancellation, the document is deleted from the *check out* and no changes are performed.

### Edit content of a checked out document

---

**01.** In document browsing, go to the My Documents folder, then to the Check out folder.

**02.** Find the document for which you wish to edit the content.

**03.** Click on ![](/download/attachments/236429288/Barras%20horizontais2.png?version=1&modificationDate=1596660822467&api=v2)**More options**, located to the right of the document name.

**04.** Click on **Edit content**.

For more information, see [Edit content of document](/pages/viewpage.action?pageId=236429131).

### Cancel check out

---

**01.** In document browsing, go to the My Documents folder, then to the Check out folder.

**02.** Find the document for which you cancel the check out.

**03.** Click on **Cancel document check out**, located next to the document name.

**04.** In the message that appears, click on **Confirm** to cancel the document check out; or **Cancel** to quit the action, if you wish.

When confirming the cancellation, the document is deleted from the check out folder and no changes are made*.*

Attention!

This documentation is valid as of the **Lake (1.7.0) update**. If you use a previous update, it may contain information different from what you see on your platform.
