# Plataforma ❙ Widgets

# Falando de widgets...

---

Um *widget* é um componente de interface com o usuário, responsável por montar o fragmento de uma página Web. Tecnicamente define-se como um aplicativo Web, empacotado em formato “war”. Para ser utilizado, o *widget* deve ser inserido em uma página pelo usuário. O TOTVS Fluig possui diversos *widgets* que podem ser utilizados para a composição de uma página criada pelo usuário.

## Endereço WEB

---

Acesse endereços WEB de forma fácil e rápida.

Esse *widget* é compatível com o aplicativo móvel da plataforma, ou seja, pode ser visualizado em dispositivos móveis a partir do aplicativo.

Importante!

O campo de largura na configuração desta widget é informado em *pixels*, ou seja, o usuário configura a página com os *pixels* adequados para a resolução de sua tela. No entanto, se outro usuário acessar a widget com um uma tela de resolução diferente, a página pode ficar desconfigurada.

Por esse motivo, recomendamos que o campo Largura não seja preenchido, pois desta forma o sistema utilizará a largura padrão de 100% e essa situação não ocorrerá.

![](/download/attachments/234455977/widget-endere%C3%A7o-web.png?version=1&modificationDate=1749653984023&api=v2)
