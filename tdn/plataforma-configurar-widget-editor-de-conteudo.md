# Plataforma ❙ Configurar widget Editor de conteúdo

# Falando de configurar Widget Editor de conteúdo...

---

Com o *widget* Editor de conteúdo é possível personalizar páginas e comunidades com o conteúdo desejado utilizando os recursos de formatação do próprio *widget* ou através de um código-fonte.

Além dos recursos de formatação de texto, por meio desse *widget* é possível inserir imagens e vídeos através de uma URL, a partir de um diretóriodo ECM ou realizando a publicação dos mesmos.

![](/download/attachments/342306655/w_editor_conteudo.png?version=3&modificationDate=1750185474793&api=v2)

Compatibilidade no modo escuro

Este recurso ainda não é compatível com o modo escuro lançado na atualização [Voyager 2.0](https://tdn.totvs.com/x/6HxjN). 

## Inserir imagem a partir de uma URL

---

**01.** Edite a página onde será inserido o *widget* Editor de conteúdo**.**

**02.** Inclua o *widget* no *slot* pretendido.

**03.**Clique no ícone ![](/download/attachments/342306655/icon-picture-portrait.png?version=1&modificationDate=1520360415000&api=v2).

**04.** Selecione **URL da imagem**.

**05.** Insira a URL da imagem.

**06.** Defina o texto alternativo para ser exibido em caso de conteúdo inacessível. 

**07.** Estipule valores de largura e altura.

**08.** Defina o alinhamento. 

**09.** Habilite opção de legenda conforme desejado. 

## Inserir vídeo a partir de uma URL

---

**01.** Edite a página onde será inserido o *widget* Editor de conteúdo**.**

**02.** Inclua o *widget* no *slot* pretendido.

**03. **Clique no ícone ![](/download/attachments/342306655/icon-sd-video.png?version=1&modificationDate=1520362431000&api=v2).

**04.** Selecione **URL do vídeo**.

**05.** Insira a URL do  vídeo. 

**06.** Defina o texto alternativo para ser exibido em caso de conteúdo inacessível. 

**07.** Estipule valores de largura e altura.

**08.** Defina o alinhamento. 

**09.** Habilite opção de legenda conforme desejado.

Os vídeos incluídos a partir de URLs são renderizados na *timeline*, porém não são salvos no ECM.

## Publicar imagem

---

**01.** Edite a página onde será inserido o *widget* Editor de conteúdo**.**

**02.** Inclua o *widget* no *slot* pretendido.

**03. **Clique no ícone ![](/download/attachments/342306655/icon-picture-portrait.png?version=1&modificationDate=1520360415000&api=v2).

**04.** Selecione **Imagem do ECM.**

**05. **Acesse o diretório no qual a imagem será armazenada.

Não é possível inserir uma imagem na pasta raiz da navegação de documentos.

**06.** Clique em **Enviar imagem.**

**07.**Defina se a imagem será**Pública**ou**Privada.**

Ao manter a imagem como privada, apenas usuários da plataforma terão acesso. Ao defini-la como pública, usuários não autenticados também poderão visualizá-la.

Para mais informações sobre documentos públicos acesse a documentação.

## Publicar vídeo

---

**01.** Edite a página onde será inserido o *widget* Editor de conteúdo**.**

**02.** Inclua o *widget* no *slot* pretendido.

**03.**Clique no ícone ![](/download/attachments/342306655/icon-sd-video.png?version=1&modificationDate=1520362431000&api=v2).

**04.** Selecione **Vídeo do ECM.**

**05. **Acesse o diretório no qual o vídeo será armazenado.

Não é possível inserir um vídeo na pasta raiz da navegação de documentos.

**06.** Clique em **Enviar vídeo.**

**07. **Defina se o vídeo será** **Público ou **Privado.**

Ao manter o vídeo como privado, apenas usuários da plataforma terão acesso. Ao defini-lo como público, usuários não autenticados também poderão visualizá-lo.

Para mais informações sobre documentos públicos acesse a documentação.

Importante!

O formato de vídeo aceito pela plataforma é o **MP4**. Caso algum formato de vídeo não suportado seja incluído, uma mensagem informativa será exibida.

Fique atento!

Esta documentação é válida a partir da atualização **Voyager (2.0)**. Se você utiliza uma atualização anterior, ela pode conter informações diferentes das quais você vê na sua plataforma.
