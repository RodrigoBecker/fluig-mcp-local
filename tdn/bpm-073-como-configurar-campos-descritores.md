# BPM 073 - Como configurar campos descritores?

# Índice

# Plataforma

**Produto:** fluig

# Ocorrência

Ao criar filtro por campo de formulário na Central de Tarefas não é apresentado nenhum campo.

# Causa

Falta configurar os campos descritores.

# Solução

Para disponibilizar os campos de formulários no filtro, é necessário acessar as propriedades de um processo, aba Formulário, e selecionar os campos descritores desejados.
