# Platform ❙ Use policy

# Speaking of use policy...

---

Use policy is a platform feature that allows to add documents, either in PDF format or articles posted in the platform – in communities or document browsing –, established as the company’s use policy.

It is possible to add a single default document – visible to all languages supported by the platform – or a document for each language. It is also possible to mark it as a document that required consent, in order for it to be presented to all users as a [Consent form](/pages/viewpage.action?pageId=550328756).

After the company’s use policy is configured, it can be viewed by users through the**Use Policy** link, located on the bottom section of the platform.

It is important to note that documents assigned as use policy are automatically made available to all platform users.

## Add documents to the use policy

---

**01.** In the main menu, click ![](/download/attachments/236429970/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1767036259523&api=v2) **Control Panel**.

**02.** Locate the **People** group.

**03.** Click ![](/download/attachments/236429970/%C3%ADcone-pol%C3%ADtica-de-uso.png?version=1&modificationDate=1767036080393&api=v2) **Use policy**.

**04.** Click **Add**.

**05.** Click **Select**.

**06.** Locate and select the document to be established as the use policy.

Only PDF files or articles posted in the platform as use policy can be added in this section.

**07.** Define other requested information.

The requested information is:

**Select the document language**
Language in which the document will be displayed as the use policy.

- English
- Portuguese
- Spanish

It is not possible to select more than one use policy per language.

**Do you wish to display this document as a consent form?** 
By selecting this option, the document is presented for acceptance in the first login of each user. Learn more about this feature in the [Consent form](/pages/viewpage.action?pageId=550328756) help section.

Note:

If the platform is integrated to TOTVS Identity, this option is not presented, since the term must be configured directly in Identity, through the Security tab.

We recommend having a legal expert review the consent form before disclosing it to users.

**Select as default document?**
By selecting this option, the document will be viewed by all languages supported by the platform, eliminating the need to add a specific document for each language.

**08.** Click on **Confirm**.

The document added to the use policy is automatically made available to all platform users.

If the document is indicated as a **consent form**, all users (including administrators) must accept the term in order to access the platform. After saving, it may take a few minutes for the term to be presented to all users.

## Edit use policy document

---

This configuration refers to the use policy record. To make changes to the document or article linked to the use policy, edit it via document browsing. If the document is defined as a consent form, each new version or review will require acceptance by all users accessing the platform.

**01.** In the main menu, click ![](/download/attachments/236429970/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1767036259523&api=v2) **Control Panel**.

**02.** Locate the **People** group.

**03.** Click ![](/download/attachments/236429970/%C3%ADcone-pol%C3%ADtica-de-uso.png?version=1&modificationDate=1767036080393&api=v2) **Use policy**.

**04**. Select the document to be edited. 

**05**. Click **Edit**. 

**06**. Edit information related to the use policy document.

 It is not possible to edit the use policy language.

**07**. Click **Confirm**. 

When the use policy indicated as a consent form is changed, each user must accept the form again in order to access the platform.

## Delete use policy document

---

**01.** In the main menu, click ![](/download/attachments/236429970/%C3%ADcone-painel-de-controle.png?version=1&modificationDate=1767036259523&api=v2) **Control Panel**.

**02.** Locate the **People** group.

**03.** Click ![](/download/attachments/236429970/%C3%ADcone-pol%C3%ADtica-de-uso.png?version=1&modificationDate=1767036080393&api=v2) **Use policy**.

**04.** Select the document to be deleted..

**05.** Click **Remove**.

This will only delete the document from the Use Policy feature and not from the platform, where it will remain posted in its original location.

Please note!

This documentation is valid from the **Voyager (2.0)** update onwards. If you are using a previous update, it may contain information different from what you see on your platform.
